# 统一格式化

本体和插件工程依赖此本地工具包，调用同一个 `nexus-format`。在任一工程根目录运行 `pnpm format` 全量格式化，`pnpm format:check` 只检查；各插件的同名脚本委托插件工程根目录执行。

- Prettier 沿用旧项目参数：Tab 缩进、120 列、单引号；JSON/YAML 使用两个空格。
- ESLint 复用旧项目的函数空行规则：函数、箭头函数、类方法、对象方法及导出声明前后留空行，注释跟随声明；SDK 与插件共享契约的顶层声明也留空行。
- 先由 ESLint 补齐空行，再由 Prettier 排版。依赖、构建产物、运行数据、锁文件不参与格式化。
- 规则只在这里维护，两个工程的 Prettier/ESLint 配置均引用本工具包。不增加业务检查，也不修改运行行为。

修改工具包后，在两个工程分别运行 `pnpm install`，再执行格式化与检查。
