# 项目开发入口

本文维护阅读入口和八步执行流程。规则按编号引用，正文只在所属规则文档维护。

## 开发前必读

依次完整读取下列文档，再核对当前代码与任务：

1. [人工规则 H-xx 全部条目及细则](rules/HUMAN.md#人工规则列表)。
2. [AI 工程规则 E-xx 全部条目及细则](rules/ENGINEERING.md#规则列表)。
3. [编码规范](rules/CODE_STYLE.md)。
4. [模块模板](architecture/MODULE_TEMPLATE.md) 和适用的 [Backend](architecture/BACKEND.md)、[Frontend](architecture/FRONTEND.md)、[Shared](architecture/SHARED.md) 架构。
5. [USAGE](USAGE.md)、[当前实施方案](后端重构下一阶段实施方案.md) 和 [验证入口](testing/E2E.md)。部署工作另读 [DEPLOYMENT](DEPLOYMENT.md)，远程桌面另读 [专题架构](architecture/REMOTE_DESKTOP.md)。

## 开发与收口流程

| 步骤              | 执行动作                                                     | 依据/入口                                                                                               | 产出                           |
| ----------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------- | ------------------------------ |
| 1. 读取与理解     | 按必读顺序读文档，核对分支、工作区与当前任务。               | H-01–H-03、E-10.1                                                                                       | 本次范围及适用规则编号。       |
| 2. 核对产品行为   | 对照 USAGE 和实际调用链。                                    | H-09、E-12                                                                                              | 本版行为及受影响章节。         |
| 3. 明确设计       | 按八节模板明确 owner、依赖、类型和转换。                     | H-04–H-08、E-01/E-02/E-04/E-09                                                                          | 可审核的设计与消费者。         |
| 4. 分阶段规划     | 读取决定项，在当前实施方案安排任务、消费者、判据及回归场景。 | H-11、E-03/E-10                                                                                         | 当前阶段的具体任务与检查命令。 |
| 5. 实现并同步     | 修改真实 owner，同步契约及实际消费者。                       | H-04–H-09、E-03/E-06–E-09/E-13、CODE_STYLE                                                              | 代码与对应产品说明。           |
| 6. 架构与代码审核 | 对照适用规则编号复核完整调用链。                             | H-04–H-08、适用 E-xx、模块模板                                                                          | 问题、修复与共性经验。         |
| 7. 检查与验收     | 执行阶段静态检查和适用逻辑回归，记录结果。                   | E-10、[阶段检查](rules/CODE_STYLE.md#阶段检查)、[逻辑回归](testing/E2E.md#阶段逻辑回归)、实施方案决定项 | 静态/逻辑回归结果及待验范围。  |
| 8. 文档与交付收口 | 核对文档及证据，刷新阶段规划和下一轮提示词，按当前指令交付。 | H-09–H-11、E-10.1/E-12/E-14                                                                             | 本阶段验收结果及下一阶段入口。 |
