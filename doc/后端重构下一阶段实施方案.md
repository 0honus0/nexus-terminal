#### 本批六个真实端点

以下路径均以 `/api/v1/agent` 为根；成功响应是当前顶层对象，不增加旧版 `{data: ...}` 外壳。

| 方法与路径                                 | 输入                                           | 成功响应与语义                                                                      |
| ------------------------------------------ | ---------------------------------------------- | ----------------------------------------------------------------------------------- |
| POST `/apps`                               | JSON `{name}`                                  | 201 App：id/name/createdAt                                                          |
| POST `/apps/:appId/threads`                | JSON `{title}`                                 | 201 Thread：id/appId/title/createdAt；范围不存在 404                                |
| POST `/apps/:appId/threads/:threadId/runs` | JSON `{prompt}`；`Idempotency-Key` UUID header | 201 `{status:created,run}`；重放 200 `{status:replayed,originalStatus:created,run}` |

| GET `/apps/:appId/runs/:id`                | path UUID                                      | 200 Run；范围或 Run 不存在 404                                                      |

共同 HTTP 安全码在 Agent 内确定唯一 owner；scope/runs 引用该 owner，不复制两份。无消费者不建空 values/events 文件。分页中的持久事件对象属于 model，HTTP 分页属于 http，本批没有 WS 事件协议。共享取值与对象/协议分离，Adapter 只允许精确 values 引用。

必须盘点并冻结下列现有语义：

1. name/title 当前原始输入 UTF-8 不超过 128 bytes，Service 保存前 trim；prompt 不超过 16384 bytes，拒绝全空白但保留原文。不得改变 trim 时机或 prompt 内容，避免改变幂等请求 hash。
2. 完整 JSON body 包含字段名、引号、外壳和转义：创建 Run 当前 128 KiB，其余 JSON 路由默认 16 KiB。Agent 路由预算显式消费 Shared，Platform 保留自己的通用限额，不反向引入 Agent。前端以实际编码后的字节数校验，不能用 JS length 或只校验 prompt 替代。
3. path/key UUID 在边界严格校验并规范成小写；operationKey 来自 `Idempotency-Key` header，不变成 body 字段。expectedVersion 是 >=1 的安全整数；after 默认 0、limit 默认 50/最大 100；重复、未知 query 和不符合现有十进制格式的值拒绝。
4. 安全错误包括 invalid_input/not_found/active_run_conflict/idempotency_conflict/version_conflict/storage_unavailable/internal_failure，以及认证的 unauthenticated/forbidden。还须沿 Platform 核对实际 HTTP 400/413/415 等安全码（如 invalid_json/body_too_large/unsupported_media_type），不能只复制 AgentErrorCode 并丢掉框架失败。通用安全 HTTP 契约若跨域复用，应有独立通信 owner，不让 Agent 引入别的业务域。
5. userId 来自服务器认证，不允许请求自行填写。当前 Agent 管理入口仅允许 userId=1；这不是本批扩展多用户或改权限的依据。prompt 存储行、hash、技术 cause、资源句柄不进入 Shared 响应。
6. 补齐实际响应的最大编码预算，覆盖事件页、所有联合和安全失败，后端发送与前端有界读取使用同一 Shared 定义。新增预算先根据实际最大对象推导，写入设计，不随意复制其他域常量。

**完成判据：** 六个端点都有完整 Shared 类型/解码及真实消费者清单；exports 与 Shared check/build 通过。此时仍不得关闭 S1。
