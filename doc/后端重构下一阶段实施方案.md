# 后端重构下一阶段实施方案

本文仅维护本批尚未执行的验证门禁、真实行为验收缺口与后续批次；N0–N3 源码已施工并移入长期架构及行为文档，不在这里重复施工任务。长期规则唯一入口为 [Backend 架构与开发约束](architecture/BACKEND.md)，尤其是人工类型规则 4–7；行为需求见 [USAGE](USAGE.md)，Agent 治理见 [AGENTS](AGENTS.md)，验证入口与证据见 [E2E](testing/E2E.md)。开发前完整读取这些入口。

## 当前进度与范围

按完整后端替换（含 Agent、Remote 全部功能、正式前端迁移及交付）估算，此前粗估约 **30%，合理区间 25%–35%**；本批增加有限只读文件能力，未重新做全产品工作量估算。这是按功能工作量的粗估，不按文件数、提交数或测试数量计算，也不是验收通过率。SQLite/SSH/HTTP/WS 和模块边界骨架约 80%；Targets 基础管理已具备，Access 仍缺完整因素/策略，Remote 已有 PTY 与独立只读文件切片，Agent 只有有限持久状态。主要剩余工作在 Agent 执行链、Remote 产品能力、系统配套及正式切换。

| 范围       | 当前可依赖能力                                                                          | 后续缺口                                                                                         |
| ---------- | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Platform   | SQLite Worker/事务/迁移、SSH 路由/命令/SFTP、HTTP/WS、密码学、关闭结果/失败证据有界管理 | 新切片按实际需要补技术能力及完整资源语义，不预建业务注册槽                                       |
| Access     | 初始管理员、密码、会话、登录失败策略与 HTTP                                             | 因素、角色、来源策略及配置管理、撤销通知                                                         |
| Targets    | 连接/代理/密钥/标签/导入/CAS/凭据/Host Key、可信解析                                    | 连接测试、完整正式前端迁移与真实单快照竞态验收                                           |
| Remote     | 普通 PTY/WS 与独立只读 SFTP 文件资源、认证、关闭与 EOF                                            | 文件写入/编辑、传输/任务、挂起恢复、桌面及其他远程能力                                               |
| Agent      | user/App/Thread scope、pending/cancelled Root、幂等、原子事件、分页                     | Provider、StateCommit 扩展、调度、grant/审批/工具、SSH Job、恢复、Plugin/MCP/ACP/Artifact/Memory |

保留 `backend`/`backend-next` 双包；新包不运行时引用旧包或 Protocol。正常产品结果保持一致，异常文案与未发布兼容分支不机械保留。本批未新增或运行测试，不切正式流量；已施工源码仍需本节 N4 门禁及真实验收。后续未实施功能应沿各 owner 实施，不代表已授权下一批立即施工。

## 当前交付边界与 N4 未完成的验证

N0–N3 的具体施工清单已从本下一阶段方案移除；长期实现事实统一见 [Backend 架构](architecture/BACKEND.md) 与 [Frontend 架构](architecture/FRONTEND.md)，独立开发页行为见 [USAGE](USAGE.md)。本批已提交 Worker 完整 envelope 解码与 fail-closed、Access/Remote Model 类型与内部 owner、Targets 重复规则归一、PTY WebSocket 流职责独立、expectedFingerprint 单快照核验、真正有界的 SFTP 列目录及元数据/字节范围解码、独立 Remote Files Machine/SFTP/用户会话资源、Shared file HTTP 契约和三语言开发消费者。Agent 执行、写入/编辑、下载上传/完整传输、挂起/恢复和正式入口切换均未施工，不应把这批源码视为产品迁移完成。

**N4 尚未完成验收。** Node/pnpm 在当前环境因权限问题无法执行，TypeScript、ESLint、Prettier、构建与真实行为专项均没有本批可用的通过证据。各项待执行命令、真实 SSH2/SFTP 故障注入、Worker/Targets 竞争、文件资源关闭、HTTP/WS 与独立开发页浏览器验收，已统一迁往 [后端重构待实机验证](testing/后端重构待实机验证.md)。该清单逐项保留状态、进入条件、成功判据和证据要求；后续执行结果以 [E2E](testing/E2E.md) 维护的真实验证证据为准。

**正式交付前置条件**：先完成该清单中适用的静态门禁与真实行为专项，再依据对应提交 SHA 核对 canonical Actions 和 Docker smoke；不得将已有静态审核或旧包 PASS 当作新包行为验收。此处不再重复维护具体待验证事项，也不把 Agent 执行、文件写入、完整传输和正式入口切换误列为本批已实现功能。

| 顺序 | 批次                               | 核心依赖与交付                                                                                                         |
