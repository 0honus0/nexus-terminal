# 人工规则

本文是人工规则的唯一维护位置，当前共 **19 条**。此列表仅记录项目所有者明确输入的规则；编号为 H-01–H-19，原有条目保持编号，新要求顺序追加；删除后不复用编号。引用统一使用完整编号。

## 人工规则列表

| 编号 | 规则                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| H-01 | 人工规则区域只能通过人工输入更新。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| H-02 | 如果人工规则相互冲突，人工核对后解决，变更到同一条上。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| H-03 | 人工规则与其余规则冲突以人工为准。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| H-04 | 内部应用类型统一定义在所属模块子功能的 `model/*-types.ts`，Service、Model 和模块内协作直接引用该唯一 owner；仅单文件使用的局部实现类型留在原文件。跨子功能共用的内部基础取值、纯校验与错误类放在所属一级模块的独立 owner，不依赖 Service、register、出口错误映射或具体技术实现。存储命令/记录/任务契约只在所属 `storage`，技术类型只在 Platform；SQLite Adapter 不引入应用 Model/Service 类型。                                                                                                                                                              |
| H-05 | 外部类型按消费者唯一归属：前后端共同消费的基础取值、业务对象、完整请求/响应、错误码和协议容量统一放入 `packages/shared/src/<域>/<子域>/{values,model,http,events}.ts`，基础取值与对象/协议隔离，复杂纯解码可拆 `http-codec.ts`；仅后端跨模块消费的安全契约定义在模块 `public.ts`，安全错误类由 `public-errors.ts` 明确导出，安装配置定义在 `register.ts`。不把后端秘密、存储行、Service/Model 类或无人消费的预留类型放进 Shared/公开契约，Bootstrap 不深层引用私有类型。                                                                                     |
| H-06 | 所有外部输入先在协议边界以 `unknown` 严格解码，再在模块入口 mapper 逐字段转换成内部应用类型；内部结果也逐字段转换成公开/Shared 类型。即使字段完全一致也保留这一转换，数组和嵌套对象同样采用白名单；禁止对象展开、断言、继承存储记录或直接透传代替边界隔离。应用与存储的转换由 Model 持有，HTTP/WS 投影归 interfaces；同一边界只有一个转换 owner，不复制 mapper、不保留旧路径转导出。公开写入类型不能从只读 View 自动派生。应用与存储/底层能力之间明确保留 Model 转换层，协议入口/出口明确保留 mapper；不因当前字段一致或暂时无需真实转换而省略或绕过转换层。 |
| H-07 | 共享类型及字段迁移必须同时检查后端、前端、模块出口、编解码、脚本和测试的真实消费者并同步迁移；双端同义同表示只保留 Shared 一份定义，内部表示/用途不同则保留独立类型并显式转换。模块失败按具名类型/错误码映射，禁止靠错误文本判定业务结果，技术异常及 cause 不越过安全出口。                                                                                                                                                                                                                                                                                  |
| H-08 | 真实 SQL 指令只在对应 Adapter 中定义、拼接和调用，外部通过明确接口调用；各模块的 `migrations.ts`、`schema.ts` 只负责安装和顺序编排，不直接包含 SQL。                                                                                                                                                                                                                                                                                                                                                                                                         |
| H-09 | 每版变更涉及的每个功能点，都必须在同一版修改或补充 `doc/USAGE.md` 对应功能章节；删除功能同步删除失效说明，无对应章节时新增章节并更新导航。保留实际操作、权限、容量和失败恢复要求，精简重复文字与历史叙述，不以文末变更日志、架构文档或实施方案替代。仅内部调整且功能行为一致时，核对原章节仍符合实际即可。                                                                                                                                                                                                                                                   |
| H-10 | 规则文档只维护长期共性约束；临时任务沟通、具体缺陷、修复清单及执行进度不进入 rules。问题写入规则前必须先总结为共性规则，具体实施点放入任务方案，并通过提示词引用共性规则展开下一步修改。AGENTS 只维护入口和流程，通过规则编号引用要求，不重复规则正文。                                                                                                                                                                                                                                                                                                      |
| H-11 | 实施阶段规划集中维护在同一份文档；最上方为决定项，记录实施范围、测试时机等已确定安排，不随阶段清理。下方为可擦写规划区，每阶段完成验收后可完全擦除该阶段规划并编写后续任务；仍未验收的事项必须保留或明确转入后续规划，长期规则、架构与验证证据归各自文档。                                                                                                                                                                                                                                                                                                   |
| H-12 | 重构中的类型、数据结构与内部实现按最新设计实现，不为旧迁移、旧开发数据或旧消费者保留可空字段、兼容分支、自动转换或长期双轨。对外契约变化同步记录明确的前端修改事项；前端按已确定的实施顺序对接，不以暂未对接为由放宽新后端契约。                                                                                                                                                                                                                                                                                                                             |
| H-13 | 所有开发、重构、审核和修复均不得擅自修改当前已确认的 UI 设计；布局、样式、尺寸、配色、导航、按钮、弹窗、控件呈现及正常交互流程的变更，必须事先获得用户明确同意，并仅在同意的范围内实施。后端重构及前端协议适配默认只修改协议对接、类型转换及应用逻辑，只替换为新后端和 Shared 契约，不保留旧协议兼容层。功能变化确需调整 UI 时，先说明必要性及具体差异并获得用户同意，不以功能修复、测试通过或优化为由自行调整，不自行将接口、内部版本及诊断操作平铺为产品交互。                                                                                             |
| H-14 | 能用开源库或开源项目满足需求的，不自行实现同类能力；选型优先选择 Star 数更高的项目，Star 数低于 500 的项目不使用。                                                                                                                                                                                                                                                                                                                                                                                                                                           |

| H-15 | 分析、判断或执行前先检查用户表述是否存在错误前提、逻辑跳跃或信息缺失；发现问题时先明确指出，再继续处理。 |
| H-16 | 不迎合用户观点，保持独立判断；结论依据事实、证据和可验证推理，不因用户立场改变判断。 |
| H-17 | 涉及数据、人物与结论时尽量核实信息来源；无法核实、来源冲突或证据不足时明确标注不确定性及其边界。 |
| H-18 | 用户表述有误时直接指出，说明依据与潜在风险；不以模糊表述回避分歧或默认错误前提。 |
| H-19 | 主动提醒用户可能遗漏的关键变量、成本与认知偏差；成本覆盖适用的时间、资金、运行、维护、迁移与机会成本。 |

## 维护与执行

**H-13.1**：修复 E2E 失败时只排查、修复和回归功能问题，保持当前已确认的 UI 设计与视觉效果，不修改布局、样式、尺寸、配色、导航或控件呈现，不顺带做 UI 重构。可以修改前端事件、状态、协议及业务逻辑；测试定位随当前真实入口调整，保留功能断言，不为让测试通过而改产品 UI。确需改变 UI 时单独说明，获得用户明确授权后另行处理。

**H-01.1**：仅根据项目所有者明确输入修改本文。AI 审查、代码现状、外部规范和一般性的文档更新都不能自行成为人工规则；AI 产生的工程经验放入 [ENGINEERING.md](ENGINEERING.md)。已有要求变更时更新对应条目，独立的新要求追加编号，不复制近义或相反规则。

**H-03.1**：人工规则与其他文档冲突时，以人工规则为准并修正其他文档。

**H-02.1**：人工规则互相冲突时，明确指出条目和影响，由人工核对后更新同一条；AI 不自行选择。开发前由 [AGENTS.md](../AGENTS.md) 指引完整阅读，不在其他文件复制人工规则列表。
