## 连接、代理与通知管理

连接、代理与通知目录以高对比名称、信息色类型徽标、主题强调色标签和浅底色区分信息层级；地址与时间保持次级文字色。工作区连接列表的标签分组标题使用主题强调色，侧栏分组带轻量底色，启动页类型徽标使用同一信息色。配色随现有深色、浅色及自定义主题变量变化，状态继续保留文字和语义色。

连接目录优化读取与筛选计算；搜索、标签、排序、批量选择和测试结果保留原行为，所有连接仍可通过原滚动与键盘入口访问。进入终端时，被配置刷新取代的旧列表读取不显示失败提示；真实读取失败仍提供刷新入口。

420px 及以下视口沿用紧凑页头，“添加连接”仅显示图标并保留完整无障碍名称；打开 SSH Key 管理等叠加弹窗时，底层连接页也不应产生横向滚动。

- 连接管理页头以四个轻量概览卡显示连接总数及 SSH/RDP/VNC 类型统计，名称与数量横向排列；工具栏提供搜索、标签下拉筛选、排序方向与批量编辑，标签增长时只在展开面板中列出，筛选控件的当前值和下拉选项居中显示。窄屏下概览卡与代理、通知页一致压成单行；搜索独占一行，标签、排序、方向和批量开关合并到下一行，仅极窄视口再按可用宽度拆行。电脑端列表标题右侧按“密钥管理／测试全部／连接全部”横向排列；密钥管理打开现有 SSH 私钥管理弹窗，可添加、编辑和删除保存的私钥。760px 及以下保留“测试全部／连接全部”上下等高排列，密钥管理从页头“更多操作”进入。连接按无额外容器描边的单列圆角列表管理，名称、地址、最近连接保持三行左对齐，中窄屏按视口增大字号、行距和内边距，左侧类型图标垂直居中；类型与标签在 360px 以下的最窄布局和宽屏中跟随名称行，在 360–760px 的中间布局改为右侧独立竖排块并垂直居中。底部测试、编辑、克隆与连接作为同一组铺满可用宽度，左缘与类型图标列对齐，按钮内容居中并使用浅色细边框；宽屏可同时显示图标和文字，稍窄时前三项收为图标、连接保留文字，极窄时四项均收为图标并隐藏卡片类型图标。批量编辑栏在窄屏固定为三枚选择操作一行、两枚批量动作一行，批量选择框在卡片左缘跨行居中。测试、编辑和克隆使用无玻璃底纹的按钮，连接保留主操作；“更多操作”使用不透明实心面板。添加/编辑弹窗在可用视口高度内固定，使用不透明表单表面和浅色分区线，表单内容独立滚动，底部操作保持可见；端口数字框提供主题化上下步进按钮，不显示浏览器原生微调箭头。SSH 测试延迟说明收在“测试连接”右侧的信息图标中，悬停、键盘或点击可展开。测试、删除、确认和取消使用同一基础按钮高度，手机端操作等宽。连接、代理和通知表单仍使用自适应布局，长名称、地址和测试说明可换行。
- 手机批量操作分为“全选/取消/反选”和“编辑/删除”两排；管理操作通常四列，窄卡片两列。代理与通知卡片在窄屏将编辑、删除改为内容下方的等宽图文按钮；代理筛选在中等窄屏保持搜索与类型同行，极窄视口按行展开；通知筛选固定为搜索独占一行、类型与状态各占半行。长名称、地址和操作提示可换行，不撑出视口。
- 代理管理页头以三项概览卡显示总数、SOCKS5 和 HTTP 数量；列表支持按名称、主机、类型或用户名搜索，并按类型筛选。每项显示协议、地址与认证状态，编辑和删除使用图标按钮。代理不显示更新时间。
- 正式代理表单只提供 HTTP/SOCKS5、用户名和密码。编辑时密码留空保留，勾选“清除已保存密码”清除；输入新密码替换，秘密不去首尾空格。名称/主机/用户名最多128/512/256 UTF-8 bytes，密码最多8 KiB。
- SSH Key 管理支持手填或上传最多64 KiB的严格UTF-8私钥；名称最多128 bytes、口令最多8 KiB。编辑私钥留空保留，更换私钥不会自动清空原口令；口令留空保留，勾选清除才删除。关闭弹窗、登出或页面停用会丢弃秘密草稿。读取和操作错误通过全局常驻 Toast 提示，不在弹窗内插入错误横条；需要恢复核对时保留原刷新入口。全局 Toast 使用状态标题、正文和底部确认行，不显示左侧状态图标；成功、警告和失败通过标题、细边框与按钮使用对应状态色，卡片保持中性主题底。无业务动作时底部显示“知道了”并关闭提示；带恢复动作时显示原动作，点击执行且不自动关闭。
- 连接标签选择器的已选标签使用主题强调色及浅底色。连接新建/编辑表单的选项加载失败、提交校验错误以及修改连接参数后需补输密码的提醒统一使用右侧全局 Toast，表单底部不插入错误条。选项读取失败 Toast 不会因切换认证方式或编辑字段而消失，可手动关闭；请先核对并刷新相关列表。测试结果徽标、耗时和延迟说明仍在测试按钮旁显示，修改草稿会清除上一次测试结果，重新测试后以当前输入为准。
- 代理/SSH Key使用编辑时原版本保存；冲突先刷新列表重新核对，不自动覆盖。网络断流、结果未知时禁止再次写入，先点“刷新并核对”；已提交的服务端修改可能仍存在。列表最多10,000项，Proxy完整JSON最多64MiB、SSH Key/标签各最多16MiB，超限明确失败，不显示截断的完整列表。删除沿当前后端按ID执行，引用保护仍生效。

全局确认、提示及上传冲突弹窗采用图标与标题同行、整行正文和底部操作区的布局；重置终端、连接/文件/快捷指令删除、主机密钥信任、备份导入以及Agent提供方/集成删除和扩展卸载均共用基础确认面板。取消在左、确认在右，手机同排按钮等宽并保持至少44px点击高度，多操作和长文案按可用宽度换行。危险操作保留红色标识，详情与复选项位于正文下方，长内容可滚动。原确认、取消、背景点击、Escape和保存中保护按各操作原规则执行，卸载仍保留继续卸载、取消排空及数据清理入口。

关闭错误 Toast 后，再次操作失败会重新提示；相同错误仍在驻留时合并展示。只读请求及挂起目录自动同步遇到网络中断时，先保留10秒前台恢复时间；同一请求地址重新读取成功或目录快照恢复后取消尚未显示的网络提示。页面在后台时不显示新的只读网络提示，返回前台重新等待恢复；离页或注销撤销原读取后也取消对应待提示。持续失败才显示常驻网络 Toast。保存、删除、上传等提交的网络失败仍立即提醒，结果未知必须先核对，不自动重发。此处理不自动重放HTTP读取，也不把网络恢复当作提交成功。

### 连接编辑与批量操作

批量编辑沿用与添加连接一致的不透明表单表面、分区强调线和固定底部操作，不再叠加玻璃卡片；先选择配置或凭据模式，两者分别提交，不能一次保存混合意图。手机端取消／更新凭据并排，保存配置独占一行。

编辑器的端口、身份与认证、高级选项继续按旧版分区卡片展示；高级选项默认折叠，只有勾选后才编辑代理、标签和备注。单个连接编辑使用一次确认同时保存配置和凭据；批量编辑继续选择配置或凭据模式分别提交。

- 新建通过单项导入事务原子保存配置与凭据。编辑先读取元数据与安全凭据摘要，两个版本一致才开放表单；密码始终为空，不回显明文或密文。
- 编辑使用底部一次确认，同时保存配置及输入的新密码或密钥，使用打开编辑时的原版本，同事务只推进一次版本；凭据或引用校验失败时配置也不提交。密码留空保留原凭据；从密钥改为密码需输入新密码。“清除凭据”为密码输入框右侧的勾选项，SSH 密钥认证时显示在密钥选择框右侧；窄屏保持同行。勾选并确认保存后才清除，取消窗口不清除。冲突、未知结果先只读核对，不自动覆盖或重放。
- 克隆同事务复制配置、凭据与关系；删除按ID执行，不虚构删除CAS。批量配置与批量凭据互斥，使用捕获的各连接原版本串行提交，失败停止后续项；已确认修改不回滚。追加标签后完整刷新连接缓存。
- 脚本支持带引号的值、已有代理/密钥名称和 tagNames，同项创建标签；解析不写库。省略凭据只创建配置；密码原样保留。IP范围仅支持同一IPv4子网的递增末段。脚本、范围及文件导入按50项协议分批，不另设前端总条数门槛。
- Connections、Dashboard 和 Workspace 使用独立应用对象及毫秒时间；最近连接时间由服务端持久记录，连接列表与单项的必填 `lastConnectedAt` 为 Unix 毫秒或 `null`（尚无成功记录），刷新、换浏览器与重启后仍可读取。SSH 在 PTY 建立后记录（包含 Workspace 与独立/Agent shell），RDP/VNC 在 TCP/TLS 桥就绪后记录；桥接就绪不保证远端认证或画面已经出现。测试、监控、票据签发和已有 SSH 会话恢复不更新时间。写入只递增，不改变配置版本与更新时间；连接期间配置版本、创建时间或协议已改变则不写入旧结果。新建、导入与克隆初始为 `null`，完整备份保留已记录时间。前端连接成功后只读刷新，不用本地时间补写；读取失败保留展示并留待下次刷新，持久写入失败沿原建连失败/资源清理流程收尾，不自动重建；后续交付失败不会回滚已提交的历史。连接完整列表最多10,000项/640MiB（包含最坏JSON转义），超限拒绝而不截断；该预算不是分页或浏览器内存保证。
- 网络断流可能已提交，显式刷新后重新核对。隐藏/停用/登出清理秘密草稿与旧异步回调；取消请求不证明后端回滚。写入已确认但刷新失败会独立提示，不能据此重复保存。

### 引用、跳板与导入

- 跳板链编辑使用按顺序编号的步骤和连接线展示，下拉项同时显示连接名称与 `用户名@主机:端口`，可直接替换或移除；链尾“添加跳板机”只追加下一跳，不改变已有顺序。
- 被引用的 Proxy、SSH Key 不可删除；跳板连接不可删除或改为非 SSH，须先解除引用。保存时事务内重检，不自动改路由。后端对此统一返回 reference_in_use，引用和原记录保持不变。
- 跳板链按显式顺序逐跳连接，只消费各跳的地址、用户名与认证，不递归执行该连接自身的 Proxy/Jump 路由。
- 标签替换最多 1,000 个安全正整数连接 ID，重复合并，空数组清空。引用不存在返回 404，失败保留原关联。
- 导入只接受新 TargetImportInput 数组，按记录独立提交；单条连接、凭据、内联 Proxy/SSH Key 与标签同事务完成，失败不遗留半条记录，不兼容旧字段或密文。
- 登出后旧响应不回填连接/代理/标签/通知缓存；已提交的服务端修改不撤销。

### 通知配置与投递

管理员在通知页面管理 Webhook、Email、Telegram 三种通道。每项最多32个Header，名称大小写不敏感判重；全部Header值、SMTP密码、Bot Token读取仅显示是否存在，编辑显式选择保留、清除或替换，删除Header条目移除该项。切换通道、关闭表单、离页和身份失效清除秘密草稿。

通知渠道页沿用连接管理的目录式结构：页头概览显示总数及 Webhook／邮件／Telegram 数量，列表可按名称、地址、事件、类型和启用状态搜索筛选；每项显示通道类型、启用状态、目标地址和已启用事件数量，事件名称只参与搜索匹配，不再作为示例列出。列表可直接启用或停用渠道，启停按钮按点击后的动作着色：启用为绿色开启图标，停用为红色关闭图标，按钮底色与边框同步使用对应语义色；操作沿用当前版本与秘密保留语义。编辑与删除在桌面使用图标按钮，窄屏显示等宽图文按钮。通知页只管理渠道配置，不展示投递记录。

通知编辑器使用固定标题、独立滚动内容和固定底部测试／保存区。测试按钮始终显示，必填信息不足时保持禁用，不额外显示“请填写必填字段”一类提示。Webhook Header 仍以当前结构化行编辑；新增渠道直接输入邮件密码或 Telegram Bot Token，已有渠道编辑时才在秘密字段提供保留、清除或替换选择。启用事件支持一键全选与反选。测试回执与失败统一通过全局 Toast 显示，不在表单内插入结果行；queued/dispatched 使用信息提示，sent 才是成功提示，failed/unknown 及请求失败使用错误提示。

保存和删除携编辑/确认时的原版本；冲突、结果未知先点“刷新并核对”，刷新会丢弃当前编辑，不自动覆盖或重放。设置最多64项，请求64KiB、响应8MiB；字段与完整JSON容量由Shared校验。管理员可配置内网SMTP、Webhook及自定义Telegram origin，只使用可信目标，出站隔离由部署网络提供。

已保存测试使用服务器当前保存配置，未保存测试使用完整输入，不从已有配置借秘密。测试只返回投递受理记录；queued、dispatched均不表示发送成功，投递记录为sent才显示已发送。投递历史在审计日志页读取，按服务端nextOffset加载；未知投递先核对接收端，不能自动重发。

### 通知协议与投递

/api/v1/settings/notifications 提供GET列表、POST新增、PUT/DELETE /:id（UUID与expectedVersion）、POST /:id/test及POST /test-unsaved；/settings/notification-deliveries读取实际投递记录。所有通道使用明确config联合，秘密操作为keep/clear/replace，不接受旧flat config或数值ID。

事件只含有限event、subjectId和UTC time；模板支持{event}/{subjectId}/{time}，Email纯文本，默认Webhook为JSON。订阅采用分发时已启用配置，不追溯创建前的事件；禁用阻止后续分发，已排队项仍使用原加密快照，删除令queued失败，不能撤回已派发请求。最多4096在途、单项20秒、串行派发；重启把dispatched标unknown，不自动重发。业务提交与事件发布分事务，通知不作为业务结果权威。

### 通知失败与恢复

400 invalid_input、401 unauthenticated、403 forbidden、404 not_found、409 version_conflict、413 limit_exceeded、503不可用/未知。派发前取消记failed；SMTP明确拒绝全部收件人且未发送DATA记failed，部分接受后其余拒绝记unknown。HTTP响应体释放未确认也记unknown；任一投递清理未确认会停止该实例的新派发和配置/测试写入，仍可读配置与投递。先确认原资源释放，再重启处理后续排队项，不重发原unknown。公网真实供应商验证仍单独待验。

### SSH 主机信任

管理员在连接管理工具栏打开“SSH 主机密钥”，读取已确认的 host/port、SHA-256 指纹及确认时间。先通过可信渠道独立核对指纹，再输入主机、1–65535 端口和 SHA256: 加43个 base64 字符，确认弹窗展示的目标与指纹。主机统一小写、最多253 UTF-8 bytes，不能含空白或控制字符。连接测试不会自动建立信任。正式 SSH 工作区遇到未信任密钥时，在原标签页弹出实际握手目标（包含跳板）的主机、端口和 SHA-256 指纹；密钥变化以警告色分区展示目标、已保存指纹和当前指纹。独立核对后点击“确认信任并重新连接”，保存信任后重试；每个跳板分别确认，不自动信任。批量连接的公钥确认串行排队，不因排队数量直接判为取消。取消或确认失败保留标签页，可稍后手动重新连接；关闭标签或退出登录会撤销等待，晚确认不重连。写入回执未知时只读核对，未能确认已保存不重试写入。

主机密钥面板将安全说明收在与全站其它提示一致的标题右侧信息图标中，悬停或键盘聚焦时显示；已信任密钥按主机/端口集中展示，指纹完整换行且可复制，确认时间使用本地化日期。手动建立信任使用独立分区，确认按钮位于指纹输入框右侧；窄屏下主机与端口改为单列，指纹和确认按钮保持同行。面板只保留底部“关闭”入口，内容独立滚动。

确认会覆盖同一主机/端口的信任；移除删除操作当时的信任，包括其他管理员刚写入的新值。二者没有版本条件，操作前均需确认。结果未知、协议失败或已派发的拒绝后先“刷新并核对”，不自动重发；关闭面板或退出登录取消等待，不证明服务端未提交。正常自动读取，失败或需要核对时才显示刷新入口。列表最多10,000项，完整 JSON 最多16MiB；超限返回413 limit_exceeded，不截断。此面板已接后端，Connections正式通信源码已接Shared，整体回归仍按D17执行。

### 后端标签关联

正式标签API、选择器和标签组管理已消费Shared。名称保存与关联替换是两个独立按钮，改名携带打开编辑时的版本；替换关联前确认整集合覆盖，未保存的新名称须先单独保存或还原。冲突或结果未知先关闭面板，刷新连接和标签列表后重新打开核对，不自动重复写入；确认成功后刷新失败不撤销原提交。标签选择在缓存重置或读取失败时保留，完整有效列表确认删除后才清理；创建名称集合先完整校验，逐项创建期间失败保留已确认记录，未知时停止后续创建。标签列表最多10,000项/完整JSON 16MiB，超限413 limit_exceeded，不截断。连接列表、表单、批量操作与 Workspace 已接当前契约；完整回归范围见 testing，不能据单个组件回归扩大覆盖。

管理员通过 PUT /api/v1/targets/tags/:id/connections，以 {connectionIds} 替换该标签的全部连接；空数组清空。POST /api/v1/targets/connections/add-tag 以 {tagId,connectionIds} 向选中的连接追加标签，数组必须非空，不改变其他关联。两者完整 JSON 最多32 KiB，原始数组最多1,000个安全正整数，重复ID合并，成功返回 {updated:true}。Targets管理路径ID与正文ID统一支持1至9007199254740991；路径使用无前导零的十进制数字，超出范围拒绝。标签不存在返回404 not_found，任一连接不存在返回404 reference_not_found，整项失败不修改原关联。

标签名称去首尾空格、最多128 UTF-8字节，导入按同一规范匹配已有标签。每个连接最多64个标签，普通新增/更新、单连接标签替换、导入及批量关联遵守同一限制；导入的已有标签与按名称创建标签合并后也不能超额。DELETE /api/v1/targets/tags/:id 同事务删除标签并解除全部关联。实际改变关联的连接版本各推进一次；已有相同关联不推进版本，标签本身未修改可见字段时不推进其版本。操作后刷新连接列表，已有编辑收到 version_conflict 时重新读取，不覆盖关联变化。

持久写入 operation_unknown 返回503；响应断流也可能已经提交，先只读核对，不自动重试。关联修改使用与其他后端管理操作一致的事务会话复查。正式 Tags/Connections、Workspace 标签组已消费这两个入口；成功或未知关系变更后完整重读连接，不能只刷新标签目录就解除旧窗口的未知围栏。

### 连接导入与测试

工作区连接列表和导入弹窗正常不显示额外刷新按钮；读取失败或写入结果待核对时提供恢复入口。工作区标签读取失败同样可手动重读。

管理员使用 `POST /api/v1/targets/connections/import`，JSON 正文为 `{items}`；也可上传唯一 multipart 文件字段 `connectionsFile`，文件内容为严格 UTF-8 JSON 数组，每项采用 Shared 的 `TargetImportInput`。每项包含 `connection`，可选 `tagNames`、`inlineProxy` 和 `credential`。凭据采用 `password`、引用已有 `ssh_key`，或带名称/正文/可空口令的 `private_key` 创建意图；内联代理可带密码。新格式不接收旧字段或旧密文。正式前端选择文件后先严格 UTF-8 解码并校验，再通过 JSON items 分批提交；后端 multipart connectionsFile 入口继续保留。前端不另设本地文件大小或总条数门槛，每批最多50项并校验协议字节容量；全部分批输入先校验再派发，逐项显示原序回执，遇失败停止后续批次，保留已确认项。导出仅含 connection 配置，不含密码、私钥或凭据；引用使用当前实例 ID，不另设前端导出条数/文件大小门槛，不是跨实例秘密备份。连接列表和导入弹窗不常驻展示这些协议／容量说明，操作失败时仍显示相应提示。

每项的连接、凭据、内联私钥、代理与标签同事务提交；一项失败不会留下部分记录，其他项继续，按原序返回 `items` 的安全结果。文件中非法项返回 `invalid_input`；文件整体无效、超容量或 JSON 请求形状无效则整批拒绝。已有代理先校验持久记录，损坏记录安全拒绝，不作为可复用配置；仅在用户名一致且不携带新密码时复用，新秘密冲突返回 `conflict`，不覆盖原代理；同名私钥冲突也明确拒绝。导入中途失去身份/权限会停止后续项并返回401/403，已经提交的项不撤销；最后一项等待期间超时也不再返回整批成功。导入不是幂等操作，`operation_unknown`、会话过期、超时或响应中断可能已有部分提交，先查询核对，不自动重传。操作观察复用 Operations；观察事件不替代逐项提交回执。

`POST /api/v1/targets/connections/:id/test` 测试已保存 SSH 连接，`POST /api/v1/targets/connections/test-unsaved` 接收 host/port/username、authentication 和明确 direct/proxy/jump 路由及引用。未保存测试支持密码（允许空字符串）、已有 SSH Key 或直接私钥，不创建数据库连接。仅进行 SSH 握手，不开启命令、PTY 或 SFTP；所有跳板与目标须通过 Host Key 信任。连接列表及新建/编辑窗口点击测试后，未信任或密钥变更会显示现有指纹确认框，独立核实后确认信任即可继续测试，无需先打开终端；取消不保存信任、不继续测试、不显示本次成功结果。多跳逐个确认各主机，同一端点再次拒绝时停止，不循环确认；离开页面、关闭表单或身份失效后不继续旧测试。成功返回 `{status:'ok',latencyMs}`，且本地传输已关闭；失败返回有限安全错误码，`host_key_untrusted` 必须带本次握手的 `hostKey`（host、port、fingerprint、expectedFingerprint），不回传供应商错误正文。最多8个在途，每次请求期限15秒，确认等待不保留SSH连接；取消后仍等待真实资源收敛，清理失败阻断新的测试并在停机汇总。SSH 测试审计复用 `SSH_CONNECT_SUCCESS/FAILURE`。新建及编辑窗口输入新密码或选择密钥后，测试捕获开始时的当前连接及认证草稿，不保存连接或凭据。编辑时密码留空且连接地址、用户名和路由未改动，使用已保存凭据测试；这些连接字段改动时，先输入密码再测试；未输入时通过右侧 Toast 提醒，不发送测试请求，避免实际测试旧连接。输入变动后清除旧测试结果；测试成功仍需确认保存。

## SSH 会话

挂起目录的时间文字使用清晰的次级文字色，不叠加额外透明度。

支持多标签、挂起、续接和布局定制；普通 Workspace 与 Agent SSH 分别授权和管理。打开第二个 SSH 或切换标签时只显示选中会话的终端画面，后台会话继续保留连接与输出。切换到其他页面再返回时保留原终端、命令草稿和已加载布局，不重新创建终端；退出登录或切换用户时清除这些缓存。离开工作区后，已发起的SSH连接继续由原标签管理，但尚未派发的批量/查询打开和挂起接管确认失效；返回页面不会继续旧确认或旧查询的连接动作。

终端输入立即发送并使用远端PTY真实回显；SSH直连、跳板及HTTP/SOCKS代理底层TCP关闭小包合并，减少逐字符输入的额外等待。输入仍逐次校验会话及当前控制权，不缓存授权。实际回显速度仍受浏览器到后端、后端到SSH服务器的往返延迟与远端程序影响。

关闭 SSH 时先请求正常结束；对端只完成半关闭时会强制关闭本次连接的实际传输流，再等待关闭确认。无法确认时仍提示清理失败，不据此重发命令或重建会话；直连、代理和跳板使用同一清理规则。

已连接 SSH 标签的右键菜单（移动端长按）依次为“挂起会话”（已标记时为“取消挂起”）、“重置终端”，后续为原关闭操作。远端程序无法退出时，可选择“重置终端”，确认后关闭旧 SSH 会话并在原标签位置建立新终端。重置会清空终端画面和命令草稿，传输与未保存编辑可能受影响；独立后台进程不保证结束。取消确认不执行重置，其他标签的会话与当前选择保留。仅已连接、未标记挂起且无未知结果围栏的会话可重置，已标记挂起的会话需先取消保留。未收到旧会话关闭成功的明确回执时停止重置，不新建第二个会话；提示关闭结果无法确认后，先核对远端任务再关闭旧标签。新连接失败保留其标签及既有错误恢复入口；本功能由用户手动触发，不检测卡死或自动终止任务。

运行 `nethogs` 后输出大量 `Ethernet link detected`、随后长时间没有统计画面时，可先限定实际要监控的网卡，例如 `nethogs enp35s0`；网卡名以目标服务器为准。默认全接口采集在存在大量容器网桥和虚拟网卡的主机上可能很慢，`q` 也可能等待抓包轮次结束才能处理；工具改变 TTY 模式后，Ctrl+C 不一定产生中断信号。退出无响应时，可通过另一条 SSH 连接核对本次进程的 PID，再对该进程发送 SIGTERM，避免批量结束其他人的任务。排查时分别核对远端程序是否继续产生输出、SSH/工作区连接状态和终端消费确认，避免将远端工具停顿直接判断为终端渲染故障。指定网卡只统计对应接口，不代表全部容器网络。

### 挂起与恢复

工作区挂起会话列表随分栏高度自动展开，放大后可显示更多会话；搜索栏保持固定，只有会话内容超过剩余空间时才滚动。起始页摘要与会话弹窗保留原紧凑列表。

- 点击挂起仅标记保留；关闭标签或断线后 Backend 接管原 SSH/PTY，适合长任务。
- 终端标签指示灯在已连接时区分挂起标记：普通会话为绿色，已标记挂起及恢复后仍保留标记的会话为蓝色；取消标记后恢复绿色。连接或重连中为黄色闪烁，断开或失败为红色，未连接为灰色。恢复成功继续保留挂起标记及原有关闭保留行为。
- 有权限的设备可恢复无人使用的会话，或确认接管使用中的会话；不要求原设备的普通续接凭据。接管撤销原设备控制权，不允许双写。后端在挂起 owner 的真实租约到期后立即拒绝继续控制和关联文件传输，不等待清理扫描；独立上传、下载分块及多步骤文件操作也检查原 Workspace 权限。普通断线仍按既有宽限期处理。已经派发的远端效果不能撤回；上传中断可能保留临时文件，清理未确认时报结果未知，先只读核对目标文件，不自动重传。
- 挂起成功返回真实会话 ID；失效或注册失败不报成功。后台标签恢复不切走当前终端；恢复等待期间切换到其它标签，成功或失败都保留当前选择。
- 恢复先按快照原始行列数重建终端，再按恢复窗口尺寸接入实时输出，避免窗口大小变化造成错行或重复提示；相同尺寸不会重复触发远端重绘。快照保留当前屏幕的滚动区域与光标位置，避免TUI重绘中途挂起后，后续输出冲掉底部输入区或队列。恢复先核对历史基线，再独立确认所有权；确认成功才开放输入和Files，不等待SFTP初始化完成。历史先显示不证明恢复完成，未确认输入不自动重发。恢复确认、挂起提交或取消标记结果未知时停止重放，先查看挂起目录核对，不自动取消标记补偿。
- 浏览器从后台或锁屏返回时，先向服务器复验原控制权，不依据过时的本地倒计时直接判定租约失效。续租响应无法确认时停止控制并显示结果未知；服务端明确撤销才提示对应租约原因。原会话在目录变为无人使用后，当前可见工作区自动恢复原PTY，即使目录更新晚于最初的短暂等待；不会自动接管其他设备正在使用的会话，也不会为此新建Shell。
- 已标记标签关闭只脱离连接并保留原PTY；要终止正在使用的终端任务，先成功取消挂起再关闭标签；无人使用的后台挂起可在目录移除并终止。续租失败、租约失效或被接管后立即停止控制；旧设备不能继续写入。
- 在挂起目录移除仍有终端使用的会话时，只取消挂起并移除目录记录，不断开正在使用的 SSH/PTY；即使从另一设备移除，原终端也会同步取消挂起标记，不再留下“待关闭”记录。无人使用的后台挂起会话才会被终止，已断开的记录只删除日志与条目。移除期间正在恢复或所有权不明时先读取最新状态，不自动退回终止操作。
- 单次快照最多4MiB UTF-8，完整挂起JSON最多24MiB+16KiB；历史页最多256KiB。历史页失败不会终止健康终端；游标交付不明时不自动重取，须先回到实时输出重置历史，或重新恢复会话。
- 保留最近 100 MiB 原始历史，先恢复状态和尾部，旧历史按需分页；达到上限仍可恢复原 PTY。
- 登录后通过独立 `/ws/suspended-sessions` 订阅当前用户的挂起目录，不绑定某个 SSH 终端；挂起、恢复/接管、续租、断线、改名、终止和过期会推送完整快照，其它在线设备无需等 HTTP 轮询。首次连接、断线重连及浏览器恢复可见时取得完整快照，离开首页仍同步；隐藏浏览器页面时暂停，恢复可见或从页面缓存返回时重新连接；网络故障时退避重连并保留最后成功列表，短暂恢复失败不立即弹Toast，前台连续10秒未恢复后才提醒，权限拒绝和协议异常仍按原错误处理。目录最多 64 项/1 MiB JSON，WS 完整帧另留 1 KiB envelope；命名、终止、移除和日志使用 HTTP，列表 HTTP 保留给显式核对和操作后的只读确认。命名最多 128 个 UTF-16 单元，完整管理请求/响应最多 4 KiB。日期为 ISO 字符串，租约为 Unix 毫秒。移除结果由 Backend 当时的附着状态决定，不根据浏览器的旧目录状态终止终端。
- 目录恢复以实际连接结果为准，浏览器显示“离线”但站点仍可访问时也会尝试读取；前台连接失败后沿原退避继续恢复，网络切换通知会立即重建目录订阅。首次目录须在原45秒期限内取得，只有心跳而没有列表也会结束本次等待并重试，不一直显示加载。重建只读目录不会接管或终止SSH会话，隐藏页面仍暂停订阅。
- 启动页的挂起会话面板与弹窗使用原有紧凑卡片：序号与名称位于首行，挂起时间和状态徽章同排，恢复、导出和移除在卡片底部均分展示。搜索只筛选当前目录，搜索框占位文字统一为“搜索会话”，无结果显示明确空态。搜索框、卡片列表和空态以“挂起的 SSH 会话”标题图标左缘为共同起点并保持同宽；滚动条槽只占用右侧，不通过额外左侧内边距把内容推离标题图标。窄面板中操作组居中，极窄时收起按钮文字但保留可访问名称；弹窗标题栏固定、正文独立滚动，手机宽度不横向溢出。关闭、隐藏或移除后仍沿用原有取消、确认和目录同步行为。
- 挂起会话空态按两条实际会话卡片预留最小高度（单卡 78px、卡片间距 6px），内容在可用区域内整体居中；面板可用高度略小于两行时贴合容器，不因硬编码余量产生无意义的内部滚动。页面滚动模式仍完整预留两行。
- 写入结果未知时保留目录与操作保护，不自动重发；先点搜索框旁的刷新按钮“读取最新状态并核对”，确认当前状态后再决定操作。后台推送不能解除此保护，较早的刷新也不能解除后来产生的未知结果。目录同步和日志读取失败仅说明读取未成功，不显示写入“操作结果未知”；原列表保留。错误通过常驻可关闭的 Toast 展示，不在面板插入告警横条；已识别网络失败沿全局网络通知去重，真正写入未知仍单独提醒并保留操作保护。隐藏、停用或卸载面板会取消原确认和等待，注销还清除目录及共享订阅。
- 日志导出限 60 秒、128 MiB 渲染后 UTF-8 文本，以服务端会话 ID 命名；此限制与 100 MiB 原始历史窗口不同。超限/断流或媒体类型、文件名无效时不启动浏览器下载，按失败处理。

日志经代理压缩传输时，容量按浏览器解码后的实际正文检查，不把压缩传输长度与解压文本长度直接比较；未编码响应仍核对声明长度，截断和超量不作为成功导出。

### 自动重连

- 手机终端会按底部工具栏上方的实际内容区域自适应行列数；内置虚拟键盘开启或关闭、横竖屏切换及软键盘改变可视高度后，最后一行保持在终端区域内，原有内容边距和工具栏位置保留。
- 异常断线约 120 秒内保留原 SSH/PTY、压缩及复制/移动任务，优先续接并补回输出/结果，不重新 SSH 登录替换终端。
- 切换 Wi-Fi/移动网络或网络暂时不可用后，传输失败按原退避继续自动重连，不因一次失败永久等待按键；离线时暂停，恢复在线后立即尝试。浏览器支持网络变化通知时，即使“在线”状态未变化也会检查存活；健康连接保持原样。已连接会话优先使用原凭据续接同一 SSH/PTY，补回缺失输出，不重发已输入命令或文件写入。
- 回到前台、恢复网络或返回终端时检查存活；正常链路不重连，并发恢复共用一次请求。布局重建等待显示快照期间若原PTY结束，不会把旧PTY画面恢复到新终端。
- 手机切后台及返回前台时都会清理未结束的触摸和临时键盘禁用状态，避免浏览器漏发触摸结束事件后无法输入；返回后立即重新测量并刷新终端，不等待旧动画帧或网络存活检查。输入资格以当前连接是否就绪为准，连接尚未就绪不会提前开放输入。Android 软键盘开关按实际可视高度调整工作区，收起后恢复；恢复过程不主动弹键盘，轻点终端或使用原聚焦入口打开，失败时轻点也可请求原重连，提示同时说明轻点与按键两种方式；失败等待时输入框可聚焦并唤起软键盘，键盘或输入法输入仅触发重连，不会发送到SSH，连接中仍禁用输入。后台冻结或网络断开仍可能需要续接，不保证浏览器持续维持连接。
- 普通续接校验原标签凭据、用户、Workspace 和连接；新标签不可接管旧 Workspace。后端注销会撤销原 Cookie，现有终端在周期身份复查（约15秒一次）时断开；原 PTY 仍按宽限期/挂起策略保留，并非立即终止远端任务。同用户重新登录后须持原续接凭据并显式确认，文件资源按新登录重新授权；终止任务请主动关闭会话。
- 待挂起标签自动恢复无人使用的会话，不抢占其他设备或关闭后来打开的启动页。页面被回收后通过挂起目录恢复；未标记会话超出窗口不保证保留。
- 主动关闭通过当前附件请求释放；收到确认才表示关闭成功。断连只表示本地脱离，关闭响应丢失仍为结果未知，不能保证原远端进程停止。远端退出或宽限期结束无法恢复。普通断线时可按终端/命令栏 Enter，或再次点击同一连接提前尝试。
- SSH 登录、主机信任、权限或目标失效等明确失败保留原标签和终端内原因，继续使用原按键/轻点重试入口，不因失败自动关闭标签或重复弹出页面错误。结果未知仍保留原恢复保护，不允许按键重复创建。
- 普通恢复先接收回放，再独立确认所有权，确认后才开放输入和调整终端尺寸。准备续接时旧附件仍占用或服务暂不可用，继续用原凭据等待重试；确认尚未发出即可安全重试准备，但确认已发送而回执丢失仍保留结果未知保护。新建或所有权确认结果未知时停止自动和手动重放，终端显示恢复提示；关闭原标签后可新建连接，但新建连接不会终止原远端进程。

### 会话容量与关闭

| 范围           | 限制                                                             |
| -------------- | ---------------------------------------------------------------- |
| 普通 Workspace | 单 Backend 64 个，包含建连预留及弱网续接；已有会话续接不重复占槽 |
| 挂起 Registry  | 每用户 32、全进程 64，包含附着/断开记录                          |
| 连续挂起       | 24 小时后终止；已恢复不按旧时间终止，再挂起重新计时              |

满载拒绝新建/恢复；Server Transfer/Suspend 的独立预算不计入普通 Workspace 上限。Backend reset/shutdown 清理挂起日志，启动清理无 owner 遗留日志，不提供跨重启挂起恢复。

跳板总期限覆盖握手/forwarding，取消后关闭已建资源，晚到 channel 不发布。远端断线回收会话，旧关闭事件不误关新 owner。命令仅零退出码且无 exit signal 算成功；关闭但缺退出状态属于未知结果，不自动重放，也不证明远端进程停止。

## 快捷命令协议与恢复

登录后通过 `/api/v1/quick-commands` 与 `/api/v1/quick-command-tags` 管理当前用户数据。命令保留变量、标签和使用次数；新增/编辑/删除/计数、标签 CRUD 与批量关联已安装，记录数据不执行 Shell。列表使用 offset/limit，命令每页最多50项，按名称或usageCount排序；标签按名称排序。命令和标签不设固定总条数上限，按分页读取；每命令50标签、32变量；命令16 KiB、名称256 bytes、变量值4 KiB、变量名为最多64字符的标识符且拒绝原型保留键。完整请求1 MiB、响应64 MiB，包含JSON转义。

快捷命令分组标题使用主题强调色及轻量底色，命令名称保持高对比；折叠、悬停、选中与编辑操作不变。

标签名称去首尾空白后保存，同用户规范名称冲突返回409；命令/标签的更新时间由实际写事务生成且不倒退。修改/删除/计数带 expectedVersion；批量关联为 `{commands:[{id,expectedVersion}],tagId}`，最多1,000项且不重复，全部检查后同事务写入，已有关联不增加计数。表单中单独删除标签会移除关联并推进受影响命令版本。标签栏删除组使用 `DELETE /api/v1/quick-command-tags/:id/group`，请求为标签 `expectedVersion` 及全组 `commands:[{id,expectedVersion}]`，成员数量按完整请求 1 MiB 编码预算准入；同一事务核对标签、完整成员和指令版本后删除组及指令，不使用批量关联的 1,000 项限制。未标记组使用 `DELETE /api/v1/quick-commands/untagged-group`，请求仅为 `{commands:[{id,expectedVersion}]}`，同样按完整请求编码预算准入，成员必须与事务内全部未关联任何标签的指令完全一致。缺记录404、名称或版本冲突409，组删除冲突时无部分副作用。成功分别返回command/tag、deleted或实际新增count；unknown不自动重放，先只读核对。正式Workspace面板按Shared协议读取完整分页；编辑和确认保留原版本。标签目录读取失败时，已成功读取的命令仍可执行，以未分组方式显示；错误明确保留，管理写入与使用计数暂停，点击错误 Toast 的“刷新”成功重读两份目录后恢复。遇到冲突或未知结果，先关闭编辑窗口，使用错误 Toast 的“刷新”只读重读，再重新编辑，不自动重放。页面停用、弹窗关闭或认证撤销后，原确认不再派发；已接纳请求仍由原Store追踪。

## 历史命令

截断命令可悬停查看全文；历史时间使用清晰的次级文字色，不额外降低透明度。

### 命令与路径历史

- 最近命令 10,000 条、路径 2,000 条；新增/复用时同事务裁剪，同秒优先保留本次触及记录。
- 并发写入按值合并，旧重复保留最小 ID 并更新时间。旧超额备份可导入，读取只展示窗口，下次写入再清理。

### 个人历史与收藏协议

- 命令历史与路径历史保留原 `/api/v1/command-history`、`/api/v1/path-history` 的 GET/POST/DELETE 方法；仅当前用户可读写。POST分别为 `{command}` / `{path}`，按原值去重并更新时间；10,000命令/2,000路径同事务修剪，同秒保留本次记录；记录时间在实际写事务中生成，时钟回退不使本次记录被当成旧项裁剪。单条4 KiB、请求32 KiB；GET用offset/limit（默认100、最多100）返回entries/nextOffset，按时间/ID升序，完整响应4 MiB。新增返回id，删除返回deleted，清空返回count；不执行命令。分页不是跨请求快照，写入/清空后从首页刷新。生产者仍是前端HTTP，后端Workspace不自动记录。
- 在文件管理器打开收藏并新增时，路径默认填入当前浏览目录，可继续编辑；取消后重新新增会重新读取当前目录，不沿用上次草稿。编辑已有收藏仍读取该收藏保存的路径。
- `/api/v1/favorite-paths` 保留收藏 CRUD、`PUT /:id/update-last-used` 及按name/lastUsedAt排序。列表默认100、每页最多100，返回entries/nextOffset；不设固定收藏总条数上限，名称可null（256 bytes）、路径4 KiB，请求32 KiB/响应4 MiB。编辑/删除/更新时间都必填expectedVersion；修改返回favoritePath，删除返回deleted。其他用户记录视为not_found，版本冲突重新读取，unknown仅核对、不自动重放。写入时间由实际事务生成，编辑及使用时间不会因排队或系统时钟回退而倒退。正式Files收藏与路径历史、命令历史面板直接消费Shared分页和有限回执。收藏冲突或结果未知时，关闭并重新打开收藏列表以只读核对，再重新编辑；路径历史写入未知先重新打开列表核对；命令历史写入未知时提示无法确认保存，可点错误通知的“刷新”只读核对。下一次新的命令历史保存、删除或清空会先读取服务器列表，成功后才执行本次新操作；读取失败不派发本次写入，后续再操作会重新核对。普通重新读取成功也能恢复保存，不自动重复未知写入或终端命令。认证撤销清空本地个人数据与草稿。

## 终端

从首页或连接列表进入工作区时，连接与工作区布局读取并行启动，终端按保存的布局就绪后显示，连接完成前仍禁用输入。SSH 优先使用所配置的密码或私钥，减少认证探测等待；主机密钥信任仍需按原流程确认。实际速度仍受网络、跳板和服务器登录脚本影响。

后端每 25 秒通过 WebSocket 标准 Ping/Pong 保活，减少空闲连接被反向代理超时断开的情况；浏览器自动响应，无需页面定时器。保活不续期挂起会话或授权，也不能阻止系统休眠、网络断开造成的重连。

终端连续输入按原顺序合并发送到原 SSH 附件，文件操作繁忙时不会因共用 RPC 名额而截断按键；仍遵守现有输入字节预算。断线、关闭或附件更换后不重放旧输入，明确拒绝时沿原提示处理。

终端翻页与连续重绘在没有待确认预测时，直接交给终端自身按顺序解析；有待校正输入时仍保留预测与真实输出的同步。滚轮或双指连续缩放将同一帧内的变化合并为最终字号；已有缩放步进、上下限及最新字号保存规则保持，尺寸相同不重复触发远端调整，切换主题不再额外测量行列。实际响应仍受浏览器渲染、历史长度和远端程序影响。

后台会话输出合并处理，等待上一批解析后再继续提交，以减少多个 SSH 同时刷屏的竞争；输出不丢弃、不重排，切回前台与关闭前仍刷新待处理内容，消费确认保持在解析完成之后。

- 点连接立即显示等待页，连接中禁用输入，成功启用；建连失败后终端用红字输出失败原因，空一行显示“按任意键重新连接”，保持等待而不后台重复建连。聚焦终端按非修饰键触发一次重试，该按键不会发送到远端；拒绝主机信任仍需重新确认，所有权结果未知仍只能按原恢复提示处理，不因按键绕过。`＋` 打开连接/挂起启动页，不停止已有会话，后台连接完成不关闭后来打开的启动页。
- 启动页桌面为连接双栏、挂起 SSH 会话右栏，外层框与终端标签栏同宽衔接；小于 1024px 时挂起会话移到连接下方，页面纵向滚动且连接在前。连接项第二行显示地址与最近连接时间，类型徽标固定右对齐；分组与批量管理入口常显。
- 连接后的工作区只由外层工作区框和分栏分隔线划分，不再为每个分栏重复描边。终端分栏显示连接名、用户名与地址及连接状态，底部显示状态、协议和终端尺寸；高度不足 280px 的分栏自动隐藏这两条信息栏，避免挤压终端。
- `Ctrl + Shift + C/V` 复制/粘贴；桌面有选区右键复制，无选区右键粘贴。接管鼠标的程序保留自身右键，Shift 拖选/右键可执行本地操作。
- OSC 52 只允许当前聚焦且可输入的终端，在用户按键/松开鼠标后 2 秒内写入有效 UTF-8 文本，Base64 最多 1 MiB；不读取本机剪贴板。需浏览器写入许可及 HTTPS/localhost。
- 示例：OpenCode v2.0.18 `Ctrl+X` 后 `Y`，Codex CLI 0.159.2 `Ctrl+O`；实际以应用键位为准。Shift 选区只复制终端缓冲，不拼接应用翻页。
- 移动端双指缩放字体；键盘已打开时，普通点按终端保持输入焦点，不反复收起再弹出，htop等应用的点击仍发送鼠标事件。长按复制不反复唤起软键盘，Copy 后不强制聚焦，普通点按/Paste 恢复输入；键盘关闭时滚动不唤起输入。触摸能力按设备判断，拖动不交给外层页面；选区清除后尺寸变化不复活选区。
- 小键盘固定 Esc/Fn/Shift、Tab/Ctrl/Alt；Shift 为修饰键，↑ 为方向键，Fn 切换 F1–F12。

| ---------------------- | ------------------ |
| 单次终端输入           | 256 KiB            |
| SSH 浏览器发送缓冲     | 1 MiB              |
| 文件二进制累计读取     | 本次请求的读取预算 |
| 终端历史单次二进制响应 | 256 KiB            |

未连接/超量/背压时拒绝并提示，不重发输入；读取超限取消并释放缓冲。输出解析过慢暂停发送，解析后继续，不丢中间输出；历史恢复暂停与网络背压分别解除。

Workspace收到畸形JSON/二进制帧、重复响应元数据或终帧后的额外数据，会中止当前传输并结束等待，不交付不完整内容。断开不证明远端写入已回滚；先核对远端结果，不自动重放操作。

- 前台输出直接解析，后台按 80ms 或 512 KiB 合并；重绘使用动画帧及每批一次 100ms 兜底，DEC 2026 完整画面结束时提交，Codex CLI 等程序的计时随收到的输出更新，无需点击触发。浏览器冻结不触发自动重发。
- 恢复实时画面不等待历史游标重置；新翻页等待重置，旧页面不能覆盖新画面。旧历史写入后按更新后的滚动范围定位，避免跳回尾部；命令栏成功发送命令后回到实时输出，多会话发送对各个成功目标分别恢复。
- 重连、前台恢复和字体加载后同步尺寸；隐藏时保留最近有效尺寸，恢复按可见区域测量。
- 弱网输入采用 VS Code TypeAhead 预测：积累回显样本后，在延迟较高且匹配有效时，常见英文字符、退格和左右移动可先显示，再由真实远端输出确认或校正。新输入行首字符等待确认；中文、粘贴及不支持的控制模式继续等待远端回显。复杂全屏应用按缓冲区、光标和滚动区域保守停用，不能保证所有 TUI 都能预测。快速输入接近行尾时保留已显示内容，分包的颜色/光标控制信息不会单独撤回输入；同一行尾的连续输入与退格可衔接本地显示，晚到的输入回显不会重新画出已删除的字符；网络抖动期间保留已显示的待确认编辑，收到不同回显时再校正。跨行、提示符边界或远端重绘仍以真实回显为准。输入只发送一次，断线、后台、尺寸变化及保存快照前撤回未确认内容，不写入历史或挂起快照；无需远端安装额外服务。

HTML终端背景在同页会话切换时保留实例；离开Workspace后，重新进入时在可见尺寸下重载沙箱文档，避免只初始化一次的主题以零尺寸启动。

## 文件管理器与在线编辑

复制覆盖普通文件时，即使大小与修改时间相同，也会传输当前内容。移动仅在目标确认后删除来源；失败、取消或结果未知仍须先核对，不自动重试。相同连接或受信服务器密钥相同的不同连接，会在写入前检查规范路径重叠；跨连接原地复制/移动明确拒绝，同连接原地移动保持不变。此检查不创建额外探测文件，但不能覆盖不同主机密钥、共享存储或挂载别名的全部情况；不要将其当作远端路径的原子隔离。

- SFTP 浏览支持自然数字排序，目录始终在前，同列相等按名称排序；刷新/搜索替换远端快照，不用本地 metadata 冒充操作成功。已有目录在刷新期间保持可操作，工具栏与列表中央显示读取状态，保留列表交互；读取期间暂停“切换终端到当前目录”，等待新目录确认后再操作，避免上传完成触发的刷新打断目录点击；首次读取仍显示加载画面。
- `↑/↓` 选择搜索结果，`Ctrl/Shift` 多选；右键复制、剪切、粘贴、删除、重命名、权限修改；内部拖动移动，外部拖入文件/目录上传。
- 桌面拖动选中的文件/文件夹，在目标文件夹或 `..` 上一级行停留约 0.6 秒会自动进入，可连续进入多级目录；原拖动内容保持不变，松手到目标目录行或当前目录空白处才移动。返回原目录的文件夹行或 `..` 即使无需实际移动也显示可进入的拖动提示，原位松手不会发起移动。拖动中按鼠标右键取消并清空选择，保留当前浏览目录，随后松手不会移动；取消后可重新选择并拖动。支持触屏的电脑使用鼠标右键菜单后，关闭菜单即可立即重新选择文件，不触发触摸长按的点击抑制。不能进入被拖动的目录自身或其子目录。
- 桌面列表选中项后 `Ctrl+V` 上传截图；输入框仍粘贴文字。手机使用可用文件选择器，取消不上传/报错，失败可重新选择；系统菜单由浏览器决定。
- 表格显示名称、权限与修改时间，列宽/行缩放持久化，窄栏按可用宽度依次收起修改时间和权限；宽屏不重复显示列名表头，列宽拖拽热区仍保留。路径历史与收藏弹层受 pane 高度约束，长路径最多两行并单独滚动。
- Monaco 编辑文本，Ctrl+滚轮调整字号时保持鼠标对应的文本位置（文件首尾受可滚动范围约束）；预览 Markdown、图片、PDF、电子表格、DOCX，支持多标签、刷新、宽内容横滚。文本类预览共用 `Ctrl/Cmd+F` 搜索、计数和跳转，电子表格多页时才显示分页。
- 图片预览保留原文件字节，支持 GIF 动画。文件管理器与 Agent 文件库共用“设置 → 工作区 → 文件 → 图片预览大小上限（MiB）”，默认 20 MiB，可填写非负整数，0 表示取消该项大小限制；保存后下一次打开或刷新图片生效，已经打开的图片不会自动重载。大图会增加浏览器内存占用，仍受浏览器和网络资源约束。PDF/DOCX 仍为 20 MiB、Markdown 2 MiB、电子表格 10 MiB、数据库 64 MiB。
- 编辑器顶部只保留标签和文件路径，编码、换行、搜索、刷新、保存、保存状态与关闭统一位于内容下方工具栏。底部工具栏沿用当前主题的玻璃表面、边框和基础按钮；空间不足时先换行再压缩，不产生横向溢出。编码下拉展开为独立宽度，完整显示 `Windows-1252`、`ISO-8859-15` 等长名称，选中项和选项文字居中。
- 文本保存期间，涉及在存文档的标签关闭、右键批量关闭及编辑器关闭暂不可用；收到保存回执后恢复。磁盘已出现新内容不代表保存回执及清理已完成，失败保留草稿。
- 文本编码识别先按连续原始字节校验 UTF-8，再对其他编码使用有界样本检测；大文件的分段采样边界不会把合法的中文或表情拆断后误判为其他编码。
- 上传/复制移动/归档/跨会话传输进入 Progress Display，可隐藏/恢复/取消/移除记录。浮窗不透明，默认 360×190px、最小 280×130px，保存位置/尺寸且不超视口；显示文件、状态、数量/字节、速度与错误，多任务窗内滚动；后台服务器传输按创建时间排序显示全部已读取任务，不只取前5项；状态列表继续读取全部服务端分页，不另设前端累计160项门槛。
- 顶部路径栏保持单行，路径文字与左侧文件夹图标垂直居中对齐，依次提供路径输入、名称排序切换、收藏、路径历史与工具区；终端、同步、刷新、搜索、编辑器、上传、新建和多选始终直接显示，工具区与路径栏同宽、保持 4px 列距，不使用“更多”收纳，宽屏工具按钮等分铺满。工具按钮采用 28px 紧凑控制尺寸；每枚按钮使用低对比 1px 细边框，工具组不绘制整体外框、底纹或内层卡片。空间足够时单行排列，窄于所需宽度时固定四列，八按钮在 1×8 与 2×4 之间直接切换，不停在 5+3、6+2 或 7+1；关闭编辑器入口或增加触控多选时按实际七/九按钮数量判断单行宽度。桌面浮窗最小宽度约 170px，浮窗及分栏拖动连续跟随指针，不在换行附近吸附或松手后跳变；最小/最大宽度仍生效。文件列表只按名称排序，路径栏内的名称排序图标单次点击切换升序/降序并同步更新 A↔Z 图标，使用动态可访问名称与悬停提示，不占用独立排序行。搜索独占第二行并自动聚焦，`Esc` 或关闭按钮退出。分栏边界保留 1px 视觉线，横向和纵向拖拽热区均限制为 9px（两侧各约 4px），减少对终端边缘文字选择的遮挡。
- 新建文件夹、创建文件、重命名和权限修改统一使用标准对话框：标题栏、图标、关闭、字段标签和底部操作区均由基础组件提供。桌面输入与操作按钮使用 36px 的舒适密度，手机使用 44px 触控高度；弹窗桌面最大宽度 448px，手机左右各留 8px，取消与确认按钮等宽，不产生横向溢出。
- 返回上级目录的 `..` 行使用更紧凑的上下留白，文字与返回图标垂直居中；仍支持点击、键盘、父目录预加载、右键与拖入。桌面文件可从文件名或行内起拖，已选中文件及未选中文件均支持，不按后缀或文件大小禁用；点击后仍把键盘焦点交回列表，Ctrl/Shift 多选、方向键、Enter 和右键菜单保持原操作。文件行使用悬停与选中背景、选中项左侧细主色线标识，并以极淡横线区分行与表头；空目录、无搜索结果、读取中、错误和外部文件拖入使用居中的独立状态。窄面板、手机工具与路径历史只在自身区域滚动，不产生页面级横向溢出。大量文件或深目录建议先压缩再上传。

- 普通文本编辑聚焦正文后使用 `Ctrl/Cmd+F`，或点击底部搜索按钮，打开编辑器原生查找。桌面 Monaco 使用 VS Code 风格的右上角查找框，保留匹配计数、大小写、全词、正则及替换入口；手机使用 CodeMirror 自带搜索面板。`Enter/Shift+Enter` 或原生上一项/下一项操作切换匹配，`Esc` 关闭。查找本身不修改正文；替换只修改本地草稿，仍需保存才写入远端。图片及 PDF、表格、Markdown 等文件预览继续使用各自现有交互。

### 远端依赖安装

压缩和解压开始前会检查实际需要的远端工具。工具齐全直接继续；缺失时显示服务器、所需工具和包管理器，确认“安装并继续”后才修改远端系统，取消不会派发原归档任务。安装可按需输入提权密码。跨服务器复制粘贴和“发送到服务器”也复用该检查和安装流程：自动方式先检查源端及目标端的 rsync，缺失时确认安装；选择“暂不安装”后，普通文件继续检查 SCP，缺失时再次确认安装，再跳过则使用 SFTP 中转。传输会按当前登录用户、服务器和工具，在本浏览器记住“暂不安装”，刷新后仍保留；再次复制、移动或发送时不重复询问已跳过的缺失工具，继续使用可用的回退工具。每次仍检查工具实际可用性，后来已安装的工具可直接使用，不锁定上次工具。传输进度显示实际使用的 rsync、scp 或 sftp，未开始选择工具时不预先标注；后台多目标使用不同工具时在各子任务详情查看。目标经代理或跳板时直接中转，不提示安装直传工具。普通SFTP上传、下载不依赖系统软件。

多目标发送检查时，若服务器明确拒绝网络连接或网络不可达，仍可创建后台任务，由任务记录各目标的实际结果，其它可用目标继续传输；这不表示离线服务器已通过工具检查，也不会自动安装或重试。主机不受信任、权限拒绝、其它检查失败、安装失败或结果未知仍停止本次发送，传输选择“暂不安装”可继续尝试其它方式；离页、注销或源/目标会话失效则停止准备，不派发原任务。压缩/解压取消安装仍停止原操作，不使用此延后处理。

归档依赖按操作及格式检查，前后端使用同一份清单；后端一次只读检查全部依赖，早于压缩写入或解压快照。缺失或不满足既有 GNU 能力要求时先提示安装，不到开始写文件后才报告笼统失败。未通过安装后的再次核验、提权认证失败、没有包管理器或安装权限时，不派发原操作；提示手动安装后重新发起。

| 操作                 | 依赖                                            |
| -------------------- | ----------------------------------------------- |
| ZIP 压缩             | zip、unzip；unzip用于非零退出时的独立归档核验。 |
| tar.gz／tar.bz2 压缩 | GNU tar及gzip／bzip2。                          |
| ZIP 解压             | unzip、zipinfo、od、grep、GNU cp、GNU ln。      |
| tar.gz／tar.bz2 解压 | GNU tar、gzip／bzip2、GNU cp、GNU ln、od。      |

支持 apt-get、dnf、yum、apk、zypper 和 pacman，使用服务器已配置的软件源和固定包名；不会添加第三方源，也不接受自定义安装命令。归档检测 ZIP、GNU tar、gzip/bzip2 及解压所需的 zipinfo、coreutils 等依赖。root 直接安装，非 root 优先免密 sudo，否则在同一确认框输入 sudo 密码；密码只用于本次 SSH 标准输入，不保存、不进入命令参数。要求终端认证、MFA、su/doas 或没有可用 sudo 的服务器需手动安装。

安装最长等待三分钟，确认计划五分钟有效，绑定当前登录及目标配置；安装结束仍重新检查工具，确认可用后才继续原操作。安装期间不能再次确认或手动关闭弹窗；离页、注销和网络中断取消本地等待，但不能保证远端包管理器停止。结果未知时不会自动重装或重放原文件操作；先在服务器确认安装及相关进程状态，必要时通过设置中的“机器突变恢复”处理工具安装围栏。安装与其他受管远端写入按服务器互斥，冲突时稍后重新发起。失败使用统一 Toast，不插入终端布局。

依赖安装使用持久机器突变来源及恢复证据，数据结构随所属版本交付。后续数据库升级见 [数据库迁移](DEPLOYMENT.md#数据库迁移从下一版本起)。

跨服务器粘贴与“发送到服务器”的凭据安全确认支持勾选“下次不再提醒”。只有勾选并确认继续才保存；取消、关闭或会话失效不保存。在当前浏览器中按登录用户记忆，两个入口共用；清除本站浏览器数据后恢复提醒。此选择仅关闭提示，不改变直传凭据交付方式、工具检测、权限核对或传输失败处理。

### 上传、下载与搜索

- 刚发起SSH连接、等待主机密钥确认或重连期间，内嵌和浮窗文件管理器均显示小型“正在连接”加载行，不提前显示“文件会话尚未就绪”等错误；连接成功后显示紧凑目录读取提示。拒绝主机信任、取消、未连接或断开后停止转圈，面板内容留白，不重复显示连接错误，具体连接失败及任意键重试提示只在终端输出。未连接或连接等待时暂停文件操作，已连接后的权限、目录读取及Files服务真实错误仍保留原安全提示。重新连接仍按原规则确认主机指纹。
- 目录浏览使用当前 SSH 会话自己的内存快照，5 分钟内返回已访问目录直接展示，不重复等待远端列表；过期后再次进入目录重新读取，当前目录不自动轮询。缓存最多 20 个目录、合计 20,000 项及约 8 MiB 估算数据，按最近使用淘汰；超限目录仍可正常读取和显示，但不进入缓存，不缓存文件正文或跨会话共享。
- 鼠标停留在普通目录行或“..”上级目录行、或键盘定位这些目录约 20ms 后，提前读取对应目录；同时最多一个预读，只保留最新候选，不递归扫描或跟随符号链接。点击同一目录复用在途读取，快速切换不会因前端已有8个读取而直接拒绝，“..”返回同样使用缓存和预读结果，根目录不预读自身。预读本身不转圈、不切换当前列表；离开目录行、停用或关闭面板停止尚未派发的预读。未缓存的读取超过约 150ms 才显示转圈，避免快速切换闪烁。
- 刷新/F5 始终绕过并清理缓存；新建、删除、改名、权限修改、编辑器保存及传输变更使旧目录缓存失效，结果未知也不复用旧快照。断线/文件资源不可用清理缓存与目录展示，恢复后重新读取。其他终端或外部程序的改动不实时推送，需刷新立即查看，或在缓存过期后重新进入目录；缓存不是文件操作授权，操作仍由后端验证。

离开Workspace、切换标签或退出登录会取消原删除确认、文件选择和剪贴板上传意图，清除归档密码；晚返回不得在新视图派发上传或重新打开密码框。已接纳的传输仍由原任务跟踪，离页不证明远端操作停止。删除确认和提交期间重复触发不会再次派发。

文件通道报告不可用后，此前已派发的只读结果不再交付；即使随后恢复 ready，也必须重新读取当前文件会话，不让旧读取覆盖恢复后的内容。已派发写入仍保留真实回执或结果未知，不因通道失败推断写入回滚。

读取期间文件会话被替换或断开时，失效读取保持“未连接”分类，不误报为响应格式异常；真正的响应解码或路径关联失败仍按协议错误处理。

| 范围               | 限制                                                       |
| ------------------ | ---------------------------------------------------------- |
| Workspace 文件操作 | 准备/上传/复制移动/归档不按任务数拒绝；控制 WS 64 个请求   |
| 上传目录 batch     | 准备完成起30分钟，过期后须显式重新选择上传                 |
| 活跃上传           | 5 分钟无有效块或写入无法收敛则失败并清理临时文件           |
| GET/ZIP 下载       | 不按全局下载数量拒绝，按流背压；HEAD 不打开流              |
| 下载预读           | 每流 16 KiB × 最多 64 块，约 1 MiB；按顺序输出，支持 Range |
| 递归搜索           | 8 个并行目录、最多返回500个结果，不限制扫描目录总数        |
| 上传目录准备       | 后端先完整校验计划，再逐项准备，全部成功后才上传文件       |

- 正式Workspace下载已接Shared：文件取得同源短期票据，目录直接流式ZIP；票据初始有效期300秒，完整JSON请求/响应最多32KiB。离开/停用文件面板或原附件断开后，晚到票据不再触发下载；浏览器接管后的保存进度不由页面确认，取消页面等待不证明浏览器下载停止。
- 正式上传已接Shared：原附件控制通道确认start和ready后，打开独立字节WS，单块最多1MiB；零字节直接等待完成。保留分块顺序、声明大小和完整终态校验，使用临时文件；发送进度100%不代表发布成功。取消请求受理后仍等待终态，未确认结果显示“结果未知”并保留记录；断线后不自动prepare/start重传，先只读核对远端文件及清理状态，再由用户决定新的上传意图。队列或目录准备期间尚未派发的文件可本地取消，已创建的准备目录不回滚。下载名额等待真实读取收敛后归还，HTTP 断开不提前释放；不承诺带宽/公平分配。

目标未进入 commit 且专属 SFTP stage 仍健康时，取消上传、字节 WebSocket 中断或 `upload.abort` 会先停止接纳新块、等待已派发 WRITE 回执，再确认关闭和删除私有暂存文件。取消请求只返回受理，不等待同组其他文件；终态仍等待整组围栏结算。清理期间重复取消、字节通道关闭、Workspace关闭及后端停止准入共用原任务收尾，不中断正在排空的 SFTP 租约，也不改变最初取消或断线的结果分类。客户端断线结果仍为 `operation_unknown`，只有技术收尾明确确认才能释放内部资源；已进入 commit 或清理失败时仍保持未知围栏，绝不自动重发上传。当前修复仍待远程 Actions 验证。

同一 Workspace、同一目录中不同目标文件的上传可并行，最多16项；父目录检查/创建串行，文件各自使用独立暂存与SFTP连接。同名目标、不同目录及其他写操作按队列执行；其他 Workspace 或 Agent 仍受整机持久围栏保护。上传组全部传输与清理收敛、围栏结算后才交付各文件终态；任一未知结果保留整组围栏，不自动重传。此并发修正待远程 Actions 验证。

- 取消上传时，字节连接提前关闭不代表清理失败；界面等待原控制请求及终态事件确认。控制链断开、取消失败或后端报告未知仍保留结果未知，不自动重传。
- Workspace目录列表完整JSON响应最多8MiB，与入站控制消息预算分开；合法的大目录列表使用该发送预算，不受普通WS默认1MiB发送缓存限制。不设置目录项数量门槛；超过完整响应字节容量时明确拒绝，不截断列表。
- 搜索超限标记截断；根目录失败报错，子目录无权限或已删除时跳过并标记结果不完整，继续搜索其余目录；连接、取消及容量失败仍报错，不伪装完整结果。不跟随目录链接，不承诺遍历顺序。
- 目录准备失败停止新任务并等待已启动任务，可能留下空目录，不递归回滚；仅明确目录类型冲突可释放变更租约，其他未知结果保留隔离。隐式父目录不自动成为授权上传目标。
- 重复二进制 requestId 拒绝，不接管原读取；原请求仍可取消。

上传、复制或归档完成触发列表刷新时，保留用户正在切换的目标目录；不因后台完成返回上一个目录。目录读取失败仍保留最后确认的列表并显示失败。

### 编辑、预览与失败恢复

- Workspace 文件资源随原 SSH 会话管理，不因两分钟没有文件操作而失效；独立 HTTP 文件资源仍保留两分钟闲置限制。会话、目标配置或权限失效时仍拒绝操作。
- 手机普通文本编辑器的查找面板使用深色紧凑布局，查找与导航、匹配选项、替换分别排列，随应用语言切换；支持原生大小写、正则、全词、全部选择及替换。替换只修改草稿，仍须主动保存。
- 手机及窄栏编辑器底栏最多两行：第一行显示路径和服务器名，长路径优先保留文件名并省略目录，保存状态位于右侧；第二行固定编码、换行符、查找、刷新和保存。编码使用剩余宽度，换行符完整显示 LF/CRLF/CR，避免控件互相遮挡；宽屏保持单行。
- HTML/HTM 与其他普通文本使用在线编辑器打开；文件读取失败在当前操作提示具体原因，保留工作区和已打开文档，不用整个工作区的“发生错误”页面替代读取失败。
- 预览/编辑的二进制读取、下载票据准备、下载类型探测和目录 ZIP 各自使用原 Workspace 跟踪的独立 SFTP 资源。取消预览、停止目录下载或离开页面时，只收尾对应读取资源；后续目录浏览、编辑和下载继续使用原文件会话。读取任务及资源关闭实际完成后才结束，不把浏览器中断视为远端已释放。
- 错误提示区分权限不足、文件/活动文件会话不存在、连接配置变化、远端不可用、冲突及登录失效。读取失败可先刷新目录；活动文件会话已经失效时重新连接 SSH。写入结果未知时仍须先核对远端状态，不自动重试写入。

- 文本打开/重载/换编码最多 16 MiB，Large File Mode 不突破容量；预览每 socket 4 个读取，按每次请求的预算检查文件声明大小和实际接收字节，不另设固定 64 MiB 总量上限。`maxBytes` 必须正安全整数；关闭预览取消读取，不保证远端即时终止。
- 保存先写同目录临时文件再 replace，保留编码/mode，失败不先截断原文件；原子性取决于远端 replace/rename 支持，断链后须核对实际文件。正式Workspace的保存/新建请求包含JSON转义与外壳后须在1MiB控制预算内，打开文本的16MiB上限不等于可保存大小；超限在派发前拒绝。
- 重命名/删除失效旧路径及后代文档，草稿保留但旧标签不可保存；保存中阻止该文件操作。操作失败须检查实际路径后重新打开。
- 关闭文档/批量标签/弹窗确认丢弃草稿，保存中不可关闭；强制断连保留可复制草稿但不能保存。草稿不跨网页刷新；注销或会话替换会清空编辑与预览，不向后来登录保留草稿。重新加载/切换编码期间继续编辑会使旧读取失效，旧结果不覆盖新内容；旧打开请求不插入已失效标签。
- 批量删除/解压可部分成功，无逐项删除结果清单；失败刷新核对，未知结果不自动重试。新建/保存/重命名/权限修改丢失回执或回执无效时也提示结果未知，先只读刷新实际文件再决定下一操作。双文件管理器属实验功能，多编辑器布局未完整支持。
- 失败/取消等待并行写入和句柄收敛后清理。归档须远端退出码/exit signal 才确认结束；仅 channel 关闭或清理结果不明返回 `OPERATION_OUTCOME_UNKNOWN`，隔离资源，不推定回滚或 writer 停止。

PDF 缩放或容器宽度变化后的异步页定位保留当前横向滚动位置，不覆盖等待渲染期间已经拖动的横向滚动；主动跳页仍按原流程定位。

### 复制、移动与归档

- 复制、移动与跨服务器传输进度行明确标注“总进度”，标题保留本次任务的源项名称；当前文件单独显示。进度条和已传输/总大小均为整个任务的累计值，切换文件不会重置；已知总项数时同时显示已完成项数。含目录且总量未知时不额外扫描或编造总大小。

- 归档在准备阶段取消也只收尾自身资源，工作区文件浏览可继续；取消后的目录刷新仍读取真实远端状态，不把进度行消失当作远端完成。
- 正式Workspace复制/移动/归档已接Shared。请求受理后继续等任务终态；取消受理、进度100%或本地断开都不代表完成。失败或结果未知不在浮动进度及隐藏任务列表中驻留，改用统一 Toast 提示；内部仍保留真实结算记录，先核对源/目标，不自动重做。密码错误仍按原流程重新输入。
- 跨服务器复制粘贴与“发送到服务器”共用直传优先、中转回退流程。自动方式优先源端 rsync，普通文件缺少 rsync 且跳过安装后尝试 SCP；源到目标的 SSH 只读探测不可达、直传工具/版本仍不满足或目标经代理/跳板时，尚未开始传文件即可通过后端分别连接两端，用 SFTP 中转。两端不必互通，文件数据不经浏览器。直传已经开始后失败、取消或清理未知，不自动切换方式重传；先核对实际源/目标。
- 跨服务器粘贴前复用全局确认，告知直传会向源服务器交付目标凭据；不信任源服务器时取消本次操作。rsync 不强制压缩，按完整文件连续传输，减少 ZIP 等已压缩文件的 CPU 开销。单文件或纯文件批次直接使用根元数据提供字节总量和实时进度，不为计算进度额外扫描目录。实际吞吐仍取决于保存的连接地址、网络路径、SSH 加密和磁盘。
- 同Workspace及跨Workspace剪切由后端move完成，前端不在copy后额外删除。成功后刷新对应目录；刷新失败单独提示，不重复移动。跨Workspace仍要求两个原资源均有效；源变化检查不是原子快照或条件删除。
- tar.gz/tar.bz2 压缩和解压使用 GNU tar 原生记录检查点报告已处理的未压缩归档数据量，单个大文件也能更新。压缩不额外预扫描目录，总量未知时显示持续进行的进度条及实际条目/字节，不伪造百分比；解压发布阶段复用已验证成员总数显示进度。字节数是 TAR 数据流处理量，含头部和填充，不等同于压缩包大小或网络速度；仅完成退出、校验和发布后显示 100%。
- 支持ZIP、tar.gz、tar.bz2；ZIP可带密码，缺少或错误密码显示明确提示。远端须有zip/unzip/zipinfo、GNU tar及od；密码按现有原生命令argv交付，须信任远端。验证后的 ZIP 警告仅通过统一 Toast 提示，不展示工具原始诊断。
- 递归任务未取得精确总量时只显示实际完成数/字节，不把顶层选择数当总文件数。断线、协议错误和超时后不重放；等待结束不证明远端已停止。

归档任务的“取消／取消中”和完成后的“移除”统一位于任务名称（压缩/解压文件名）同一行最右侧，复制、移动及混合任务的“取消”也位于各任务标题行右侧，底部不再单独占操作行；取消中仍禁用重复取消，“移除”仅清除本地任务记录。隐藏浮动进度后，小入口右侧显示任务进度百分比，单任务使用该任务进度，多任务按当前展示任务的进度等权平均，不再显示任务数量；未知总量不推算新的百分比，沿用任务已报告进度。

上传、复制、移动、归档及发送到服务器的浮动进度和隐藏任务列表不再附加错误或警告说明，统一使用 Toast，保留原任务状态、进度及操作。后台服务器传输失败通过 Toast 显示文件名与安全错误原因，列表读取和取消/移除失败同样通过 Toast 提示；相同失败不会随轮询重复弹出。

### 服务器传输

文件管理器选择源文件/目录，打开“发送到服务器”；弹窗左侧选择已保存的目标 SSH 连接，标题栏提供全选和清空，右侧设置目标目录与传输方式，逐次确认信任源服务器后发送。后台独立执行，不借用 Workspace 附件或 Agent 授权；当前仅管理员可操作。

目标路径不再手动输入：先选择目标服务器，再点击路径条打开目录选择窗口，以路径栏和目录列表浏览根目录、子目录及上一级，点击“使用此目录”确认；可以刷新目录，也可浏览指向目录的符号链接。只选择已经存在的目录，不在选择器内创建目录；根目录可选，最终是否可写仍由远端权限决定。取消选择器不会改动原路径，读取失败通过 Toast 提示。多目标发送时可指定其中一台作为目录浏览服务器，所有目标仍使用同一条所选路径，请确认路径对其它目标也适用；不因目录浏览成功就保证传输成功。

目录中含换行、制表符、引号或反斜杠等合法 POSIX 名称时，列表和目录导航仍保留原名称，不因单个特殊文件名导致整个目录加载失败。NUL、无效 Unicode 和容量超限仍会拒绝。

当前浏览器按登录用户和目标连接记住最后一次确认的目录，重新打开或重新选中目标后自动恢复；更换浏览服务器读取它自己的上次选择。连接删除重建或配置版本变化不复用旧记忆；上次目录不存在时提示并回到根目录重新选择。本地存储不可用时仍可正常选择和发送，但不保证下次恢复；不跨设备同步。目录浏览使用独立 SFTP 资源，不要求打开目标终端，继承原 Remote Files 完整列表 200 项/48 KiB 元数据预算，超限明确提示而不截断；目录本身已确认存在时，即使其子目录列表无法读取，仍可选择当前目录。关闭、换目标、隐藏或注销会取消读取并释放原资源，不关闭正在使用的终端。

进入或返回工作区会只读获取一次后台任务列表，恢复先前或其它设备创建的任务；只有排队、传输中或取消中的任务才继续约每 2 秒更新，当前读取完成后再安排下次读取。没有任务或全部结束后停止周期请求；本设备发送新任务后自动恢复，离开工作区或注销时停止。浏览器退到后台或离线时暂停状态轮询并取消在途状态读取，服务器上的任务继续执行；回到前台或恢复网络后，仅有活动任务、被中断/失败的读取或尚未完成的首次加载时补读，空闲列表不因反复切前台增加请求。提交结果未知时只读核对一次，不自动重发或解除未知保护。空闲页面不持续发现其它设备的新任务，返回工作区时重新读取；当前后台服务器传输尚无独立 WS 推送，不等同于 Workspace 文件上传、复制或归档的 WS 进度事件。

## 远程桌面

RDP 传输按完整协议消息交付浏览器，避免握手结束时把随后画面数据混入同一消息而丢失；不等待定时合并或凑满缓冲。远端仍按变化区域更新画面，弱网下可能逐步显示，当前不承诺视频流式的整帧刷新。

浏览器将同一动画帧内收到的 RDP 像素更新合并后显示，重叠区域保留最新内容，减少重复逐块提交；只复制变化区域，分散更新超过区域预算时优先合并额外重绘最少的区域，减少无变化区域的提交；协议处理和键鼠发送不等待绘制。单个画面的可选合并底图最多 32 MiB，超大分辨率或底图分配失败时自动采用原直接绘制，不拒绝连接；关闭与分辨率变化释放旧底图。此优化不改变画质，仍不能消除弱网中尚未到达的数据或保证远端整帧同步。

生产构建将 RDP 二进制独立为可缓存资源，首次连接仍需下载完整 WASM；功能和窗口操作不变，普通页面不提前加载远程桌面或编辑器。

RDP 输入优化：普通按键、点击与滚轮立即提交，输入法确认和批量文本按最多 32 个完整字符一组发送，不等待凑满；某批失败时停止后续文本并提示，不自动重放。连续鼠标移动在约 16ms 内合并为最新位置，按键、点击及释放输入前先提交最后位置。传输按实际发送缓冲水位控制背压，减少逐块暂停的调度开销。窗口与操作入口不变，不做本地预测回显；按键后的实际画面仍受网络往返、远端处理及画面传输速度影响。

RDP 使用已修复位图行跨度与边界校验的固定上游构建，避免部分画面更新导致解码器越界并中断输入；窗口尺寸与操作入口不变。RDP 窗口连续缩放时先由本地显示已有画面，尺寸稳定约 150ms 后只向远端请求最后的分辨率；相同宽高及有效缩放不重复请求，减少远端桌面重建。输入仍立即发送，关闭取消尚未发送的尺寸变化。后端按完整 TPKT、Fast-Path 或 CredSSP 消息逐条发送 WS，不随意合并握手与后续数据；网络较慢时仍可能看到服务器的渐进画面更新。

手机端触控操作指南收在触控标签旁的说明图标中，点击查看当前模式的完整操作方式，避免长指南换行占用画面；直触/触控板切换仍直接显示。RDP 触控操作时显示本地位置指针，触控板首次从画面中心定位，随后跟随手势移动；该指针仅表示本地输入位置，不代表远端已处理操作，使用实体鼠标时隐藏以避免双光标。

手机端 RDP/VNC 底部的宽度、高度与重新连接按钮保持同一行，尺寸输入框随可用宽度收缩，保留完整标签与按钮文字。

RDP/VNC 拖拽产生的小数像素在保存时取整；保存宽度为 320–8192、保存高度为 200–8192。小于此范围的手机窗口仍按当前视口显示，记住的尺寸限制在保存范围内，避免缩放时因小数或窄屏尺寸被拒绝。

支持普通 RDP/VNC 完整桌面：浏览器使用 IronRDP WASM / noVNC，Backend 只提供认证后的 WebSocket → TCP/TLS 桥，无需 guacd、remote-gateway 或额外桌面容器。不支持 RemoteApp，其前端配置、协议字段与数据库列均已删除。

在 Connections、Dashboard 或 Workspace 打开桌面，保留原窗口、最小化/恢复、全屏、触控模式与软键盘入口。RDP/VNC 密码仍通过版本化凭据接口加密保存。连接时浏览器临时取得主机、端口、用户名及密码，仅交给当前 SDK 内存实例；不进入 URL、日志或本地存储。公网必须使用 HTTPS，浏览器端的凭据不是对已登录用户隐藏的秘密。

当前认证 Cookie 调用 `POST /api/v1/connections/:id/rdp-session` 或 `vnc-session`，初次请求可无 body 或传 `{certificate:null}`，width/height 为 200–8192，dpi 为 48–480。成功返回 `{ticket,protocol,host,port,username,password}`，完整 JSON 最多 64 KiB，响应 no-store。浏览器使用同一个有效登录的 Cookie 在 30 秒内连接 `/ws/remote-desktop?ticket=...`，ticket 仅可消费一次；URL 不携带凭据。票据写完前断连撤销尚未消费的票据，未取得有效响应时重新签发，不复用不确定票据。

单 Backend 待签发/待用最多 1,024 项，建连/活跃/未确认清理共用 16 槽；满额拒绝新建，不踢旧会话。目标/版本变化、登录撤销、缺少密码、ticket 重复或过期时拒绝继续。签发等待 15 秒、Backend 初始化等待 30 秒、技术握手 20 秒；等待超时不代表原任务结束，所属资源真实收敛后才归还名额。

仅接受 `direct` route，Backend 必须可访问目标端口；Proxy/Jump 目标被明确拒绝，不静默绕过声明路线。RDP 支持 TLS、NLA 及增强 NLA（HYBRID_EX）协商，增强 NLA 的四字节认证结果由桥完整透传后交 SDK 验证，不作为画面数据解析。RDP 要求支持 TLS（最低 1.2）。连接前先读取服务器证书；受系统信任、地址匹配且在有效期内的证书可直接连接。无法验证、地址不匹配、过期或与已记住证书不同，会弹出证书确认窗口，显示目标、颁发者、有效期及 SHA-256 指纹。选择“取消”停止连接；“继续连接”默认仅本次有效；勾选“记住此证书”后，当前用户连接同一主机/端口且证书相同时不再询问，证书变化重新确认。信任保存在后端，并包含于完整备份；没有忽略所有证书的开关。请从独立可信渠道核对指纹；手动记住证书表示接受该具体证书的信任、名称或有效期例外，不代表它获得了 CA 验证。VNC 远端传输本身可能未加密，不建议跨不可信网络直接暴露。

未确认的证书返回 HTTP 409 `certificate_required`，仅包含证书信息，不返回票据或连接密码。明确确认后向同一路由提交 `{certificate:{host,port,fingerprint,previousFingerprint,remember}}`；后端重新读取证书并核对确认内容，保存时复核登录及原信任。成功票据绑定本次证书指纹，实际 TLS 再次核对后才向 SDK 交付握手证据；期间证书变化会拒绝建连，主动重连后重新确认。关闭窗口或退出登录会取消等待；保存响应失败不证明信任未写入，下一次连接重新读取当前信任，不自动重放保存。

最近连接时间从连接列表读取服务端持久毫秒时间，桌面 connected 事件只触发只读刷新。Backend 在 TCP/TLS 桥就绪后记录，桥就绪不保证远端密码认证或画面成功；桌面是否可用仍看实际画面与操作反馈。网络/响应中断不自动重放，点击“重连”签发新票据。错误使用安全本地化类别，不显示厂商正文；登出、关闭与页面停用撤销原请求和桌面。原生 SDK 无 pending-connect 取消 API，已关闭窗口的晚成功仍由原实例收尾，不重新显示。

RDP/VNC的文本剪贴板单次最多 1 MiB；权限被拒仍可操作桌面。批量文本输入每次最多 64 KiB UTF-8，超量整次拒绝，不发送部分内容。切换触控模式取消原手势，失焦释放 RDP 按键。RDP本地输入法候选框锚定最近点击的桌面位置，窗口缩放、全屏和滚动时同步换算；当前SDK没有远端文本光标坐标接口，通过Tab/方向键移动或程序自动切换焦点后，候选框不能精确跟随，可重新点击输入位置。RDP 动态分辨率依赖远端 display-control，DPI 换算为 SDK 的 100–500% 缩放提示，初始协商仍受 SDK/远端能力限制；本版不提供视频加速/媒体重定向、磁盘映射、多显示器或RemoteApp。

RDP窗口顶部工具栏的“文件剪贴板”可选择多个本地文件，随后在远程桌面的目标文件夹按Ctrl+V粘贴；浏览器确实向粘贴事件提供文件时，也支持直接粘贴本地文件，并在远端接受文件列表后发送一次粘贴。上传显示等待粘贴或累计进度，避免重复同步旧文本覆盖文件列表；新复制的本地文本沿原文本通道处理。同一会话中，主动选择或粘贴的上传未结束时不替换批次，已完成文件的远端重复粘贴不阻止重新选择。远端复制文件后，在此面板逐项下载到本机，显示各文件进度，不自动下载；目录本身不打包，目录内已列出的文件可逐项下载。浏览器通常无法把通用文件列表写入本机资源管理器的剪贴板，不能保证像mstsc一样直接在那里粘贴；本机文件是否出现在浏览器paste事件中也取决于浏览器和系统。

文件通道复用上游SDK的CLIPRDR分块传输，远端需允许文件剪贴板重定向。下载保留SDK现有每文件2 GiB限制，本版不再额外设置文件数或大小门槛；使用内存Blob缓冲，不创建浏览器持久临时文件，大文件仍可能受设备内存限制。远端剪贴板改变会使旧列表操作失效，需重新复制；传输失败不会自动重试或报告为全部成功。关闭桌面/断开会取消本地文件传输并释放文件引用，不保证删除远端已经接收的部分文件。VNC仍仅接入纯文本剪贴板。

RDP非全屏窗口将标题、状态、文件剪贴板、尺寸与窗口操作合并在顶部浮动工具栏，连接成功后自动收起。鼠标移到顶部中央短横条展开，移到桌面区域或窗口外收起；触屏点横条展开、点桌面收起；键盘可聚焦横条按Enter展开，Esc收起并返回横条。文件面板打开期间工具栏保持可见。工具栏覆盖画面而不挤占桌面尺寸，窄屏在顶部按可用宽度换行；连接中或失败时保持操作可见。VNC保留原上下布局。

修改桌面窗口宽高或拖动后保存个人偏好；保存期间禁用尺寸输入及拖动，避免旧响应覆盖新编辑。失败使用本地化提示，冲突或结果未知先刷新核对，不自动重试写入。最小化、恢复与浏览器全屏不重建连接；手机点按操作鼠标，用右上“键盘”按钮开关软键盘，最小化/断开释放焦点。本地关闭不证明远端程序停止。

RDP音频输出默认随连接启用，复用IronRDP的RDPSND通道；当前接入上游尚未合并的Web音频补丁，支持22.05/44.1/48kHz的16位PCM立体声，实际播放取决于服务器音频重定向策略和格式协商。浏览器阻止自动播放时，点击/触摸桌面或按键后恢复；无需麦克风权限，不传输录音。播放采用实时优先策略：暂停期间不缓存声音，积压超出设备延迟与实际音频块时长时丢弃旧块并追上最新声音，弱网可能有声音缺口。音频不可用不阻断桌面，断开/关闭释放播放器。已通过指定Windows目标的非零PCM、浏览器播放排程及暂停丢弃/恢复测试；物理扬声器听感、xrdp、真机和弱网仍待验收。

新桥的指定目标 RDP 基础连接、常用键盘/中文 composition、双向纯文本剪贴板及拒绝授权、窗口/全屏切换、移动仿真输入与触控，以及分钟级持续输入、票据重放/过期拒绝、受控断线后显式重连、建连中关闭和刷新后的连接释放已验证；VNC、其它系统组合键、原生输入法及手机真机、小时级/空闲稳定性、并发、多平台及复杂网络/清理故障仍待回归，不能当作全部桌面能力已验收。旧版 guacd/Windows 验收不作为本版通过证据。设计见 [远程桌面架构](architecture/REMOTE_DESKTOP.md)，检查状态见 [testing](testing/E2E.md)。

## Agent

管理卡片不常驻展示协议容量、事务过程和内部配置版本；具体限制见本章对应功能。上传通过会话附件入口完成，引用只保留必要帮助；文件页清理需先选择来源 App，失败恢复与安全确认继续按实际状态显示。

管理员登录且 Agent 执行设置启用后才显示悬浮入口，通过该入口打开 Agent；执行设置关闭时不显示入口或已打开窗口，重新启用后仍从入口打开。Host 读取真实 App 与插件安装目录，应用仅由签名插件安装创建，初始目录为空、执行默认关闭。首次启用 Agent 会引导从插件市场安装 Nexus Agent；确认推荐新安装后，应用自动启用并授予该签名包声明的能力，再配置 Provider。普通市场安装仍需单独启用和授权，已有安装不重置权限。App 实例 UUID、App 数字版本与定义／插件包版本分别使用，不以应用名称拼接请求。

Provider、App、插件、Browser 和安全设置沿用旧版卡片、分区和抽屉层级；只保留当前 Shared／后端真实提供的状态、版本、秘密意图和恢复动作，没有数据来源的运行数、审批数、诊断字段或旧协议控件不恢复为常驻界面。

悬浮按钮可拖动、贴边和右键重置；窗口保留拖动、缩放、最大化、最小化、键盘与焦点约束。窗口布局按用户保存在浏览器，采用当前结构，不转换旧布局。最小化或临时切换应用保留各自尚未发送的任务输入，恢复时保留已加载画面并在后台核对应用目录与会话，不自动发送草稿；浏览器标签页的输入互相独立，不跨网页刷新保存，登出或切换身份清理私有草稿。新建或空会话的欢迎首页填满可用会话区，默认窗口和默认输入区下不产生内部滚动；空间不足或多列建议卡换成单列时仍可正常滚动。配置弹出框打开时，Escape先关闭弹出框，不连带关闭Agent窗口。SSH 目标弹层保留逐项勾选，并提供全部启用、全部停用与当前已选数量；批量选择不授予权限，执行时仍按授权目标核对。SSH 目标选择按登录用户和 App 记在当前浏览器中，关闭/重新打开、切换 App 或刷新网页后恢复；主动全部停用也会记住。恢复须先成功读取实际连接和禁用名单，自动去除已删除、非 SSH 或被禁用的目标；读取失败不覆盖上次选择。记忆不跨浏览器/设备同步，不授予能力、不自动发送任务；浏览器禁止本地存储时，本次页面仍可正常选择。原生会话与自定义插件分别显示；不再显示没有真实来源的运行／审批汇总数量和健康标签。目录读取失败先明确刷新，不沿用旧可写目录。

最小化后，已打开的原生Agent任务继续接收更新；只有任务状态变化、出现或处理审批、发生需要核对的失败时，才在悬浮按钮旁短暂显示紧凑卡片。普通流式文字、单纯最小化和已读取的旧完成记录不会反复弹出。聊天界面展开时不额外弹卡片；本页刚确认发送的任务即使首次回执已完成，最小化后仍可显示该次新结果，不把它当旧历史。同一任务的变化合并，多任务依次显示；新审批优先，但不替换正在操作的卡片；卡片约8秒自动收起，鼠标悬停或键盘操作时暂缓，手动收起只关闭本条提醒，不取消任务或审批。卡片不遮罩页面、不自动移动焦点，并随入口贴边、拖动和手机可用宽度避让；待审批时入口保留小标记，过期后清除。

提醒显示真实任务状态、会话标题及简短结果；待审批显示安全操作摘要、目标与风险，可直接批准或拒绝本次操作，点击详情打开完整会话。按钮继续核对当前任务、审批版本和期限；已过期、正在提交、冲突或写入结果未知时禁用快速操作，进入完整任务核对，不自动重试、不批量批准。浏览器标签隐藏时暂停订阅与提醒收起倒计时，返回后续读；关闭Agent窗口、停用App/总开关、卸载或登出停止相关观察与清理提醒。自定义插件界面不伪造原生任务进度。

### 线程与运行操作

会话沿用左侧会话栏、对话主区和固定底部输入区布局；只有消息正文滚动，输入区不随正文滚出视口。列表读取完成后，若当前尚无选中会话且列表非空，自动打开最近更新的会话，避免主区空白；空会话显示原欢迎提示卡，点击填入草稿；用户与助手消息保留原气泡样式。点击发送后立即显示本次用户文字，等待提交回执及消息同步期间不留空；服务器同一Run的用户消息到达后接替本地展示，不显示两份。提交失败撤下本地展示并保留草稿，结果未知时先按原提示核对，不自动重发。输入区回到单层输入壳：键盘提示在上，文本编辑区在中间，模型、SSH 目标、附件、停止和发送集中在底部单行工具栏；窄输入宽度逐级隐藏次要文案，发送按钮收为图标，短窗口压缩输入区高度。模型和 SSH 目标通过工具栏弹出框选择；宽输入区的 SSH 目标按钮显示“选择 SSH 目标”和已选数量，手机及窄输入区仅显示图标。附件以紧凑文件胶囊展示并在发送前显式关联，Enter 发送、Shift+Enter 换行，输入法确认不发送。任务详情由标题栏的任务按钮展开独立侧栏，待审批卡片位于侧栏任务区顶部，可直接批准或拒绝；处理完成后待办立即移除；审批结果直接显示在对应工具调用的状态位置，不再单列审批记录。工具行分别显示当前操作的审批状态与真实执行状态，批准不代表执行成功；展开工具可查看申请与处理时间、目标、风险、执行详情和操作哈希，只读展示不授予执行权。操作哈希按需展开；执行详情显示 Shell／ACP 的有界命令预览。顶部按钮折叠／展开线程，窄窗口改为侧滑抽屉，选择线程或点击遮罩关闭。 窄屏点选当前会话也会收起会话抽屉，不重复读取当前已加载正文。

消息导航区按“回到最下、上一条、下一条”排列；回到最下仅在离开底部时显示。长会话首次只加载最近一页，向上滚动到顶部或点击“加载更早消息”再读取之前内容；加载时保持阅读位置，实时新消息不打断正在查看的历史。正文和工具分组采用动态测高的虚拟列表，屏幕外内容不全部挂载；消息导航按已加载的逻辑消息定位，在最早一条继续向前可加载更早内容。同一页面切换会话优先复用已确认正文和阅读位置，再核对任务状态；窗口宽度相同时复用已测量的消息高度，避免切回后因估算行高偏移。补读历史一次呈现，不从头逐段重新输出。闲置正文缓存沿原128条消息/256Ki UTF-16字符预算淘汰，活动历史可按需继续读取，服务器记录不受此缓存预算限制。

发送对话、新建／删除会话等原生会话操作成功后直接更新界面，不再弹“操作成功”Toast；设置和插件管理仍保留原成功回执。运行失败或结果未知时，在聊天消息最下面显示全局样式的红色行内错误提示，不弹失败Toast；提示保留具体工具名、已知原因、恢复建议和运行编号；区分能力未授权、目标禁用、App 停用、审批失效、工具超时、主机未受信任、参数错误、预算／输出上限，以及模型认证、限流、无效响应和网络错误。原生Run创建、读取和流式订阅被拒绝时也在聊天底部显示相应原因，例如执行已关闭、模型不存在、配置已更新或仍有运行中任务；写入结果未知的核对要求继续保留。不向页面发送 API 密钥、供应商原始响应或异常正文，也不自动重新发送任务。

查看 SSH 列表需要 App 的 machine.inspect 全局能力授权；返回内容仅包含本次选择且未被 App 禁用的 SSH 目标。machine.inspect 不使用 SSH 目标范围 grant，沿 Shared 定义与其它全局能力使用同一授权规则。选择目标本身不会授予权限；保存能力授权后可在原会话继续发送，新运行读取当前授权，不必新建会话。已失败的旧运行保持原失败状态，未授权时在 Agent 设置中授予所需能力后再明确发送新任务。新工具失败的安全原因保存在原工具记录中；模型流及派发前故障的原因在当前后端进程内保留最近512次运行，淘汰只影响诊断，不限制执行，重启后依运行编号查看后端日志。没有已记录原因的失败明确提示原因未知，不根据当前授权猜测历史原因。

会话栏提供搜索、新建和单会话删除入口；列表行只显示标题与更新时间，选中行有明确指示，不常驻展示内部版本或技术表单。新建按钮直接创建并选中“未命名会话”，成功回执到达后直接更新列表，不等待再次全量读取；首次提交任务先用首条消息摘要作为兜底标题，并在当前文字模型有剩余请求、Token和并发额度时后台生成同语言短标题，列表和当前会话沿原WS同步，不需刷新。图片模型只用消息摘要，不额外请求图片接口。手动命名的会话不参与自动覆盖；命名期间手动改名以人工名称为准。命名额外调用计入当前任务用量，最多尝试一次；失败、短超时、取消或前台回复先完成时保留摘要，不弹Toast、不阻止正常回复，不自动补发命名请求；正常取消命名请求不计作资源清理失败；若实际清理无法确认，当前运行会保存结果未知并显示具体原因，不继续停留在执行中，也不自动重发任务。会话页切换时复用已加载的线程、附件及运行状态，不重复请求或清空当前选择；返回文件页时保留筛选和原列表，并自动重新读取当前筛选的第一页及容量统计，以显示对话新生成的图片等文件；关闭或最小化后再次展开先显示已加载列表，再后台核对原已加载范围，以发现其它页面的增删，保留当前选择及未发送草稿。后台核对不禁用新建、删除和选择；交互写入取代旧后台读取。成功创建/删除直接消费权威回执，不再额外刷新整表；首次进入、显式重试或身份失效时重新读取。读取失败时提供重试，写入结果未知时先检查原意图，再决定是否重试。行尾删除按钮需在 3.5 秒内再次点击确认；存在 pending、running 或 unknown Run 时会话拒绝删除，先结束或收敛活跃 Run。删除成功后选中相邻会话，没有其他会话则清空主区和附件状态。删除会移除该会话的运行、事件、审批、子任务及附件引用，保留已生成的 Artifact 文件对象，并保留用户记忆但清空其运行来源关联；不做仅浏览器本地的假删除。删除结果未知时保留原线程版本，先只读刷新核对；检查会沿分页游标查找原会话，不能仅凭第一页没有该项判断删除成功；全部页面均不存在才收口，仍存在才可按原版本重试。App 切换器、附件选择器和文件来源只显示产品名称，不向普通界面平铺 App UUID；仅在异常或折叠技术详情中按需保留内部标识。

1. 打开已启用的原生 Agent 插件应用，读取线程；每页最多50项，标题最多128 UTF-8字节。选择已有线程，或点击新建创建默认标题会话；正文按服务端四段游标续读。
2. 选择真实可用模型和本次SSH目标，输入任务创建Run。模型选择绑定Provider配置版本，目录变化不自动换模型；最多50个唯一SSH连接。空目标只表示未选择SSH目标，不授予或撤销其他能力。
3. 输入最多16 KiB UTF-8，包含附件引用；完整Run JSON最多128 KiB。同线程存在活跃Run时由后端拒绝另建。pending、running和unknown均不可当作已收敛；unknown仍可明确请求取消。
4. 查看当前Run的状态、事件、审批和子任务；可见时通过 `/ws/agent-runs` 直接接收持久正文增量与状态，收到文本片段即更新，不再通过定时轮询或变更通知后发HTTP读取。首次加载和显式核对仍可HTTP读取；断线或恢复可见时通过WS携带已接纳游标补齐，正常生成不逐段发HTTP。突发更新约16ms合并，最多16页、总编码容量按Shared runs/values计算的未确认窗口用于流控；窗口满暂停发送，确认后继续，不拒绝Run。心跳与权限复查不读取正文。unknown不自动恢复执行。事件显示最近200条；同一次模型步骤的连续正文片段合并到一条回复，跨页和断线补读继续追加，不为每个片段新建消息；不同运行或模型步骤保持分开。正文历史按需分页并虚拟渲染，不再以固定展示窗口丢弃活动会话的已读消息；持久记录保留。终态后继续推完剩余正文再结束订阅，显式续读保留。
5. 打开会话时沿运行列表游标读取至最新一页，不把首100次中的旧任务当作当前任务；界面仅保留最近100次运行的元数据，持久历史不删除。completed、failed、cancelled Run可用原版本发起follow-up，创建同线程的新Run；不再向运行中Run注入输入，不提供旧Goal／输入队列／interrupt／手工预算追加／手工checkpoint恢复或历史删除接口。检查点和预算分别归后端上下文与执行治理，清理归相应管理入口。

写入结果未知时保留原键、输入和版本，先只读核对，再明确重试原意图，或承认可能已提交后放弃跟踪；读取成功不证明原写入未提交，重试被当前版本／权限拒绝也不抹去原未知事实。不会自动换键、套新版本或重放副作用。临时隐藏暂停订阅与自动读取，保留原实例未知意图；恢复可见、网络恢复或断线重连后按原游标补读，不重放执行；注销／会话重置／销毁清除私有草稿并隔离晚响应。取消本地等待不证明远端停止。

聊天输入栏的盾牌菜单设置下一次 Run 的**批准策略**，新会话默认“按需询问”：写入或破坏性操作暂停后，在聊天审批卡片确认。“全授权”按创建 Run 时的用户委托自动批准允许范围内的操作；每次仍持久记录审批并只消费一次，App grant、目标选择/拒绝名单、禁止操作、当前配置、撤权和任务总预算继续生效。策略在 Run 创建时冻结，运行中不能修改；切回已有会话恢复其所选 Run 的策略，后续 WS 状态不覆盖正在编辑的下一轮选择。子任务继承主任务策略；ACP 内部权限仍有独立操作身份和单次消费，全授权也沿同一审批链。总开关、App 能力授权和 Run 批准策略用途不同，不能相互替代。

执行开始前的确定数据库语句失败会安全结束尚未派发的任务，在聊天底部说明数据库操作失败；等待模型并发名额期间取消也会结算原预留步骤。未知提交或回滚失败保留原证据，不自动重放。数据库结构签名不符会在启动时拒绝，不能跳过结构校验；后续版本的升级按 [数据库迁移](DEPLOYMENT.md#数据库迁移从下一版本起) 交付。

DEV `/__agent-next` 仍提供独立协议诊断，不作为正式入口或行为验收证明。正式适配已完成源码接线，按D17仅静态检查；完整回归留最终远程Actions E2E。

切换会话时，重复点击当前会话不清空正文；连续切换由最后一次选择接管只读加载，较早返回不覆盖当前会话。当前Agent界面内已确认的正文窗口和独立游标在内存中复用，切回来先恢复已有正文与阅读位置，再核对当前任务、审批和权限；缓存只用于显示，不授予写入。未缓存会话先显示原加载状态，历史追赶完成后一次显示当前窗口，后续新回复继续正常流式输出。正文与闲置会话缓存共同使用原128条消息／256 Ki字符展示预算，优先淘汰较早闲置窗口；被淘汰后再次打开需要重新读取，网页刷新、退出、App退役会清除缓存。首次读取长历史仍需按原后端分页追赶，不将批量显示视为网络读取已经加速。

任务订阅按真实WebSocket结果退避恢复，不因浏览器onLine标记滞留而永久停止；网络change/online/offline促使重新建连。浏览器隐藏时暂停，返回前台从已接纳游标续读；首份任务状态仍必须在原45秒期限内到达，单独心跳不能掩盖未加载。权限或协议拒绝仍需人工核对，不重发任务或审批。

### Provider 与模型配置

Provider、MCP/ACP 集成与插件市场按名称、类型/容量/版本、标签和状态分色；仓库来源标题使用主题强调色，插件标识保持清晰的次级文字。启停、安装与保留数据继续使用原状态文字及语义色，普通数量保持中性。

顶部“Agent 功能”开关关闭时直接保存；首次开启先检查 Nexus Agent 安装，未安装则显示官方推荐插件确认弹窗，已安装则复用。读取期间保持可见并显示加载状态，读取失败时禁用开关并可只读重试。取消不安装、不修改开关，确认安装成功后才启用总开关；安装结果未知时先只读核对，不自动重装。确认从此引导新装 Nexus Agent 时，安装事务同时启用 App 并授予当前签名包声明的全部能力，文件/Shell 能力覆盖全部 SSH 目标；已有安装保留当前启停和授权。普通市场安装仍默认停用、空授权。目标禁用名单、本次 Run 选择和批准策略继续生效，总开关不代替应用权限。官方目录不可用时显示失败，不伪造推荐信息或安装进度。

预算与存储沿用单位快捷输入（K/M/G、k/M、m/h）及底部保存栏；窄屏下状态提示可换行，保存按钮固定在右侧，不换成单独的左对齐行。单位换算结果必须是范围内的安全整数，空值、非整数量或超限输入不会发送保存请求。编辑展示保留精确数值，不因缩写或四舍五入改变预算。四个分类共用同一份版本化草稿。

插件仓库沿用 URL 添加条、可移除的仓库标签、搜索及按来源折叠的插件卡片，目录自动读取。第三方发布者仍须显式信任；核验包后进入同一安装／升级确认区，不直接安装。目录部分失败保留成功来源；仓库写入冲突或结果未知时先读取当前配置，不自动重放写入。

“App 与扩展”使用单个工作区容器，按 Agent App、MCP / ACP、插件市场、执行预算四个页签切换，避免应用、集成、仓库和策略四组内容同时纵向堆叠。页签保留在设置页内部，并始终按可用宽度四等分、内容居中；390px 与 320px 下四项仍完整显示且不产生页签自身或页面级横向滚动。Agent App 使用连续目录行展示定义／插件包版本、启停、能力数量和签名来源，不显示内部 CAS 修订；权限在行内抽屉中按能力分组，支持全选切换和显式保存，能力项只控制启停，目标范围由全局禁用名单与本次 Run 的目标选择统一收窄。新版没有旧运行数／待审批数聚合字段，不以零值代替。市场页提供刷新仓库、仓库添加条、可复制来源与按来源折叠的插件行；刷新仓库并入仓库标题操作区，不单独占行，窄屏与添加仓库同排，360px 以下收起文字仅保留带无障碍名称的图标。仓库分组只用箭头表示折叠状态，不显示“展开／收起”文字，整行点击及键盘 Enter／Space 仍可切换。移除的是自定义仓库配置，不是已安装插件。App 与扩展仅从默认官方仓库或已配置的第三方仓库下载签名包、验签并确认安装／升级，不提供本地包选择、上传或上传归属弹窗，也不要求先创建 App。校验后的插件包在独立弹窗中确认，不再在市场顶部展开；弹窗保留签名、名称、版本、能力与折叠技术详情，按当前安装状态提供安装、准备升级或完成升级。操作期间禁用取消、Escape和遮罩关闭；非忙碌时可取消返回原市场位置。准备升级后取消弹窗只关闭确认展示，不撤销已确认的排空状态。升级或安装成功后自动关闭；失败重读与结果未知的核对入口保留在弹窗内，不自动重试。窄屏正文独立滚动，操作按钮固定在底部，按钮文字保持单行，空间不足时按钮整体换行。各页签只读取自己的资源，切换页签或离开分类会停用旧页签的写入与晚结果回填。

每个 App 行的“安全策略配置”展开后使用单一授权面板：标题、已授权计数和操作保持同一层级，能力按类别以浅分隔组织，宽屏为两列、窄屏为单列；能力名称与说明连续展示。能力项只控制启停，SSH 目标范围由全局禁用名单和本次 Run 的目标选择控制，不在每个能力项内重复选择。授权项、全部启停和保存仍按原完整集合语义工作。

插件安装目录确认变化或首次安装完成后，应用列表与定义目录一起重新读取；重复读取同一安装快照不再次触发这两项查询。正在读取或保存应用时合并保留一次后续刷新，不丢失变更，也不自动重放写入。离开 Agent 设置撤销旧目录展示与在途回填，返回后重新读取；读取失败保留最后确认状态，仍通过原恢复入口核对。

卸载入口回到 Agent App 行，须先停用。确认弹窗使用新版排空流程，未完成时可继续卸载或取消排空。卸载完成后，对应插件从 Agent App 列表、App 选择器和数量统计中移除；排空中的插件仍显示，便于继续或取消卸载。卸载确认弹窗可勾选“同时清除插件配置和应用数据”；默认不勾选。App列表在宽屏下将右侧安全策略配置、启用／禁用与卸载操作组和应用概要垂直居中；手机沿用全宽三列操作行。清除范围包括能力授权、执行预算、MCP / ACP 配置与凭据及插件独立存储，聊天记录、任务历史、记忆和生成文件保留。卸载与清除分阶段完成，清除失败会重新核对实际状态，不提示全部成功或自动重放。保留数据的插件在市场对应行标记“仍有应用数据”，可确认清除或重新安装；清除成功后标记和清除入口消失，不再另外列出已卸载应用的数据面板。原仓库不可用时仍显示对应保留数据行并允许清除，恢复原仓库后可重新安装。重新安装后恢复 App 目录项；已清除的配置与存储不会恢复。集成页使用连续行与图标操作栏；顶部应用选择框在宽屏保持紧凑宽度，重新读取与创建集成按钮始终成组右对齐。手机选择框按剩余空间伸缩，320px下也与按钮保持同排，避免操作换行或横向溢出；360px以下“创建集成”简写为“创建”，仍保留完整操作名称的无障碍提示；长应用名在选择框中省略，展开列表可读取完整名称。添加／编辑、删除确认及发现目录分别使用弹窗；无集成时显示空态。新版 MCP 私网例外、凭据保留／替换／清除及 ACP SSH 参数仍按真实字段填写。各 App 的集成与策略相互隔离，切换 App 或离开分类撤销旧视图等待，未知写入不会自动重放。

Agent 设置按原来的“模型与预算、工具与扩展、执行与集成、安全与防护”四个分类浏览；总开关卡片只保留开关和活跃 App 汇总，不重复显示启用／停用徽标，480px 以下四个分类改为两列两行，内容区右侧为滚动条保留稳定留白。提供商采用卡片和添加／编辑弹窗，桌面弹窗支持拖拽大小，窄屏保持原自适应尺寸与定位，表单正文左右对称留白并双侧保留滚动条槽，内容不会随滚动条出现而偏移。提供商标题行按可用宽度换行，添加 Provider 按钮在空间不足时独占下一行并右对齐，不覆盖 Provider／模型统计。调用协议与启用开关在宽屏同高对齐，窄屏改为宽度铺满的独立操作行；API 密钥标签独立成行、显示凭据按钮与输入框同高对齐，模型发现和手动配置保持原流程。提供商与 Agent 配置自动加载，读取失败或写入结果未知时才显示刷新核对操作；高级诊断与恢复在数据设置中展开。模型目录状态与更新入口位于提供商卡片内；创建、版本化编辑、凭据保留／替换／清除、发现模型及连通测试见下文“后端Provider与模型冻结”。测试会真实请求并可能计费，失败不自动重试；发现成功不等于模型可调用。每模型可覆盖Provider默认协议，Run冻结实际配置，不自动降级或回退。

OpenAI-compatible支持管理员配置的HTTP(S)地址，discovery/test/run使用同一配置；应用不提供逐跳allowlist或DNS pinning，网络隔离由部署负责。错误仅展示Shared安全类别，不回传供应商正文。

添加发现模型后自动查询本地模型库，手动填写模型 ID 后离开输入框也会匹配。匹配支持供应商前缀、大小写与分隔符差异、同系列日期版本、推理等级及 `thinking`、`fast` 后缀；目录中有完整同名模型时优先使用该项，多个原始来源同级且能力冲突时保留未匹配。`thinking`、`fast` 用于名称匹配，不据此虚构工具、图片或推理能力。目录快照保留供应商来源，不生成无来源别名，避免聚合目录的别名造成误冲突。本次内部缓存格式更新后需点击更新模型库重新获取目录，已保存的 Provider 配置保留。除上下文与输出长度，还会补齐目录声明的工具调用、图片／文件输入、缓存键、支持的推理等级、默认等级和必需推理标记；供应商已报告或已配置的有效值保留，显式“应用目录”才替换现有配置。已支持的推理等级后缀可设为默认等级；保留旧版对明确模型的缓存键及推理能力修正。手机添加模型时参数默认收起，仍可手动展开，已填写参数无效时自动展开。模型库尚未更新、上次更新失败或未匹配时通过全局通知提醒更新；目录缺少最大输出预算时，文本运行前仍需手工补齐；上下文容量未知不阻止文本运行，图片模型无需文本预算。

在供应商卡片中可创建、编辑、启停和确认删除，手动或批量加入发现模型，逐模型编辑协议、能力和推理选项，查看来源/观察/冲突并显式应用观察或目录建议。未知可选能力保持“未声明”；上下文和输出 Token 允许留空并保存；填写时须为正整数，同时填写时输出不能超过上下文。文本 Agent 运行仍需最大输出预算，缺少时先补齐；上下文容量允许未知，不能以图片模型的零预算代替文本输出预算。每份草稿绑定读取时的版本；更新冲突或结果未知后停止写入，点“重新读取（放弃草稿）”只读核对，读取失败不解除阻止。发现已有供应商成功后读取当前配置再打开草稿；不自动重复发现。连通测试会发出真实请求并可能计费，文本模型临时错误按下述SDK政策有限重试，图片不重试。密钥使用保留/替换/清除操作，提交、取消、离页或身份撤销清除本地秘密。旧版全局默认/fallback模型选项不再由管理页拼接；正式Host按本次Run显式选择模型和配置版本。

### Agent 长对话上下文

聊天输入框工具栏在所选文字模型声明思考等级时显示闪电按钮。点击可选择模型支持的等级；未手动选择时，按钮文字、强度说明及滑块位置按当前模型配置的默认等级显示，不再显示“默认”。模型未配置默认等级时显示“自动”，交由供应商决定，不将它记成某个具体等级。未配置默认等级不会阻止模型列表和会话加载。 OpenAI-compatible文字流支持供应商的native_finish_reason元数据及reasoning_content/reasoning思考片段，兼容无拒答/无工具的null占位、工具续帧null占位及带正式结束原因的null结束帧；供应商逐帧报告累计Token用量时，只取流结束时的最终单调快照，不重复累加；思考片段不作为答复正文，仍需真实答复、正式结束原因、SDK正常结束和本地清理成功才能完成任务。任务失败或结果未知时在聊天消息末尾保留具体错误原因，不弹Toast、不自动重发原请求；提示使用全局行内错误样式。强制思考模型不提供“无”，未声明等级的模型和 Images 模型不显示此入口。切换模型会清空本轮覆盖；同一模型下后续新任务继续使用当前选择，已发送任务及其子任务保持创建时冻结的等级。调整只影响之后的新任务／追加输入，不会修改在途请求。

会话列表右侧删除按钮与整行垂直居中，保留再次点击确认删除。会话列表搜索会沿现有分页继续读取后续会话，包含最初50条之外的记录；清空搜索或离开界面后停止搜索触发的后续读取，读取失败可用原重读入口恢复。手机端左侧会话列表以主题实色背景覆盖聊天内容，点击外部遮罩可收起。Token 统计和消息跳转按钮独立放在输入框上方，控件悬浮于正文上方，不占用整行正文空间，也不绘制整条底色或边框；只有各个按钮自身保留底色并响应点击，按钮之间的空白可透显、点击和滚动后面的消息。对话底部保留留白，避免最后一条消息停在按钮下面。Token 在左，回到最新、上一条、下一条在右。输入框与下方配置／发送工具栏保留共同外框；权限选择、添加文件和 SSH 目标使用一致的按钮边框。SSH 目标按钮统一只显示图标，悬停或使用屏幕阅读器可识别用途，点击后仍可在选择面板查看数量和修改目标。底部模型、思考强度、SSH 目标、权限及停止按钮靠左，添加文件和发送靠右；图标按钮保留自身宽度，空间不足时模型名称收缩省略。状态行显示当前选中任务（含其子任务）的 Token 总量，点击可查看输入／输出 Token、模型请求数、工具执行数及用量报告覆盖数。只累计供应商实际返回的用量；完全未返回时显示“—”，部分请求未报告时总量仅代表已报告部分，图片请求不补成零。状态行的上一条／下一条按钮按消息起点在当前已加载内容中跳转，流式输出的同一步骤片段作为一条消息，首尾按钮禁用；导航覆盖当前展示窗口，窗口外的持久内容不会因此删除。上翻阅读历史后，可通过“回到最新消息”跳到对话底部；阅读历史时新消息不会强制拉回底部，保持在底部时继续跟随输出及图片加载。

Root读取同Thread的持久历史，保留失败、取消、unknown和真实工具结果；Child不继承父私有历史。历史、摘要和工具结果都是不可信数据，不授予权限。模型按冻结预算生成语义检查点，不通过关键词或截断伪造摘要；来源变化、摘要失败或无法安全压缩时明确失败，原始历史保留。

模型历史使用最近连续窗口：最多4096个Root、1024步骤、4096工具和4 MiB原始正文；从最新完整Run向前保留，超出窗口的较早内容不注入本轮，单个历史Run超过窗口则本轮不注入它及更早历史，不阻断新对话。原始对话和内部运行记录不删除，模型会收到近期历史可能省略的说明；窗口内来源仍逐项核对版本和状态，兼容的语义检查点继续复用。首轮会继续按完整编码容量缩小近期历史，并同步缩小来源核对范围；不删除原记录，不裁剪当前用户输入或半组工具。首轮成功预留后固定历史来源，后续步骤不靠删旧来源绕过连续性校验。不另设每Run消息条数上限，消息及工具定义合计4 MiB，用于限制后端处理与快照内存；不把字节数当精确token数拒绝模型窗口。完整请求完整性与编码容量在派发前核验，不静默重跑工具。工具结果账本最多256 KiB；模型可见结果按已保存的工具输出预算投影，超过该预算时给出带hash的预览，`tool_result_read`在原权限下按Unicode码点续读已捕获内容，不能恢复未捕获数据。正文UI使用独立的Run序号／步骤／事件／码点偏移游标，不把审计字节数当正文。

### 审批、协作与 Browser

审批展示原工具、风险、目标、摘要及期限；操作哈希按需展开，版本保留在提交校验中。明确批准或拒绝时使用原版本和操作内容；过期、权限变化或冲突先只读核对，不自动批准新内容。批准不是已执行，仍由后端在消费事务复查权限及原操作。Run 的 ask/full_access 是当前批准策略；governed 是宿主执行政策，两者用途不同。旧 plan/execute 前端模式已移除，不拼旧字段。

子任务显示真实状态和 profile，可分别请求取消；消息观察只显示序号／发送者／容量，不读取或确认正文。Run 事件保留独立游标；不再提供步骤与工具审计面板。

Browser使用设置中的独立Backend运行资源，不回落为浏览器本机或SSH桌面。目标、URL规则、当前节点引用与权限按实际工具逐次核对；导航／点击／输入后的断连仍可能产生副作用。配置、容量及错误语义见[集成接口](API.md#mcpacp-与-browser)。

聊天消息中的本站 Artifact 图片预览支持 PNG、JPEG、WebP 和 GIF，GIF 原字节直接显示，可保留动画；链接或强调文字中的本站图片也可展示，图旁的说明文字会保留；文件必须已就绪、未失效且当前用户有读取权限。外部图片 URL、data URL 和 SVG 不在聊天图片预览准入内；生成响应也接受这四种真实格式，是否支持动画由供应商决定。

已有选中会话时，新建后读取、发送、追加、审批或取消等请求在途均保持当前会话内容，不额外插入整块“加载中”；尚无会话的首次读取保留加载提示。正常请求在途不提前显示黄色“操作结果未知”面板；请求结束后仍无法确认结果时才显示核对、重试与放弃入口，避免把正常等待误当失败。

浏览器目标沿用卡片列表和添加／编辑弹窗；“添加目标”和“添加 Endpoint”使用全站统一基础按钮，添加／编辑目标使用紧凑单卡片，字段标签、等宽标识与 URL 列表分区展示；弹窗保存为主操作、取消为次级操作。取消丢弃本地草稿，保存提交当前配置版本。冲突或结果未知先只读刷新核对，不自动重发；离开分类或设置页关闭弹窗并撤销旧等待。新契约的多个 endpoint、优先级和 TLS 选项在弹窗内编辑。

### Agent 执行额度与进度

新执行卡片使用已保存预算，不保留旧Balanced/Deep预设、自动并发或自动增额：

| 范围              | 默认预算 | 默认硬限制 |
| ----------------- | -------- | ---------- |
| 模型请求          | 80次     | 400次      |
| 工具执行          | 400次    | 4000次     |
| 活动时间          | 1800秒   | 7200秒     |
| 并发Run／模型调用 | 4／2     | 8／8       |

预算与权限分别核验，Root冻结全族预算，Child共用账本；App覆盖只能缩窄全局值。修改配置会围栏旧Run，不能撤回已派发效果。正式界面显示真实状态及审计元数据，不以accepted／pending／本地取消表示执行完成，也不伪造精确进度。完整配置及硬限制语义见[执行设置接口](API.md#执行设置)。

### Agent 项目目录规则

当前使用按Run隔离的`project_directory_bind/read/clear`，不是旧Thread共享长连接。绝对路径、目标版本／指纹、AGENT.md／AGENTS.md的读取范围与容量见[项目目录接口](API.md#项目目录与突变占用)。规则不自动变成系统权限、Shell cwd或长期Memory。

### Agent SSH 长会话与后台任务

后端不提供旧`ssh_session_open/list/close`及sessionId，普通SSH应用不受影响。Agent使用独立Remote任务；后台Job与当前Run绑定，通过`shell_job_control`查询／等待／取消，不列任意主机进程。新命令不继承前次cwd/env，也不共享Root/Child活跃连接。配置、授权失效、断连或重启后的未知任务不自动重放。

### SSH 工具与控制中断

File/Shell/ACP/Docker只使用显式选择并授权的SSH连接，不切换目标或回落本机。`file_read`为最多32 KiB的完整UTF-8读取；`file_list`最多200项。`file_search`是区分大小写的字面量搜索，不支持旧正则或glob：最多100文件、100目录、深度8、总2 MiB，单文件32 KiB；结果限额明确标记。路径、hash、版本及单项审批按实际操作核对。

取消Run、Child或Job只发出对应取消请求，不保证远端进程停止或文件回滚；未确认副作用与清理继续保留unknown及机器突变围栏。没有自动重连、降级执行或副作用重试。

### ACP

ACP使用显式SSH目标、argv、绝对cwd及prompt，或当前已保存集成；配置不自动安装远端程序。入口批准与内层permission分别授权。非PTY channel的断连、超时或清理不确定保留unknown，不解释成操作未发生；ACP协议完成仍须独立核对实际结果。

### 执行、完成判定与治理

同一轮中，明确独立的文件/目录/诊断等读取可并行；写入、浏览器共享页面、控制与共享状态操作仍按顺序，下一轮结果保持原模型调用顺序。取消或不可继续的失败停止后续派发，等待已启动操作收尾，不重放未知效果。批准或拒绝会即时唤醒原审批检查，ACP内部批准沿同一方式，仍在实际消费事务核对原权限和版本。

模型文字按已有交付节奏合批保存，确认持久化后才推送；用量、完成及断流保留顺序。明确的开流前请求拒绝可显示确定失败；网络超时、5xx、半流或清理失败仍需核对未知结果，不自动重发。只有明确429限流拒绝可在同一步原期限内沿SDK既有退避；连接无响应、408/409/5xx不会自动重发。此实现不构成已经实测的性能收益。

Run、Step、Tool和审批有各自持久身份及版本；历史批准不替代当前执行许可。新输入与follow-up、Root与Child、批准与实际消费分别表达。后台Job受理、单个工具成功、模型结束及整组资源收敛不是同一个完成判据；unknown不改成成功，记录缺失不补成功。旧Goal/Plan/队列等交互已按当前Run、上下文与治理设计替换。

### 运行额度、终态与清理

Run状态为pending/running/completed/failed/unknown/cancelled。执行、预算与恢复以服务端为权威；重启仅对账／围栏，不自动恢复旧付费模型流或外部副作用。终态、取消信号和实际资源释放分别确认，清理失败继续阻断相关占用，管理员只能按独立事实处理。

### Memory

记忆审核位于对话右侧，不在 Agent 设置中。当前对话的 Agent 或子任务提出新记忆后，自动展开待审核卡片，不抢输入焦点；点击“保存记忆”后才进入此 App 的可召回记忆，点击“不保存”则拒绝该候选。关闭侧栏不会拒绝或自动保存，可通过对话顶部的记忆按钮重新打开；手机端沿用右侧浮层。仅显示当前对话来源的候选，不展示其它对话或无运行来源的记录；已过期候选不能保存。候选内容是不可信文本，不构成执行授权。

当前对话可见时每3秒后台检查一次，每批最多50条，超过时提示逐批处理；保存或拒绝后重新读取第一页。隐藏应用、后台标签页和卸载会停止轮询，切换对话后旧结果不回填。读取失败保留原卡片，通过“重新读取并核对”恢复；审核冲突或结果未知时暂停写入及自动刷新，必须显式读取后再决定操作，绝不自动重发审核。每 App 最多10,000条未过期候选/已发布记忆；已拒绝、撤销或过期的历史不占新记忆名额，审计记录保留。历史分页不再受累计10,000条偏移限制，仍保持每页50条和完整响应预算；只有人工发布且未过期的记忆才能被召回。后端保留全 App 的管理 API、撤销能力、已有记忆和备份，使用方式见[Memory 管理 API](API.md#memoryartifact-与语义检查点)。

### Artifact 容量与清理

Artifact 历史目录按服务器游标继续分页，不再把10,000条有效资源额度当作累计历史偏移上限；每页和完整响应预算不变。

文件库完整下载支持代理压缩或分块传输；实际内容仍必须与所选文件的版本、字节数和 SHA-256 一致。未编码且提供 Content-Length 时还会核对声明长度，不因缺少该头或压缩后的传输长度不同误拒绝完整文件。

Host文件库采用紧凑工作区布局：标题行只保留文件库名称与清理入口，存储容量合并为单行摘要，搜索、类型／App／状态筛选使用独立基础控件，内容区为单一容器内的虚拟文件列表。删除确认、清理结果、操作成功和失败恢复使用紧凑状态条；列表行提供保留、删除和下载图标，底部按需加载更多。窄屏下搜索与筛选分行展开，次要列收起并把大小、状态移入文件行内，不横向裁切。文件库本身不常驻上传或清理诊断表单，上传仍从会话附件入口完成；清理必须先选择来源 App，再通过一次确认按当前账号清理可回收文件。目录使用当前 Shared 协议，提供有界下载、保留、删除和清理。会话附件选择支持一次选择多个文件，不截断所选文件，串行上传；失败或结果未知停止后续文件，已确认的文件保留，不自动重试。原生输入选择附件后先读取当前版本，再明确关联当前线程；全部确认后才把artifactId及不可信名称写入prompt，Run不会自动派发。关联不授予`artifacts.read`，执行时仍核对权限、版本和精确Thread/Run范围。

关联结果未知时停止后续关联和Run派发，先只读核对附件；读取文件对象不证明引用已确认，须承认旧关联可能已提交后再明确发起新意图。已确认关联不因后来Run创建失败回滚。完整prompt（含引用）仍受16 KiB预算。

清理每批最多128项，确认有效10分钟，执行时重检版本、期限、引用及当前保护。失败保留unknown，不自动重放；删除保留可查询墓碑。模型分段读取最多4 KiB，HTTP下载逐块复查权限和版本；已交付字节不能撤回。关闭等待所属读写及清理任务，不能以UI隐藏证明资源释放。

正式文件库从 Agent 浮窗“文件”打开，独立读取真实 App、offset 分页列表和存储统计。用量概览展示已用／上限、保护、可回收和剩余空间；搜索条按名称、类型、应用和保留状态筛选，可重置筛选。保留／删除使用原版本，删除确认显示文件名和大小。上传按预留→字节 PUT 完成，成功后不显示核对按钮；下载核对 ETag、长度和 SHA-256 后作为文件交给浏览器。写入后须重新读取列表，读取统计不能解除写入围栏。上传结果未知时保留已知预留 ID，只读核对；无 ID 时先核对列表，明确承认可能重复后才能开始新上传意图。清理不再提供独立预览步骤；选择 App 后打开一次确认，按当前用户全库清理可回收文件并使受保护文件保持不动，确认未知不重发。文件库不提供手填内部ID的引用管理表单；会话附件通过选取文件并确认绑定到当前线程完成，执行权限仍独立核对。文件页与会话页切换时保留已加载目录、筛选、存储摘要和附件选择结果；首次进入、筛选变化、显式重试、写入后或身份失效时重新读取。切换其它页面或身份清除私有草稿和确认。

### 自动图片预览

image_generate 成功后自动展示图片及下载按钮，接受供应商返回的真实 GIF 并原样播放；能否生成动画由实际图片模型决定，不会把静态图改名成 GIF。模型不需要拼接 Markdown 地址。

交付文件时，模型可用 `artifact_create` 创建短文本文件，或在已选 SSH 上生成文件后调用 `file_deliver(connectionId,path)`。后者按流复制普通文件的原字节到当前 App，支持 GIF、PDF、表格、压缩包等，不读取 Nexus 宿主文件、不下载任意外部 URL，不改变源文件，目录和符号链接会被拒绝。它同时要求目标 `file.read` 与全局 `artifacts.write`，沿原突变审批流程执行，并受当前文件总空间和工具期限约束。

模型也可用 `artifact_present(artifactId)` 展示当前 App 已有的 ready、未过期文件，需要 `artifacts.read`；不复制、不自动保留、附加或共享文件。图片/GIF 自动内联播放，后续总结文字到达时文件预览保持在对应工具步骤的位置，避免图片重新挂载和跳位；普通文件显示名称、大小及预览/下载入口；普通文件预览复用文件库组件和容量策略，聊天内联图片仍沿原图片入口。未支持的格式仍可下载。待批准、失败、取消或 unknown 不显示成功交付；刷新从持久工具记录恢复，失效或已删除文件显示不可用并可重新读取。下载和预览始终重新核验当前登录身份与文件权限，文件期限与空间管理沿原文件库。

插件的 `agent.json` 若使用 `toolNames: null`，会按当前能力与授权接收宿主工具；若使用显式工具白名单，需要加入所需的 `file_deliver`、`artifact_present` 等名称。交付沿用已有 `file.read`、`artifacts.write`、`artifacts.read` 能力，不新增权限种类；包内声明不等于已授权，已有安装被撤销的权限需在应用权限中明确开启并保存。

### Plugin 与 MCP

应用权限在对应应用卡片内展开。插件发布者管理沿用折叠区；从仓库选择插件后自动下载／暂存／核验，再显式确认安装或升级，授权仍独立处理。普通页面不展示内部暂存版本、手工 JSON 数据修改或运行时诊断；数据页的“诊断与恢复（高级）”现只保留宿主诊断和机器突变恢复，不再提供插件安装恢复、版本目录或运行态入口。卸载后清除保留数据位于市场对应插件行，须明确确认；上述已移除的诊断入口所对应的后端接口暂时保留。

正式管理提供受信发布者、暂存、核验、安装、升级／排空、退役、仓库及明确确认的数据清除；数据迁移由后端 HTTP／SDK 提供，不在普通设置页展示手工 JSON 编辑器。签名证明来源，不授予能力或网络隔离；插件App仍须独立启用和授权。Publisher／包版本／安装修订分别核对，静态代码不存秘密。MCP、Browser、插件进程及CDP的部署限制见[集成接口](API.md#mcpacp-与-browser)；当前验收与未验范围见[测试入口](testing/E2E.md)。

正式插件管理支持受信发布者、仓库包下载/暂存/核验、已核验包安装、安装实例的准备升级/draining/完成升级/卸载/取消退役，以及官方/指定仓库目录、仓库配置和推荐安装。包需新 manifest 和有效签名；普通市场新安装默认关闭、授权为空，启用与授权到 App 管理完成；启用 Agent 引导的推荐安装在确认后同时启用并授予全部声明能力。插件页面没有本地上传入口，文件库的普通附件上传独立保留；未知暂存不自动重放。更新后先读取对应目录；未知结果须核对安装/包/运行态，明确新意图才继续。

插件仓库标题右侧可刷新目录，下方输入仓库地址并添加，搜索框独立筛选插件；手机窄面板使用刷新图标，地址输入独占一行，添加按钮位于下一行右侧。长仓库地址在行内省略，仍可复制完整地址或删除配置；插件介绍自然换行，较窄的设置面板将校验、信任及数据清理按钮排在介绍下方，文字保持在完整按钮内。

在仓库中选择插件后自动完成下载、暂存和签名校验，再显示包信息供确认安装；升级仍按原安装修订先准备再确认，不自动重复写入。前端不再提供暂存目录、已安装版本目录或运行态观察入口；相关后端接口暂时保留，未知写入和运行态核对语义不因此改变，但当前产品界面不发起这些操作。文件库恢复紧凑列表，移除新增的手填Thread／Run引用管理；记忆审核在对话右侧进行，不恢复设置记忆页、跨应用导入或手工提案表单，不常驻显示内部 ID 和存储版本；管理提案及撤销 HTTP 能力仍保留。

MCP／ACP 集成选择应用后以卡片列表展示名称、启用状态、MCP 端点或 ACP 工作目录和凭据是否已保存；内部标识与修订不常驻展示。添加／编辑使用弹窗，取消清空未提交草稿；切换分类关闭弹窗。创建结果未知保留原输入和键，先只读核对，不能通过取消或重开表单生成另一创建意图；身份失效或编辑器销毁清除私有数据。应用选择与集成配置是后端的必要差异，仍使用 Shared 契约。

## 布局与通用操作

- 正式界面的普通下拉统一使用半透明模糊玻璃触发器与浮层，不再出现浏览器原生下拉外观；语言、时区、筛选、排序、日志等级及 Provider、模型、目标等选择保持一致，当前值、占位、键盘操作和屏幕阅读器名称继续按实际选择控件工作。
- 全局 Toast 使用主题底色和轻微状态色，标题、细边框与确认按钮区分成功、警告、失败和信息。卡片依次展示标题与右上关闭、正文、底部操作行，不显示左侧状态图标；桌面同侧等宽 288px，手机左右各留 20px。无业务动作时底部提供“知道了”关闭提示；带恢复动作时显示原动作，点击后不会自动关闭。导航存在时在导航下方显示，避免覆盖页头操作；长正文自行换行。失败默认驻留直到手动关闭，成功/信息/警告默认 3 秒，调用方显式时长优先。当前可见的同类同文案去重，恢复范围不同的操作分别保留，错误另有 15 秒短期去重。同一网络故障统一通知，主动取消不提示；关闭 Toast 或恢复网络不解除未知结果保护、不重放写入。关闭按钮保留向外扩展的透明点按范围、无障碍名称与键盘焦点反馈。
- 工作区布局、快捷指令、命令历史，以及设置中的个人偏好、日志、安全、监控、外观、备份、宿主诊断和 Agent 管理的通用读取失败、保存结果与版本冲突统一使用全局 Toast，不在正文插入结果横条或自动弹出失败对话框。设置需要核对时，Toast 提供“重新读取”，关闭后仍可通过页头待核对入口再次打开；工作区布局、连接树及命令列表的错误 Toast 提供只读刷新，原有恢复按钮仍保留。关闭通知不解除写入限制，也不重放操作。字段格式校验、危险操作确认和未知结果的人工核对仍留在对应位置；CAPTCHA/Passkey 冷配置的待重启与保存成功说明只通过全局 Toast 展示，不插入分组正文，避免提示出现或消失时造成布局跳动。
- 导航高 48px，上下各 6px，桌面左右 8px、手机无额外边距，占正常布局且可隐藏；预留滚动条空间，设置/终端共用高度计算。
- 窄屏页面菜单/标签可访问所有入口，桌面窄栏支持鼠标拖动及原生触摸滚动；拖动不触发选择/切页或带动终端。
- 表单/编辑弹窗使用不透明主题底色；更新提示、确认提示与上传冲突使用统一玻璃浮层、标题图标和单一操作区，长内容可滚动。安全检查可展示结构化目标与指纹，警告/危险色只用于状态语义；手机操作按钮等宽且保持至少 44px，登录控件 44px，编辑器下拉紧凑。
- 工作区偏好扁平分组，手机单列/桌面双列，保留分组独立保存、未保存提示和高级折叠。设置页的保存动作统一放在对应分组标题右侧；工作区四组、系统语言/时区/日志、首页与监控、监控核心配置、安全密码/CAPTCHA、IP 白名单/黑名单和外观标题栏颜色均使用“保存”，两步验证启用后的禁用主操作也位于标题右侧。没有实际修改时按钮保持弱化且禁用，草稿与已保存值不同后切换为主题主操作样式。前、后端日志共享一个保存入口，拒绝时不显示成功。

- SSH/文件标签右键支持关当前/左侧/其他/右侧，分组名可点改；触摸终端规则见 [终端](#终端)。

### 核心持久设置

返回缓存的设置页面时，个人偏好与后端日志会自动只读重载。正常初始化和离页造成的读取失效不显示模块失败提示；真实读取失败或写入未确认仍提示重新读取。重新读取只核对服务器当前状态，不重放未确认的写入。

管理员使用 GET /api/v1/settings 读取 {version,effectiveVersion,requiresRestart,policy,effectiveMonitoring,captcha}；PUT 同路径提交完整 {expectedVersion,policy,captcha}。policy 包含 ipWhitelist、ipBlacklistEnabled、maxLoginAttempts（1–1000）、loginBanDuration（1–2592000秒）、statusMonitorIntervalSeconds / remoteHostRefreshIntervalSeconds（1–86400秒）、passkeys。白名单最多256条IP/CIDR、16 KiB；Passkey站点最多16项。未知字段、旧字符串字典、布局/外观字段均拒绝；个人偏好使用独立 /settings/preferences 与布局入口；外观使用独立设置入口。

CAPTCHA配置为 {enabled,provider,siteKey,expectedHostname,secret}，secret 显式使用 {action:'keep'}、{action:'clear'} 或 {action:'replace',value}；key最多1024 UTF-8 bytes，启用时须有效供应商、非空site/secret和准确hostname。更换供应商不能keep旧密钥。读响应只含hasSecret，不含明文或密文。匿名 GET /api/v1/settings/captcha 与 GET /api/v1/auth/captcha/config 都返回当前实际生效的公开验证码配置；管理员 PUT /api/v1/settings/captcha 只更新CAPTCHA，但与完整设置共享expectedVersion，返回安全配置及生效元数据。

正式CAPTCHA/IP安全面板加载已保存的完整配置，不将公共运行时CAPTCHA配置当编辑快照。各面板携带所读原版本保存；网络面板提交该快照的完整policy并保留其余字段和密钥，验证码面板明确选择保留/清除/替换密钥，只显示hasSecret。替换供应商时须清除或替换原密钥；验证码启用须有效site key、secret与预期hostname。版本冲突或写入结果未知后，先点“重试”只读重新加载，再核对并手动保存，不自动覆盖；离开缓存页或卸载清除未保存密钥。

采样周期在系统偏好与工作区偏好共用的“监控核心配置”中独立保存，两个周期均为1–86400秒，仅管理员可编辑，保存后热更新。组件不依赖其余个人偏好加载成功。GET 的 effectiveMonitoring 返回当前实际生效的两个周期，Dashboard使用该值轮询，返回页面时重新核对；其他已打开客户端在下次读取配置时同步，不推送浏览器配置。未读取或配置失效时暂停资源读取，可点只读刷新恢复，不用默认值或已保存值猜测。保存携带原版本及完整配置，保留其它policy、Passkey站点和验证码密钥；冲突/unknown先只读核对，再手动编辑。Workspace图表按真实样本时间与点数降采样，显示参数不修改服务器周期。

核心设置按实际消费者激活，不再统一要求重启：IP 白名单、登录黑名单开关/次数/封禁时长和两个监控周期保存确认后热更新；IP 策略用于后续请求，不踢出现有终端或清除已记录封禁。白名单立即影响新请求；封禁查询异步返回后再次核对白名单与当前黑名单开关，避免热更新期间沿用旧准入结果。保存前应确认当前来源仍在允许范围，保留部署恢复入口。状态订阅重新计时，在途采样不取消、不并发追加；资源 TTL 改变时清除旧成功缓存，在途成功按新 TTL 缓存。CAPTCHA 和 Passkey 站点仍在重启后生效，以保持认证挑战与可信 Origin 一致。读取安全配置时若已有这类冷配置待重启，以警告 Toast 提示；CAPTCHA 保存后需重启时显示成功 Toast，网络/IP 等热更新保存后显示“已保存并生效”Toast。两类提示都不占用设置分组正文。

version 为已保存版本；effectiveVersion 为最近一次全部字段均与运行配置一致的版本，存在未激活的验证码/站点更改时保持原值，requiresRestart 表示这类冷配置尚未生效，不表示监控/IP 热字段未应用。重启读取/校验/解密全部持久设置后才开放监听。已有配置不受初始化环境覆盖；数据库或密钥异常拒绝启动，不回落默认。备份恢复预检也复用同一配置解密与完整校验，拒绝会导致启动失败的配置。网络/主Origin/代理/加密密钥仍由部署提供；站点协议必须与监听主Origin一致，修改协议须同时调整部署后重启。保存成功不等于已通过实际外部验证码或域名配置验证。

请求/响应完整JSON最多64 KiB；400 invalid_input、401 unauthenticated、403 forbidden、409 version_conflict、413 limit_exceeded、415 invalid_input（媒体类型）、503 storage_unavailable/operation_unknown/internal_failure/unavailable。冲突先重新读取并人工核对；设置CAS在同一SQLite事务复查当前管理员会话，先完成撤销则拒绝写入；写入后认证失效、响应中断或未知提交可能已保存，恢复身份后只读核对version与内容，不自动重放PUT，也不以新版本覆盖。CAPTCHA/IP与采样周期正式面板已接新契约；Passkey 站点与其它系统设置也已接当前契约，行为覆盖以 testing 为准。

### 工作区可用面板

- 连接列表顶部只保留搜索与添加入口，搜索提示统一为“搜索连接”。宽栏直接显示分组连接、管理标签和删除分组操作，窄栏收进“分组操作”菜单。连接行在空间足够时显示名称、主机摘要与最近使用时间，极窄栏退回单行名称；启动页同时显示连接类型。点击连接，右键编辑/克隆/删除，批量连接确认与标签管理保持不变。
- 命令历史不再放常驻刷新按钮；搜索、紧凑模式和清空位于标题工具区，空态、无匹配和读取态使用统一状态组件。历史行显示命令与时间，点击执行，右键可复制、删除或发送到全部会话；清空仍先确认。
- Docker 使用统一容器卡片，窄栏保留启动、停止、重启和“更多操作”（移除、进入、日志），宽栏直接显示全部动作；展开后显示统计。读取、未连接、Docker 不可用和空列表均有独立状态，移除仍二次确认。
- 文件编辑器顶部保留标签与文件路径；编码、换行、保存状态、搜索、重载、保存和关闭统一放在底部工具栏，编码选择器按最长编码名称自适应宽度，窄栏按可用空间换行。桌面 Monaco 使用原生 VSCode 风格查找，保留匹配计数；手机 CodeMirror 使用适配窄屏的原生深色查找/替换面板。两者支持上一个/下一个、Enter/Shift+Enter 导航和 Esc 关闭；编辑正文、草稿与保存结果仍由原会话持有。

### 界面偏好、布局与焦点

连续调整字号或面板比例立即显示最新值，自动保存完成前保留预览，较早保存返回不会覆盖后续调整；保存失败会提示，并恢复已确认的设置。

GET/PUT `/api/v1/settings/preferences` 读取/替换当前用户的完整界面偏好；安全配置仍独立于 `/settings`。保留语言/时区、前端日志级别、终端/编辑器/预览/缩放、Docker面板轮询、标签显示、侧栏尺寸及桌面窗口尺寸字段。backendLogLevel通过独立 /api/v1/settings/logging 管理，状态采样/资源缓存间隔归核心policy；不会因保存UI字段修改这些后端限制。界面偏好仅接受当前完整字段，缺字段或已移除字段均拒绝，不补齐旧记录。语言仅en-US/zh-CN/ja-JP，时区必须有效；终端scrollback0–100000，预览行10–2000/列5–200，图片预览imagePreviewMaxMiB为非负整数（默认20，0不限，MiB换算字节需在JS安全整数范围内），桌面宽320–8192/高200–8192。

GET/PUT `/settings/layout`、`/settings/sidebar`、`/settings/focus-switcher-sequence` 与PUT `/settings/workspace-layout` 均安装；最后一项原子更新布局与侧栏。每项共享同一用户版本，未保存时明确version=0/默认布局，PUT带expectedVersion，首写变成1，冲突先刷新。布局用明确pane/container联合，id/size必填、ID及pane不重复，深度最多12/总节点100，容器至少一项；焦点最多32项、不重复，快捷键为序列项→字符串。请求/响应128 KiB，未知字段拒绝。

正式工作区与系统设置面板已使用这些接口。保存立即成为后续读取权威，无需重启；个人偏好、布局、侧栏和焦点共享版本。配置布局弹窗保存时核对打开时的布局与侧栏基线；同页锁定开关、其它偏好或焦点保存仅推进版本而未修改布局/侧栏时，使用队列中的当前版本继续保存，不必关闭重开。布局与侧栏作为整体核对，不拼接两份不同配置；两者确实被修改且与当前草稿不同，才提示冲突，需先点“刷新”并重新编辑。刷新会放弃当前未保存草稿。协议异常不会回退旧本地布局，工作区通过常驻 Toast 显示安全错误并提供只读刷新，不在终端布局顶部插入错误行。页面离开或身份替换取消尚未派发的保存；已派发结果未知时先读取核对，不自动重放。焦点快捷键仅对启用项保存，关闭某项同时移除其快捷键。

终端、命令输入栏和文件管理器上下排列时，拖动文件管理器上边界会联动终端高度，命令输入栏保持原有紧凑高度；上下往返拖动和分隔条方向键均受面板最小尺寸及布局锁约束。

点击工作区顶部导航的隐藏/显示后，导航、按钮状态和终端可用高度立即响应，保存沿原队列完成；连续点击保留最新选择，较早回执不会切回旧状态。保存失败时恢复已确认状态并提示；结果未知仍须刷新核对，不自动重放。离开页面或退出登录清除未确认的导航预览，重新登录使用当前账号的已确认配置。

工作区拖动尺寸、布局锁和顶部导航开关共享串行保存队列。尺寸自动保存只修改当前页面上次确认后调整过的容器比例，保留其它容器及偏好、侧栏和快捷键设置；同一容器的所有子项比例作为整体核对，避免合并出错误总比例。明确的版本冲突会先只读重新读取；布局结构及所改容器未冲突时最多再保存一次，已是目标尺寸则不重复写入。其它页面同时改了同一组比例、布局结构变化、恢复读取失败、再次冲突或写入结果未知时停止，Toast准确说明布局需要核对，并保留原刷新入口。刷新前保留当前拖动预览，保存回执不回写预览，避免跳动；尚未调整的远端尺寸会在显式刷新后显示。离页或重读后不再派发旧待保存尺寸，包括冲突恢复仍在读取时尚未派发的再次保存；已派发且确认成功的保存仍推进本地确认基线。配置布局遇到服务端明确拒绝的版本冲突时，同样只读核对完整快照；布局与侧栏仍符合原基线时最多再保存一次，已经是目标配置则不重复写入。重新读取失败、再次冲突或结果未知会保留草稿并停止保存。其它普通表单草稿仍绑定原编辑版本，未知写入不自动重放。

工作区、系统偏好及监控配置正常自动读取，读取失败、冲突或结果未知后才显示恢复刷新入口；首次加载不显示刷新按钮。布局与焦点配置的刷新同样仅在失败后提供，正常操作保持原版。

系统设置中的后端日志自动读取，并在前端日志同一分组右上角共享保存入口，失败或需要核对时才显示刷新，使用 /api/v1/settings/logging 的原版本CAS，不随个人偏好保存。级别仅debug/info/warn/error/silent，正文保留“前端日志等级”和“后端日志等级”两个同级标题及选择控件，两端控件顶边对齐，不显示当前生效级别；后端选择仍保留可访问名称，草稿变化后保存入口切换为主题主操作态。前端日志另支持trace。冲突或结果未知后必须只读刷新再编辑。客户端显示偏好不成为后端资源许可。

前后端日志均使用Pino：前端走浏览器日志输出，后端通过Platform日志实现同步写入stderr单行JSON，保留time/severity/code/facts字段、32项facts及16KiB限制，不增加pid/hostname或将凭据写入公开日志。日志设置、生效级别与审计持久化机制不变，不因更换库将前端日志自动上传至后端。

### 后端诊断日志

后端向 stderr 写入单行 JSON，沿用 `time / severity / code / facts`。默认 `info` 记录生命周期、核心状态及写操作；`warn/error` 记录拒绝、异常、未知结果和清理失败；`debug` 增加读取、SSH 建连、外部请求和数据流阶段。系统设置中的后端日志等级保存后立即影响全部这些日志，恢复备份后也使用同一实例与恢复的等级。持久设置加载前的启动早期日志使用默认 `info`；`silent` 生效后停止输出。诊断日志不额外存入业务数据库。

| 范围              | 主要事件与信息                                                                                                                                                                                             |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 启动、停机与重启  | `PROCESS_STARTING`、信号、`APP_STARTUP_*`、`HTTP_LISTENING`、`APP_SHUTDOWN_*`；重启表现为前一进程退出及新进程启动。配置失败只记录设置名称。未捕获异常按 Node 原退出行为处理，同时记录安全诊断。            |
| 数据库与恢复      | schema、启动文件恢复、模块初始化/关闭、Worker 不可用、备份预检/导出/导入、暂停准入/排空/应用/重建/恢复，以及失败或未确认。                                                                                 |
| HTTP 与 WebSocket | 所有注册 HTTP 路由的入口、状态、耗时、本地响应完成情况；WS 授权拒绝、建连、异常、队列/帧容量、输出拒绝、关闭码与进出字节汇总。路由用模板，不记录实际参数或查询字符串。                                     |
| SSH 与工作区      | SSH 建连/断线、PTY 打开、命令结算的退出状态/字节数、清理；Workspace 附着/分离/挂起/恢复/关闭及文件附件状态。                                                                                               |
| 文件与后台任务    | 文件操作开始/完成/失败、机器突变占用与未知结算、服务器传输的开始/取消/子任务失败/最终状态、依赖安装。                                                                                                      |
| 监控与 Agent      | 首次采样失败、连续失败的 debug 及恢复成功；Agent Run、模型派发提交、流读取、步骤完成/失败和清理；后台 Job 接纳/派发/结算/取消/排空、插件实例预留/激活/异常退出/关闭与恢复、通知派发/结算与外部 HTTP 请求。 |

`facts` 中按链路包含 `requestId`、`socketId`、`workspaceId`、`sshId`、`fileOperationId`、`taskId`、`runId`、`jobId` 或 `instanceId`，可按同一 ID 串联入口、派发和失败。HTTP 的 `responseFinished` 仅表示本地响应完成，WS `outputTransportBytes` 含协议开销；均不证明浏览器已收到或处理。后台任务的 `TASK_SETTLED` 表示执行 owner 已结算，最终业务结果仍以持久 Run/任务状态为准。

Docker 部署可执行 `docker compose logs --tail=200 -f` 查看；按事件 `code` 或关联 ID 筛选。排障时临时将后端等级设为 `debug`，复现后改回 `info`。终端和文件数据流不逐块打印，避免日志量拖慢交互。日志不包含密码、令牌、Cookie、密钥、命令正文、终端内容、文件内容、外部 URL 或模型对话；异常只保留有限类型/代码/分类、源码位置及最多四个原因节点，不打印原始异常正文。每条日志最多32项 facts、16 KiB，额外原因有界省略，`errorBranchesOmitted` 记录当前已知未遍历原因分支数（不递归计算其后代），`factsOmitted` 记录被省略字段数。诊断输出失败不改变业务结果、重试策略或清理流程。

## 关于与更新检查

更新比较使用标准 SemVer，支持发布标签的 `v` 前缀和预发布顺序；无法解析的版本不提示存在更新，避免把任意不同字符串误认为新版。

设置 → 关于使用“应用信息”分组，以版本和项目地址两张等宽信息卡展示：宽屏并排，窄屏按单列堆叠并保持整行宽度，长仓库名在卡内省略而不产生横向滚动。版本卡显示当前前端版本和自动更新检查结果；有更新时点击状态徽标进入对应发布页，检查失败只显示失败徽标，不阻断其他设置，重新进入页面会再次检查。项目地址卡打开 GitHub 仓库，不用文字竖线把版本与仓库入口拼在同一行。

## 外观自定义

支持明暗、终端配色、页面/终端背景、工作区样式。设置统一分区/控件：桌面使用带左侧选中指示线的紧凑纵向导航，窄屏只显示当前分类选择器，展开后以单列菜单切换四项；主题/HTML 背景共用搜索，主题可下拉切换，长名称和手机按钮不横向溢出。

内置背景深黑，应用时保存内容副本，预设更新须重新应用。动态背景在可见且尺寸有效时独立加载，不等待终端字体测量；切换会话时保留已加载文档，隐藏暂停动画，返回后主动恢复并同步尺寸，无需点击或重新应用主题。减少动态效果时保留静态画面，尺寸变化或恢复后允许补画。主题须自行处理 resize；沙箱不加载外部脚本、字体或网络资源。浏览器完全冻结期间无法绘制，恢复后再同步。

手机/粗指针 HTML 动画最高 20 帧/秒，不可见暂停帧/CSS，减少动态效果只保留首帧；不限制终端/桌面，自定义 timer/视频仍可能耗资源。

### 外观与 HTML Theme

支持本地 HTML 和 GitHub catalog；按当前 Shared 契约读取和保存，不自动转换旧配置或重写第三方仓库地址。内容 API 返回文本，终端只在 sandbox iframe 执行，GitHub 来源不意味着可信。

### 主题升级与背景保存

- 删除活跃主题同事务清空设置引用；同名新 preset 将用户主题改名“原名 (user ID)”（冲突再编号），保留颜色/ID/引用。
- 上传/删除顺序执行；删背景先清设置再删文件，设置失败不先删，清理失败记诊断但不改变已清引用结果。崩溃可能遗留文件，非文件/数据库跨资源原子更新。

正式外观设置、自定义面板与 Workspace 字体已接 Shared 和新 Access 会话。编辑草稿保留原版本；冲突或结果未知先点“刷新”核对，刷新会丢弃草稿，不自动重传。字体预览与保存快照分离，预览结束恢复保存值。主题/背景/HTML 库均沿现有入口，不保留旧响应兼容。

### 宿主诊断

管理员 GET /api/v1/system/diagnostics 读取采集时间、运行时、进程 RSS、主线程已用堆/堆容量/外部内存/ArrayBuffer、进程累计用户态/内核态 CPU 秒数、当前诊断实例启用后的主线程 GC 次数/耗时、模块资源及数据库可用性/版本，响应最多16KiB。使用 prom-client（官方后继包 `@prometheus-io/client`） 的私有 Registry 聚合，不需安装 Prometheus，不开放公共抓取或调试端口。进程/模块/数据库并非同一物理采样时刻，不含路径、环境、连接 ID 或业务内容。Agent 的 host_diagnostics_read 仍需单独 host.inspect grant，默认不授予；与普通SSH目标诊断分开。

设置 → 数据 → 诊断与恢复（高级）→ 宿主诊断，展开“内存与模块资源明细”查看各组。明细先显示可折叠的统计口径，再以进程开销网格和模块卡片展示资源；模块按内容自适应排列，指标较多的模块横跨整行，仅统计数量的模块使用“仅统计数量”徽标，不重复插入长说明。七个业务模块均显示在途 HTTP 请求；终端与远程操作另显示普通工作区、挂起标记/断开记录、输出/输入/日志写入/恢复缓冲数据量、活动传输/保留记录和状态订阅；Agent 显示活动执行、在途写入与操作；数据库显示已派发未结算的 Worker 请求、排队及执行中的操作和主库 Worker 的独立已用堆/堆容量/外部内存/ArrayBuffer；事务按一项操作计算，不重复累计内部 SQL。系统显示诊断在途。仅有资源数量的模块明确标注尚未计量内存，未接入或采集失败单独显示，不以零代替缺测。

除数据库 Worker 明确列出的独立线程内存外，其它模块字节值是 owner 跟踪的逻辑缓冲数据量，不包含全部对象、底层分配、后台终端解析器或原生句柄开销；不同类别可能共享数据，不应相加或从 RSS 相减来推断剩余占用。RSS 是整个进程，主线程堆不包含数据库 Worker 的独立堆；每个线程的 ArrayBuffer 已包含在对应 external 中，不可重复相加。数据库 Worker 数据不含 SQLite 原生页缓存，也不覆盖临时恢复预检 Worker；诊断消息不执行 SQL，不进入事务队列，但仍需等待 Worker 当前同步任务完成。GC 不追溯本次诊断实例启用前的事件。进入或重新激活数据页时读取，多个调用合并采集、成功快照最多复用一秒，不新增后台轮询或“四个请求”拒绝限制；身份检查仍逐次执行。隐藏页面或身份失效撤销原展示，失败不补默认指标。当前仍未完整计量第三方原生句柄、全部 JS 对象及其它缓存的模块归属；这些缺口不按零显示，也不从 RSS 差值猜测。诊断不执行强制 GC、堆快照或常驻堆采样；停机和在线恢复会退订采集器。

## Dashboard

连接目录完成后结束 loading，挂起会话独立加载。桌面宽度达到 1100px 时使用一屏布局，内容区最大宽度 74.25rem 并居中，连接区在剩余高度内滚动且不产生页面纵向滚动。顶部保留连接总数、标签数量和 Nexus 本机资源摘要，不展示最近连接或重新连接快捷入口；下方不再分左右栏，也不展示最近活动。搜索、标签和排序控件直接排列，不额外套一层卡片外框。窄屏按“统计、本机、连接卡片”自然排列，不压缩卡片，也不产生页面级横向溢出。

连接卡片按 SSH、RDP、VNC 分区展示，只有当前实际存在且通过搜索/标签筛选后仍有内容的类型才显示分区标题和数量。标签紧接连接名称后的协议标签展示，不单独占用卡片底部一行。默认按服务端最近使用时间降序，可选择名称、类型、修改时间或创建时间；切换字段时名称/类型默认升序，时间字段默认降序，排序方向仍可手动切换。标签、搜索和排序选择保留在当前浏览器，点击任意卡片直接进入对应工作区或远程桌面。

同一类型分区内的连接卡片固定同等宽高。SSH 卡片高 188px，使用环形指标展示 CPU、内存和根磁盘占用，环形进度与实际百分比一致，缺测值显示占位符而不是补零，具体内存/磁盘用量显示在对应圆环下方；等待数据、资源检测关闭或读取失败也占用同一内容高度，不因状态改变卡片尺寸。状态下方以较小字号展示“上次连接时间 | 本次更新时间”，左侧为相对时间，右侧为刷新时刻，细竖线分隔；完整含义保留在悬停提示中。RDP/VNC 使用 76px 紧凑卡片，只保留连接信息、状态和上次连接时间，不显示资源占位区，不伪造在线状态，也不混入 SSH 资源指标。资源检测关闭或监控配置不可用时显示有限状态提示。本机资源固定显示运行 Nexus 的宿主机，不提供“本机连接”配置项，也不从连接列表识别本机；隐藏或读取失败时保留恢复入口。本机后台按配置周期刷新，刷新按钮外观保持稳定，后台请求不播放旋转动画；用户点击时复用同一在途读取并在请求结束前显示旋转，不重复派发。本机与 SSH 的根磁盘百分比统一按 `已用容量 / 总容量 × 100` 计算，不采用扣除文件系统预留空间的 `df` Capacity 字段；容量字节仍来自各自真实采样，百分比限制在 0–100%。

本机与 SSH 资源显示最后一次成功采样的刷新时间。后续刷新失败时继续显示最后成功的指标和该成功时间，只在状态处标记“刷新失败”；尚未取得过成功结果时才显示资源不可用提示，不能用失败占位覆盖已有结果。

路由离开 Dashboard 即停止本机 status 与 SSH 资源摘要的周期请求并取消在途读取；已排队回调同样核对当前路由，不在其它页面继续采样。保留最后一次成功状态，返回时先显示缓存而不清空跳变；全部主机采样成功时，同一刷新周期内返回不重复读取；存在主机未受信或其它采样失败时，返回首页重新读取，不复用成功刷新间隔，确认主机密钥后无需刷新网页。周期外后台更新时也保留旧结果直到新结果到达。挂起目录由登录级独立 WS 同步，不随首页停用；打开工作区或恢复健康前台不额外请求 HTTP 目录，需要恢复的断开挂起会话仍读取权威目录核对归属与状态。退出登录或切换用户会清理原会话标签与本地资源；本地标签移除不代表远端关闭已确认，关闭失败或 unknown 仍单独保留诊断，不自动重放操作。

资源按主机去重、主机间隔 200ms 请求，独立显示成功/失败，不一次全量启动；页面销毁取消待请求，不让单主机失败阻止其他状态展示。采集与缓存见下节。

## 状态监控与 Docker

网络卡片的上传、下载数值在各自半栏内居中，保持分隔线两侧留白；窄栏及矮栏继续沿用紧凑自适应布局。

Workspace服务器状态使用透明外层表面，不绘制整块外框或底色；标题分隔线与内部指标卡边界保留；指标卡区域收紧左右外侧留白，加载骨架使用同样的紧凑边距，窄栏和矮栏继续自适应。顶部主机状态使用小圆角芯片和加粗主机名，较窄面板隐藏复制装饰以完整显示名称。面板宽度允许时，CPU、内存、Swap 与磁盘使用 2×2 等边方形卡片，卡片内按图标/标题、详情、百分比和进度条重排，容量详情随可用宽度缩放并换行而不省略；网络使用通栏卡片，左侧图标跨标题与速率两行垂直居中。更窄的纵向面板保持单列卡片，避免压缩文字。网络标题与上下行速率保持紧凑但清晰的分隔；矮面板将上下行速率放到“网络”标题右侧同排显示；收紧面板与卡片左右留白、图标和上下行间隔，标签与百分比略缩小，网络数值按面板实际宽度自适应字号，优先显示完整数值与单位，避免省略号遮住速率。字体只在数值处调整，不叠加父级缩放；加载骨架沿用单行排列。趋势模式下网卡名贴网络行右缘显示；趋势当前值位于标题右侧；网络趋势左侧完整显示标题，右侧上下行速率及颜色标记保持同排，最窄栏位和手机弹窗也不换行；速率文字按实际可用宽度缩放，1/5/10/30分钟选项固定在标题区域下方。趋势标题与 1/5/10/30 分钟选项使用更紧凑的字号和行高，缩放面板时保持清晰及原键盘选择入口。连接中或首轮采样时显示紧凑加载标题与五张低对比骨架卡，骨架尺寸随窄、中、宽栏与最终指标布局一致，不使用大块“等待数据”占位。未连接、拒绝主机信任、取消或断开后停止加载并留白，不显示指标和趋势；成功连接且取得样本后恢复原监控视图。具体连接失败与任意键重试提示只在终端输出，已连接时的采样失败仍显示原安全错误，不自动信任。

服务器状态趋势选择 1/5/10/30 分钟时，横轴始终覆盖对应的完整时间范围，右端为最新采样时间，左端为对应分钟前；连接时间较短或历史不足时左侧留空，不缩短时间范围、不补造采样数据。各范围保留真实采样的数值和时间，短历史不合并成隐藏的单点；单样本和断点两侧的孤立样本显示小点。缺测、采样失败或停止后恢复保留断点；采样序号连续但实际时间明显中断时，也按完整历史的常规采样间隔断开曲线，不跨空白画斜线，不删除先前的真实样本，各时间范围采用相同判据；选中指标缺测时横轴仍跟随最新监控采样。悬浮提示只显示同一采样时刻的数据，不按不同序列的数组位置拼接上下行。

趋势图下方的时间刻度保持紧凑单行，面板缩放后仍维持相同的文字和间距占位，给曲线保留更多高度。图表加载时在原绘图区显示淡色网格与居中加载提示，使用轻微呼吸效果；系统开启减少动态效果时停止动画，加载完成后原位显示真实曲线。

服务器状态趋势的网络纵轴使用同一组 B/K/M/G 二进制单位和整档步长，避免十进制字节刻度转成 4.8M、9.5M 等不直观读数；纵轴文字更紧凑，空闲时保留 0、1 两档，不重复显示相同刻度。各时间范围仍按可见流量自动缩放。

多 SSH 标签切换保留各会话自己的状态指标、历史及趋势选择，不重建桌面状态面板；最后一个可见状态面板离开后，原订阅继续保留30秒，期间返回不重新初始化采样。超过30秒停止采样并保留最近展示数据，返回后先展示原数据、再恢复实时采样；隐藏期间不补造历史点。实际断开或会话销毁会清理订阅及缓存，不复用其它连接的数据。手机状态浮层仅在所属会话激活时显示。

监控设置把“显示本机资源”“显示远程资源”与对应采样/缓存周期放在同一开关卡片内，“默认展开容器详情”与 Docker 状态刷新周期同卡展示，分组只保留一个保存入口；当前生效间隔继续显示在分组标题下，保存即应用，不展示内部配置版本或待重启提示。个人显示偏好与管理员核心周期仍分别使用原接口、权限和版本，同一保存动作只提交实际有修改的部分，失败部分保留草稿并保留只读核对入口。IP 设置保存提示已生效；只有验证码/Passkey 站点保留真实待重启提示，失败仍通过 Toast 提供只读核对。

- 默认显示在线状态，可设置显示/复制 IP 和图表缩放；Docker轮询默认5秒。远端实际采样使用服务器生效配置，调整图表显示不改变采样周期。
- 首次数据到达前显示可访问的骨架加载态，窄栏与宽栏均保持最终卡片尺寸，不因状态切换跳动。矮面板中的指标图标高度随卡片可用空间收缩，避免超出卡片；正常尺寸保留原大小。CPU/内存/Swap/磁盘/网络显示实时数值、总量/单位，适应宽窄矮栏，历史可切指标/时间并关闭；历史采样短于所选区间时按实际已采集跨度自适应窗口，避免图表长期停留在空白区间；极小面板存在可读性限制。
- 指标提示支持悬停/键盘聚焦并原位更新，不重启原生 title。
- Docker 容器名称保持高对比，镜像使用信息色，端口与统计字段名使用清晰的次级文字；运行、停止、暂停等状态保留文字与语义色徽标，卡片底色及展开态随深浅主题调整。Docker 统一使用容器卡片；Start/Stop/Restart/Remove 管容器，Enter/Logs 进入当前 Workspace。窄栏将 Remove/Enter/Logs 收进“更多操作”，宽栏直接显示全部动作。
- 缺测显示不可用，历史不补零。读取失败与Docker未安装分开提示。操作进行中禁止重复派发；结果未知时先人工核对远端，再使用“只读核对最新状态”。轮询成功不会解除未知保护；只读核对仅解除本页保护，服务器持久围栏仍须按下节恢复。已确认命令后的刷新失败不表示命令失败，不要重做。关闭/停用面板取消原删除确认，重新打开不会继续旧确认。

### 机器突变恢复

Tool 账本派发、原子消费批准或完成事务的确认未知时，不补写推测状态、不继续模型步骤、不重放原操作。重启按原持久账本围栏未完成项，已提交的 completed 结果保留；原远端效果与持久确认分别核对。ACP/后台 Job 即使真实进程已退出，也必须等已开始的权限监控收敛；监控存储失败保留至停机，恢复不自动释放原机器突变围栏。

机器突变恢复的阻塞、任务状态与人工证据结果使用对应语义色徽标，普通计数保持中性。设置 → 数据 → 机器突变恢复提供管理员列表、详情、人工证据和独立解除入口。逐项勾选生产者及关联资源已停止，填写实际观察时间、结果和证据说明；记录后必须重新明确选择最新证据，再单独确认解除。不会自动勾选、选择证据或重试原操作。隐藏页面取消原确认及草稿；写入结果未知或版本冲突后暂停写入，必须显式刷新权威列表和原操作详情后重新核对。

普通文件、Docker 控制与 Agent 远程突变共用持久围栏。管理员用完整会话访问 GET /api/v1/remote/mutations?limit=20&after=<cursor>（最多50项），或 GET /api/v1/remote/mutations/:id，查看原目标 ID/配置指纹、来源、状态、修订和不可变证据。分页按 ID 排序，不是全局时序快照；原 Agent claim ID 对应 ToolCall 操作身份。held 表示正在使用，blocked 表示执行或清理未确认，released 只表示已解除准入，不证明原操作成功。

1. 先独立核对原执行生产者已停止、全部关联资源已停止及远端实际效果；不能确认就保留 blocked。重启和 owner ID 不同都不证明进程或远端副作用已停止，当前实例产生的阻断返回 resource_active，须先完成原 owner 的退出。服务不自动连接远端探测、杀进程或重放任务。
2. POST /:id/evidence，提交 {expectedRevision,outcome,producerStopped:true,resourcesStopped:true,observedAt,note}。outcome 为 applied/not_applied/partially_applied，observedAt 为不早于 blockedAt 的毫秒时间，note 最多1024 UTF-8字节，写清独立核对依据，不含秘密或原始命令。证据明确来自管理员，不冒充自动技术测量；保存后取得新 claim 修订和 evidence ID。
3. 再 POST /:id/release，提交 {expectedRevision,evidenceId,confirmed:true}，引用最新证据和新修订；冲突重新查询，不能套用新版本自动重试。解除与锁移除同事务，原证据和 Tool/Job/Run 的 unknown 历史不变。需要再次执行时另建新意图，不恢复旧任务。

每个 claim 最多16份证据，不设置未释放claim或活跃资源的全局数量门槛；独立服务器的操作不会因其它服务器记录较多而拒绝，原阻断/释放与人工证据继续保留，不覆盖未知占用。完整 JSON 请求16KiB、响应8MiB。证据或释放响应中断、存储/审计失败可能已提交，先 GET 核对，不自动重放；恢复写入暂停后只读查询仍可用。每步在实际事务入场及读取交付/写入提交前复核原管理员会话，末次复查失败回滚本项写入；记录 REMOTE_MUTATION_EVIDENCE_RECORDED/REMOTE_MUTATION_RELEASED 审计。备份包含阻断与恢复证据，恢复不自动重派。

设置 → 数据 → 诊断与恢复（高级）默认折叠；展开后只展示宿主诊断与机器突变恢复。宿主诊断只读展示运行时、运行时长、驻留内存、主线程堆内存、数据库版本和采集时间，并在内部折叠展示 prom-client（官方后继包 `@prometheus-io/client`） 进程及模块资源明细；机器突变恢复保持权威列表、独立证据与释放入口。插件安装恢复、插件数据迁移、已安装版本和运行态核对的当前前端入口已移除，后端接口暂时保留。两个保留分区在进入或重新激活时自动读取，读取失败通过全局 Toast 提示，正文不保留常驻刷新按钮。

## 安全与认证

主动退出登录会撤销旧会话的读取、自动保存与通知意图，不因这些正常取消弹出“操作失败”或“个人数据请求失败，请重新读取”。退出清理期间短暂出现的连接列表不再请求数据或提示会话失效。退出后旧通知的“重新读取”不能继续请求旧个人数据；重新登录重新建立当前会话。退出接口本身失败仍显示错误并核对会话状态，未确认写入不视为回滚，也不自动重放。

IP 黑名单开关切换即保存并热更新，只提交该开关，保留且不提交相邻白名单、次数与时长草稿；白名单和封禁参数保存也无需重启。明确失败恢复原开关，冲突或结果未知先刷新核对。

支持密码、Passkey/WebAuthn、TOTP 2FA、hCaptcha/reCAPTCHA、IP 白/黑名单、登录通知和审计。Passkey 配置见 [部署文档](DEPLOYMENT.md#配置与数据)。

Passkey 注册和两步验证启用等分组主操作固定在标题行右侧；两步验证进入扫码配置后隐藏启用入口，禁用仍需在密码确认表单中完成。

### 初始化、因素与会话

- 空库初始化仅成功一次；已初始化时在密码哈希前返回“已初始化”，避免重复初始化请求继续消耗哈希资源，并发创建仍由数据库事务保护。此保护不验证部署者身份；没有部署 token，先在受控网络建管理员再开放。
- Session 目录 0700、文件 0600，权限失败/异常条目拒绝；仍明文，不隔离 root/同 UID/额外 ACL，保护数据与备份。
- 新增 Passkey/启用 TOTP 由完整会话授权，无统一 recent-auth；改密码/禁用 2FA 仍验证密码。新因素不撤销泄露旧会话。
- 部分 2FA 会话固定 5 分钟、不续期，Backend 最多 64 个，满载拒绝；记住我第二因素成功才生效，不是完整会话/磁盘总配额。
- 2FA 验证失败记 LOGIN_FAILURE、通知及 IP 失败；不存验证码/secret，投递依实际配置。
- Passkey discovery 可公开配置状态、credential ID/transports，标识不是秘密，须签名验证；false 不区分账号不存在/未配置，无专用限流保证。
- 登录页在窄屏（不超过 560px）隐藏品牌图片区，仅保留垂直居中的登录表单，并在登录标题上方显示项目图标；主题切换固定在右上角。手机高度不超过 760px 时使用紧凑间距。561–900px 平板保持上下布局且主题切换与标题同一顶线，矮横屏切换为双栏。错误或二阶段提示需要更多空间时允许页面滚动，不裁切字段和 Passkey 入口。认证成功后导航栏、Agent 浮层与目标页面同时切换，不在登录或初始化页面上提前显示已登录外壳。
- 启用 2FA 约束新密码登录，不自动注销/重挑战已有完整会话。

### 认证并发、撤销与秘密存储

- 正式设置页改密已对接新契约：提交期间防重复；确定成功回登录页，结果未知先核对会话、不自动再提交。改密码失效所有旧 session/WS，旧无凭据版本会话也须重登，Passkey 可继续认证；已接纳副作用不回滚。
- 登出撤销同 session 的 Workspace/上传/桌面/Agent WS，包括其他页面，不撤其他 session；前端缓存/传输轮询清空，晚响应不回填，交错握手可能拒绝。
- 同 session 只支持一个 Passkey 注册/登录 challenge，新流程失效旧流程；失败重新发起。提交重检签名计数器，并发旧快照拒绝；同步零计数器不要求递增。
- TOTP/CAPTCHA/通知配置按实例密钥加密，不提供旧明文启动迁移；错误密钥拒绝解密。备份配置 envelope 加密、导入用目标密钥；用户/TOTP 不在 Full Backup。旧页/WAL/外部备份不擦除。
- 生产建议 HTTPS。

### 来源、反向代理与网络准入

普通写请求检查 Origin/Fetch Metadata，兄弟域 same-site 不放行；无 Origin 的 same-origin 或无浏览器 metadata API 客户端可用，认证不变。Agent 使用同一来源检查，不提供旧 CSRF token 端点。WS 只在可信 TCP peer 时采用 forwarded host/proto，不读取 X-Real-IP，Origin 不替代认证。

代理须正确覆盖外部 Host/Proto/来源。宿主 NEXUS_TRUSTED_PROXIES 默认 loopback，自定义代理指定精确 IP/最小可信 CIDR；Compose 默认仅信任隔离网络中的受控代理，不公开 Backend；Frontend 信任私网入口，必须保护转发路径，不能让不可信私网 peer 伪造 IP。具体示例见 [部署文档](DEPLOYMENT.md#https-与代理)。

### 来源与登录失败策略

- loopback/RFC1918/IPv6 ULA/link-local（含 IPv4 映射）豁免 IP 白名单/失败封禁，不免密码/2FA/Origin；旧内网黑名单行可保留但不阻断。
- 公网按配置阈值/封禁；到期后下次失败开启新周期，未到期不追加延长。并发失败原子累计，仅首次进入封禁触发通知。
- 7 天无新失败且封禁结束可惰性清记录，每 5 分钟至多清一次，不删活跃封禁；分页最多 200，完整列表JSON最多256KiB；正式面板每页50项，可前后翻页并单独刷新，解除使用集合DELETE的JSON正文而非IP路径。解除结果未知先只读刷新，不自动重复；时间戳对外为 Unix 秒、内部存储毫秒，无保留期来源总量配额。

### 审计日志

操作记录以时间线展示：时间列、事件类别节点和事件内容分离，摘要仅含用户、来源IP、资源ID、路由模板、HTTP状态码和有限事件名称，不展示任意原始详情。支持关键词防抖、操作类型筛选及全部时间/最近24小时/最近7天/最近30天范围；每次筛选、页面重新激活或读取失败后手动重试时按当前时刻重算时间范围，翻页沿用本次读取的范围。每批40条，按服务端 nextOffset 近底或手动续页；只显示已加载数量，不虚构总数。读取失败保留旧项并提供重试，筛选/离页/身份失效取消原读取，旧结果不能覆盖当前列表。长对象和路由可换行，窄屏保留时间线并纵排，使用动态虚拟列表。

页头可在“操作记录”和“通知投递”之间切换。通知投递视图使用同一时间线样式显示事件时间、事件类型、投递状态、渠道编号和可选更新时间，保留 queued/dispatched/sent/failed/unknown 的原始语义；渠道已删除时不显示伪造名称，提示“渠道已不可用”。结果未知的已加载记录显示数量提示，重新读取和继续加载不会重发通知。切换视图或离开页面取消原读取，旧会话结果不覆盖新视图。投递记录仍由 `/api/v1/settings/notification-deliveries` 只读提供，写入和派发语义不变。

SSH Key 新增/更新/删除记录 ID、操作者、来源、字段名，不记录私钥/passphrase，无额外外部通知。

通知管理的 320px 窄屏表单中，事件订阅仍使用可点击的复选框及完整事件名称，长翻译文本在所属选项内换行，不缩小控件或裁剪字段来规避溢出。渠道的 Secret keep/clear/replace、投递状态及失败恢复语义不变。此 UI 改动待完整远程 E2E 验证。

### 审计保留与失败

保留 50,000 条，新增/按时间及 ID 裁剪同事务。审计 best-effort，故障记安全诊断，不回滚已提交业务，也不保证存储故障时全部落库。

## 备份与恢复

Compose 部署在 `.env` 用 `NEXUS_DATA_DIR` 指定宿主数据目录，默认 `./data`，容器内统一挂载为 `/app/data`；自定义目录后，外部备份也须使用该实际路径。桌面连接不再需要 guacd 服务或相关环境变量，详见 [部署说明](DEPLOYMENT.md)。

实例使用一个独立数据目录，`NEXUS_DB_PATH` 指向其中的数据库文件。默认结构为 `data/nexus-terminal.db`、`data/appearance/`（背景资源）、`data/artifacts/`（Agent 附件与产物）、`data/plugins/`（插件包）；数据库目录即实例数据目录，不同实例须使用不同目录，不能仅更换同目录下的数据库文件名。启动自动创建资源子目录，SQLite 的 WAL/SHM 及恢复临时文件也保留在数据目录内。本次为破坏性布局调整，不读取、迁移或自动删除旧的 `nexus-terminal.db.appearance/`、`.artifacts/`、`.plugins/`；部署使用新的空数据目录，不将旧数据库单独拷入新目录。停机外部备份需保存完整数据目录及实例密钥，不能只复制 DB；应用内导出/导入仍使用原备份入口和逻辑文件分区。

新版完整备份包含 SSH 私钥、私钥口令和已确认的主机信任记录（Host Key trust：host、port、fingerprint、confirmedAt）。恢复时信任记录按备份整体替换，不与目标实例原记录合并；备份没有信任记录时恢复后也为空。主机实际指纹与恢复的记录不符时仍拒绝连接，需要核实后重新确认。此处为源码链路核对结论，信任记录恢复专项尚未在本批执行行为验证。

普通连接导入支持密码、已有 SSH Key 引用及随连接创建私钥，不导入 Host Key trust；导入连接不代表信任远程主机，首次连接仍需确认指纹。

数据管理页的备份导入文件选择框使用可见的圆角、边框、主题背景和键盘焦点状态；长文件名在窄视口内裁剪，不使页面横向溢出。文件格式、完整会话授权、导入前确认及未知结果围栏保持不变。

导出和导入继续使用旧版按钮行与就地结果提示：成功、失败和未知信息显示在对应表单内，不把两类操作的结果合并到页面底部。恢复成功后的全局回执、明确重载和未知围栏仍由恢复遮罩持有。

完整认证会话可导入合法备份，同实例用 instance key，跨实例需备份密码；校验完整性/密钥，不含认证表。无额外 recent-auth/服务端破坏式确认，导入前核对目标，合法旧备份可能回放旧状态。

正式设置的数据管理页已对接 Shared 与新 Access 会话。Backend 已安装 `POST /api/v1/settings/backup/export`：完整管理员会话提交 JSON `{password}`，验证当前密码后下载二进制 `nexus-terminal.nexus-backup`。密码提交后立即清除本地草稿，隐藏数据页也清除密码和所选文件。后端已接入同路径 backup/import，使用 multipart backupFile 和可选 password；仅完整管理员会话可导入最新备份，不兼容旧备份。password 用于备份解封：同实例可省略，跨实例需备份密码，不是再次验证当前登录密码。B10 已验证隔离实例的加密导出、损坏密文拒绝、同实例 multipart 恢复和现有 HTTP 消费者重绑；跨实例已验证不同实例密钥下的附件字节恢复、SSH 私钥及 Provider 凭据真实使用，目标实例密码与当前会话保持；上传取消释放备份名额，等待上传期间登出阻止导出。故障/未知提交、背景与插件原包恢复等其余专项仍待验，不能视为完整恢复验收。未修改过日志级别时也可备份，恢复继续使用默认日志级别，不需先保存日志设置。恢复预检复用连接元数据、关系图和凭据类型规则；RDP/VNC不能引用SSH Key。非法ID/版本/时间、超容量或非法Unicode元数据、超过16个直接跳板、损坏凭据均拒绝，不自动修补。便携明文秘密在重新加密前校验容量；损坏当前秘密导致导出不可用，不生成无法恢复的文件。

新导出采用最新 NXSEALED2 认证加密封装，载荷及数据密钥分别保护，包含同实例密钥包和密码密钥包；跨实例秘密以受加密保护的明文传递，不复制源实例密文。覆盖五个产品模块的88张固定表和被引用的背景、Artifact、插件原包；HTML自定义库及活动副本已在SQLite。认证表、会话、模型目录缓存和活跃进程目录不导出。

新导出的快照最多64 MiB，文件最多100 MiB；导入/导出共用一个在途名额，输入、预检和执行共用120秒期限；导出的交付也计入期限。采集前后核对全部表内容，复用实际持久记录解码器和跨表读取，检查跳板关系/成环/展开上限、Agent 声明与签名插件包一致性、文件实际大小/hash、外观引用和插件清单/签名；上传/发布/删除中的内容或数据变化返回`source_changed`，稍后重新导出，不返回缺引用包。文件句柄清理未确认时停止新的导出；下载断流须重新导出。普通隔离导出/同实例恢复已执行 B10；跨实例与上传中断后的名额归还已完成隔离回归；容量极限、完整期限与提交/清理异常等其余场景仍待验。

### 容量、一致性与运行资源

| 范围              | 限制                                          |
| ----------------- | --------------------------------------------- |
| V1 快照 JSON      | 64 MiB，文件读取前计算 base64 膨胀            |
| 编码导入/导出文件 | 100 MiB，超限明确失败；内存生成，不保证低内存 |

- Artifact 配额不等于备份容量，保留整个 data 的外部备份，勿因导出失败盲删数据。
- 表快照短暂阻塞数据库，扫描文件不占事务；非跨文件/数据库同一物理时点。验证 ready Artifact 大小/hash、Plugin 包/入口/清单，缺失或并发变化拒绝，不交付缺引用包。
- 后端先完成解密和隔离预检，再暂停 HTTP/WS/public 能力并排空旧 owner；不能安全排空时停止准入。文件和数据库按持久日志及同事务提交标记对账，确认成功或回滚后重建全部模块和接口。
- 既有专项已验证真实进程在暂存、完整目录发布、未提交事务、提交后及清理后被 SIGKILL 的技术恢复；真实应用启动已验证前两种未提交恢复。日志损坏或提交证据不可读时保留现场，修复依据后再启动，不删除日志强行运行。逐个目录切换中途、实际 SQLite COMMIT 成功但调用方尚未收到确认，以及恢复回滚/清理中再次 SIGKILL 已有限验证；已提交恢复的应用 owner 初始化失败会保持 HTTP 暂停，重启后使用同一恢复标记完成初始化，附件和 SSH 凭据可用。上述不等于断电或持久介质故障通过。
- 正式导入先明确确认替换业务数据；开始后全局阻止旧页面操作。确认恢复后显示回执，必须点击“重新加载应用”后继续；不自动重载。结果未知保留全局提示，即使认证重置也不解除，不提供再次导入或推测性重载。
- 导入响应为 restoredTables/restoredRows/restoredFiles/cleanupPending；cleanupPending 只表示已确认恢复后的旧文件清理待续，不表示恢复回滚。operation_unknown、重建失败或响应断流可能已经恢复，不能自动再次导入；保留数据现场，通过重启对账和只读状态核对处理。
- 认证表和当前会话不恢复；旧模型/工具/Job 不自动续跑，派发未知状态仍保留。历史 queued 通知结算 failed、dispatched 保留 unknown，旧审计不重新派发通知；导入的插件运行时不自动启动，需显式管理操作。
- 恢复清理挂起会话并撤销旧订阅；恢复成功或确认回滚且模块重建完成后，可新建挂起会话。提交未知、排空/重建或旧实例关闭失败时保持维护状态，不继续接受新操作。

## 客户端与平台

导航栏切换在浏览器完成布局后测量并定位当前入口，窄屏继续自动滚动到当前入口，横向拖动与页面状态保留原行为。

前端首屏只合并原本必须加载的依赖，远程桌面、编辑器和文件预览仍按需加载；布局、样式及入口不变。省流、离线、后台页面、2G/3G 或浏览器报告 RTT ≥300ms／下行 ≤1Mbps 时停止后台页面预取，主动打开页面不受限制。生产构建附带 gzip 压缩资源，客户端按支持情况协商使用；哈希资源（含字体与图片）缓存一年，HTML 与更新入口继续及时检查，不缓存认证/API 数据。

支持响应式 Web/PWA；[桌面安装包](https://github.com/0honus0/nexus-terminal/releases/latest) 的部分认证/会话能力可能不同。代理、通知、审计、插件、诊断及设置列表在进入、重新激活或筛选时自动读取，模块标题区不再提供常驻刷新按钮；只有读取失败或写入结果未知时保留一次性的“重试／重新读取”，且不会重放原写入。Service Worker 检测到新的前端资源后显示全局“新版本已就绪”弹层；选择“稍后”只在当前页面会话内抑制同一更新，选择“立即更新”会清理前端缓存并重载页面，重载会丢失当前页面的临时界面状态，但不回滚后端数据或已确认操作。镜像支持 AMD64/ARM64，部署见 [DEPLOYMENT](DEPLOYMENT.md)。
