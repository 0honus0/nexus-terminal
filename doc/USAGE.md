# 使用

本文是实际软件需求与用户可见行为的规范入口。Bug 修复和需求变更应同步更新对应行为说明；实现边界见 [Frontend 架构](architecture/FRONTEND.md)、[Backend 架构](architecture/BACKEND.md) 和 [Agent 架构](AGENT.md)，开发约束见根目录 [AGENTS.md](../AGENTS.md)。

## 连接、代理与通知管理

公共标准弹窗使用不透明的主题底色，亮色模式下不会透出深色遮罩而变灰；页面背景仍由遮罩压暗以突出弹窗，弹窗正文及操作区域保持自身主题对比度。

Agent 每个模型可在「能力配置」中独立选择调用协议，保存后测试及正式调用使用该模型的协议，不改变其他模型。未独立设置的模型沿用提供商默认协议；外层卡片及测试弹窗顶部不再显示共享协议选择。手机端能力配置中的协议选择占满可用宽度，模型操作保持紧凑两列。响应格式校验失败返回 `PROVIDER_RESPONSE_INVALID`，DNS/TLS/网络故障、超时及上游 HTTP 状态分别返回对应错误码，未知原因返回 `PROVIDER_REQUEST_FAILED`，不假称资源不可用；不自动降级协议，不伪造缺失的响应 ID。

| 错误码                                                                                | 含义                                           |
| ------------------------------------------------------------------------------------- | ---------------------------------------------- |
| `PROVIDER_RESPONSE_INVALID` / `PROVIDER_RESPONSE_EMPTY` / `PROVIDER_STREAM_TRUNCATED` | 格式不兼容、空响应或流未完成                   |
| `PROVIDER_HTTP_<status>`                                                              | 上游实际 HTTP 错误状态，401、403、429 分别保留 |
| `PROVIDER_DNS_FAILED` / `PROVIDER_TLS_FAILED` / `PROVIDER_NETWORK_FAILED`             | DNS、证书或网络连接故障                        |
| `PROVIDER_NETWORK_TIMEOUT` / `PROVIDER_TEST_TIMEOUT` / `PROVIDER_DISCOVERY_TIMEOUT`   | 网络、测试或发现模型超时                       |
| `PROVIDER_REQUEST_FAILED`                                                             | 尚未分类的请求失败                             |
| `PROVIDER_UNAVAILABLE`                                                                | 提供商不存在或已停用                           |

首页手机端快速连接的搜索与筛选栏随列表上滑，不固定遮挡连接卡片；快速连接和 SSH 资源列表滚动后提供悬浮回顶箭头，各自返回对应列表顶部。SSH 资源按主机去重后逐个请求，主机之间间隔 200ms，逐项更新结果，不在进入首页或刷新时同时发起所有主机请求；页面销毁时取消未完成请求与后续队列。

顶部导航以圆角悬浮条展示，本体高 48px，上下各留 6px，使用主题顶部栏底色并随页面宽度延伸；所有页面的导航外侧留白与终端外框一致，桌面两侧各 8px，手机不额外留白。导航保留正常布局空间，不覆盖页面内容。宽屏菜单居中；窄屏通过页面选择菜单访问全部入口。终端仍可隐藏顶部导航。

页面统一预留浏览器滚动条空间，避免长短页面切换时导航横向跳动；设置页和终端页使用同一导航高度计算可用空间。

连接列表以独立卡片显示名称、类型、地址和操作，支持搜索、筛选、排序与批量操作；宽屏卡片右侧操作区纵向居中，窄屏自动换行。代理与通知列表共用管理卡片布局，类型标签位于名称右侧，空间不足时换行；桌面编辑和删除按钮在右侧居中，手机放在卡片底部并等宽排列，长名称和地址不会撑宽页面。

手机连接批量工具栏分两排：第一排为全选、取消选择和反选，第二排为编辑和删除，按钮等宽排列；桌面保留横向工具栏。

代理与通知管理桌面操作按钮至少高 44px、宽 96px；代理卡片不展示更新时间。非编辑区域不显示文本插入光标，导航、按钮和功能标签不选择文字；输入框、可编辑区域和正文复制保留正常行为。

挂起会话移除、连接/代理/通知/文件删除、接管和放弃修改等公共确认提示统一使用项目表单材质、状态图标、清晰的标题与正文以及独立操作区；危险操作以危险色按钮区分。桌面按钮至少高 44px，手机等宽排列，长提示可换行并纵向滚动。上传同名文件冲突提示使用相同视觉规范，保留跳过、覆盖和应用到全部的选择。

仪表盘连接目录加载完成后即可结束目录加载提示，不等待审计和挂起目录请求；返回仪表盘保留已有内容并后台刷新。

仪表盘 SSH 资源按主机独立加载、独立展示结果或错误；单个慢主机不阻塞其他主机的资源卡片，探测采用有界并发。

手机顶部页面切换使用可左右滑动的圆角页面标签，点击标签切换页面，当前页面高亮并在切换后自动滚动到可见位置；导航滑动不切换页面，也不带动下方终端滚动。连接管理的四个操作按钮通常一排四列，卡片可用宽度过窄时改为两排两列。

横向导航不额外叠加背景色，与顶栏共用背景。桌面窄窗口下，顶部菜单和设置功能标签同样支持鼠标按住左右拖动，并保留触摸与触控板原生滚动；拖动结束不误触选项，普通点击仍切换页面或功能。

连接、代理及通知配置使用统一的不透明表单背景，分组以标题和留白区分。连接测试的延迟说明在表单底部完整换行显示。

通用确认提示与上传冲突使用同一确认面板组件；管理卡片及批量操作区共用公共操作组。统一样式由公共组件集中维护，登录控件使用 44px 触摸密度，编辑器编码和换行下拉使用紧凑密度，业务操作与保存行为保持不变。

登录控件保持 44px 高度，字号与圆角沿用公共触摸密度。Agent「已配模型与连通测试」的模型名称完整展示，长名称换行；四个操作统一位于模型信息下方，桌面四列、手机两列，按钮使用至少 32px 的紧凑高度，测试结果可换行。模型连通测试执行实际模型请求；失败时显示本地化错误类别与服务端错误码，网站可访问或模型列表可获取不代表模型调用一定成功。

设置中的工作区偏好使用扁平分组与分隔线，不再层层嵌套面板和字段卡片；手机单列、宽屏双列，保留各分组独立保存、未保存提示和高级设置折叠。

## SSH 会话

全局 Agent 呼出悬浮按钮使用 44px 圆形、实心主色底与高对比图标，图标为对话框内的终端提示符；保留拖动位置、点击打开和任务数量徽标。拖到左右边缘附近松手后吸附贴边并半隐藏；鼠标悬停或键盘聚焦时完整展开，手机点击露出的半圆直接打开 Agent，也可拖回页面内取消贴边。贴边侧和纵向位置随布局保存，右键重置位置。

手机终端小键盘左侧六个固定键在普通页和功能键页保持相同顺序：第一排 Esc、Fn、Shift，第二排 Tab、Ctrl、Alt。Shift 使用文字显示，是修饰键而非方向键；右侧 ↑ 是终端方向上键，Fn 切换 F1–F12 页面。

### 挂起与恢复

SSH 标签页支持挂起会话。点击挂起只设置保留标记，不关闭当前标签或终端；关闭标签或浏览器断开时，后端接管并继续保持原 SSH/PTY。标记后的会话会显示在挂起面板中，具有会话访问权限的其他设备可以确认接管正在使用的会话，或恢复无人使用的会话；不需要持有原设备的普通 Workspace 恢复凭据。接管后原设备失去会话控制权，不允许两个设备同时写入同一 PTY。

挂起标记和提交成功必须返回真实的挂起会话 ID；注册结果缺失或 owner 已失效时返回失败，不发送没有 ID 的成功响应。

挂起会话保留最近最多 100MiB 的原始终端历史，恢复优先提供当前终端状态和有限尾部，更早历史按需分页。持续输出达到历史上限后仍可恢复原 SSH/PTY，不应因每次输出重写整个历史文件而耗尽恢复租约。

适合编译、下载、长时间运行任务等不希望因浏览器断线而中断的场景。

### 自动重连

浏览器网络抖动或 Workspace WebSocket 异常断开后，系统会在约 120 秒内保留原 SSH/PTY 和正在运行的压缩、复制/移动等后台任务。恢复网络后会优先续接原会话，并补回可用的终端输出和任务结果，不会新建 SSH 登录替换原终端。

手机切换应用后回到前台、页面从浏览器缓存恢复或网络恢复时，会对当前已连接的 Workspace 做有界存活检查；正常链路不重连，失效链路通过原会话凭据续接。标记为待挂起的断联标签会核对服务端目录并自动恢复无人使用的会话，不自动接管其他设备正在使用的会话，也不关闭用户后来打开的启动页。浏览器回收页面后不保留原标签内存，可通过启动页挂起目录恢复；未标记会话超过普通续接窗口时无法保证原 PTY 保留。

从其他管理页面返回终端同样检查旧链路存活；多个前台或网络恢复事件并发触发时复用正在执行的恢复，续接成功后不再次对已绑定链路发起续接。

恢复只接受当前标签持有的会话凭据，并校验登录用户、Workspace 和连接身份；打开同一连接的新标签不能接管旧 Workspace。主动关闭标签会立即释放会话，远端终端已退出或宽限期结束后则不能继续恢复。

连接处于断开状态时，可以通过以下方式提前触发恢复：

- 在命令输入框按回车。
- 在终端中按回车。
- 再次点击连接列表中的同一个 SSH 连接。

## 命令输入框

- `Alt + ↑/↓`：切换 SSH 会话标签页。
- `Alt + ←/→`：切换文本编辑器标签页。
- 开启命令同步后，命令输入可以同步到选定目标。
- `↑/↓` 可选择菜单中的历史或快捷命令项，`Enter` 发送。

## 终端

- 点击 SSH 连接后立即进入终端；连接中显示状态并禁用输入，连接成功后自动启用。
- 自定义 HTML 终端背景会在终端可见时显示，切换回标签页后自动恢复。
- `Ctrl + Shift + C`：复制。
- `Ctrl + Shift + V`：粘贴。
- 普通桌面终端有选区时右键复制，无选区时右键粘贴；Codex 等接管鼠标的终端程序保留右键操作，可按住 `Shift` 拖选，再用 `Ctrl + Shift + C/V` 复制粘贴。
- 移动端支持双指缩放终端字体。
- 终端在没有会话时，以及点击标签栏 `＋` 后，桌面和手机均显示统一的“连接与会话”启动页，可恢复挂起会话或搜索并发起连接。手机使用整页纵向滚动；已有会话保持运行，可点击原标签或“返回当前终端”返回。标签栏的挂起入口可在已有会话时直接打开挂起列表。
  宽屏启动页将操作区置于左侧，发起连接在左栏、挂起会话在右栏，页面右侧为非交互装饰；小屏隐藏装饰并纵向排列列表。
  点击 SSH 连接后立即进入终端连接等待界面；连接过程中可再次点击 `＋` 打开启动页，后台连接完成不会自动关闭新打开的启动页。
  手机启动页优先展示发起连接，挂起会话在下方；桌面仍为左侧连接、右侧挂起。连接标签分组展开后，子项类型图标与分组箭头左侧对齐。

  连接标签分组标题使用中性浅底色和细边界区分，不使用紫色选中背景；适用的批量连接、分组管理和批量删除工具常显，无需悬停。

浏览器剪贴板能力通常要求 HTTPS 或 localhost 安全上下文。

## 文件管理器与在线编辑

文件管理器支持：

- 搜索后使用 `↑/↓` 快速选择文件。
- 从浏览器外拖入文件或文件夹进行上传。
- 在文件管理器内部拖动文件或目录完成移动。
- 使用 `Ctrl` / `Shift` 多选。
- 通过右键菜单执行复制、粘贴、剪切、删除、重命名、权限修改等操作。
- 桌面文件列表中选中任意项后，可按 `Ctrl + V` 将剪贴板截图上传到当前浏览目录；搜索框、路径框等文本输入区域仍按原生文本粘贴处理。
- 桌面表格列使用 `Type / Name / Size / Permissions / Modified` 标题；列宽和行缩放可在设置中持久化。
- 使用 Monaco Editor 在线编辑文本文件。
- 预览 Markdown、图片、PDF、电子表格和 DOCX 等受支持文件；Markdown/PDF/电子表格/DOCX 共用搜索控件，支持 `Ctrl/Cmd + F`、匹配计数与前后跳转，电子表格只有在行数超过当前每页数量时才显示分页栏。
- 上传、复制/移动、压缩和跨会话传输会进入共享进度模型；浮动进度窗可隐藏，隐藏任务可从 Progress Display 恢复或取消。
  各处浮动进度窗共用紧凑结构，默认 360×190px，最小 280×130px，超出视口时自动收敛；保留用户保存的拖动位置和缩放尺寸。上传显示文件名、状态、百分比、已传/总字节数和总速度；多任务在窗内纵向滚动，保留取消、隐藏和移除记录操作。其他任务保留当前文件、文件计数或字节进度及错误提示，不额外扩大窗口。

路径输入框获得焦点后可打开路径历史。路径历史与“收藏路径”弹层会根据当前 Workspace/浏览器宽度自适应，并允许长路径换行显示；调整浏览器或 pane 宽度时，弹层会保持在可用视口内。

大量文件或深层目录上传时，建议先压缩后上传，减少浏览器一次性处理的文件数量。

## 历史命令

历史命令过长而被截断时，可以将鼠标悬停在命令上查看完整内容。

## 布局与通用操作

- 终端、文件管理器、文本编辑器和快捷指令视图支持 `Ctrl + 鼠标滚轮` 缩放。
- 布局管理器中的容器方向会直接反映在预览结构中：`水平` 容器的直接子节点横向排列，`垂直` 容器的直接子节点纵向排列；切换方向只改变该容器的子节点排列方向，不改变子节点本身的类型或内容。
- 展开的侧栏可以拖动调整宽度并持久化。默认点击 Workspace 其它区域会收回侧栏，开启“保持侧栏”偏好后才持续展开；无活动会话时使用统一启动页。
- File Manager / File Editor 的 popup 设置提供额外弹层入口，不复制文件系统或编辑器业务状态；embedded/sidebar presentation 仍使用同一 feature controller。
- File Manager 在很窄的 pane/sidebar 中会自动收起 `Size / Permissions / Modified` 次要列，只保留紧凑的文件类型图标与名称；恢复较宽 pane 后仍使用原来持久化的列宽。目录或搜索加载期间，加载动画显示在文件列表剩余区域中央。
- Quick Commands 的 Copy / Edit / Delete 行级操作通过右键菜单提供，不再在每一行末尾占用三个图标位置；单击指令行仍执行当前指令。
- 手机端顶部导航通过页面选择菜单访问全部页面，不需要横向滚动。
- 手机端终端长按选择/复制期间会暂时抑制系统软键盘，拖动选择手柄和点击 Copy 不会反复触发键盘弹入/收回；Copy 后不会主动重新聚焦输入框，下一次普通轻点终端时恢复键盘输入，Paste 仍会按原有行为恢复终端输入焦点。
- SSH 标签栏和文件管理器标签栏支持右键菜单，包括关闭当前、关闭左侧、关闭其他、关闭右侧等操作。
- 快捷指令分组仅在点击分组名称文字时进入编辑；点击箭头或名称右侧空白区域用于展开/收起。快捷指令顶部控制按钮会随 pane 宽度缩放，并在极窄 pane 中避免产生水平溢出。
- 标签分组中的名称可以直接点击修改。

## Dashboard

- 常见桌面分辨率下，Quick Connect 与 SSH 资源列表使用内部滚动和受限高度，避免必须先滚动整页才能看到“最近活动”。
- SSH 资源卡片在连接列表加载后分别请求状态；一台主机连接超时或失败时，其他主机的状态仍会及时显示，失败只标记在对应卡片上。
- 列表内容较多时继续在各自面板内滚动，不牺牲最近活动的首屏可达性。

## 状态监控与 Docker

- Status Monitor 默认显示在线状态而不是直接展示 IP；可在 Settings 中开启 IP 显示与复制。
- 状态采样间隔、缩放和 Docker 刷新间隔均由 Settings 持久化；默认 Docker 刷新间隔为 5 秒。
- Docker manager 在桌面宽 pane 使用表格，在窄 sidebar 使用卡片布局；Start/Stop/Restart/Remove 走 Docker capability，Enter/Logs 发送到当前 Workspace terminal。

## Agent

- 首次启用 Agent 时按 onboarding 安装推荐的 first-party Plugin，并在 Settings 中配置 Provider、模型和 Runner。
- Agent launcher 在认证后显示；打开 Host 后可创建 Thread、设置 Goal、提交输入并查看 Plan、approval、artifact 和运行历史。
- 桌面 Agent 窗口可拖动标题栏调整位置；右下角缩放手柄围绕窗口当前中心对称扩展或收缩，并跟随鼠标移动。任一边缘到达屏幕边界后停止该方向的扩展；键盘方向键调整大小采用同样的居中缩放方式。
- Run 执行期间可以继续提交输入。输入会进入 durable queue，并按当前 Run 状态打断或留待后续消费。
- Environment 选择器决定下一次 Run 使用的 Workspace、Toolchain 和 target；服务端会验证并冻结本次执行配置。
- Workspace Terminal、ACP、Browser 和 Runner Plugin 依赖可用的 Agent Runner。Runner 不可用时，普通 SSH/文件管理/远程桌面仍可使用。
- Plugin App 只获得已声明并授权的 capability。需要确认的 mutation 会先显示 approval，未知执行结果会进入核对或恢复流程。

## 外观与 HTML Theme

Style Customizer 支持本地 HTML theme 和 GitHub 目录形式的远程 HTML theme catalog。远程 catalog 配置在升级、保存、读取和备份恢复后都会经过规范化；用户配置的第三方仓库保持原地址。

## 安全与认证

Nexus Terminal 支持多种认证和安全配置，包括：

- hCaptcha / Google reCAPTCHA。
- 2FA。
- Passkey / WebAuthn。
- IP 白名单与黑名单。
- 登录和异常通知。
- 审计日志。

Passkey 的部署域名配置见 [部署与更新](./DEPLOYMENT.md#passkey--webauthn)。

## 镜像发布

Workspace 是独立的项目与运行环境管理模块。支持版本 JSON 保留 Node、Python、Go 的可选版本和架构，用户从列表选择；安装使用 mise 获取指定版本并检查实际版本，不限制该版本具体的上游构建来源，也不要求维护安装树摘要或选择指纹。已安装环境重复使用，不因上游重建自动替换；使用中的版本不能卸载，明确卸载后重新安装可获取该版本当前的上游构建。

镜像发布保留生产依赖 high 级安全审计；release channel 仅发布当前 main 提交，并要求该提交的完整 E2E（基础检查、全部 Playwright 分片和 Docker smoke）成功。Actions 运行标题显示 channel、架构和发布目标，主镜像与 Runner 任务使用固定名称，准备失败时仍可辨认任务。发布和部署方式见 [部署与更新](./DEPLOYMENT.md)。

## 当前限制与注意事项

- 双文件管理器布局属于实验性能力，复杂场景可能存在边界行为。
- 同一布局中添加多个文本编辑器目前并非完整支持场景。
- 请自行备份部署目录中的 `data`；项目本身不替代外部备份方案。
- 生产访问建议启用 HTTPS。
