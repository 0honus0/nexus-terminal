### 本轮修正与边界

- Service 决定挑战/部分认证的期限与容量，检查 TOTP 已启用政策；Model 接受明确应用政策并转换存储/技术调用。协议时间 Unix 秒只在 HTTP mapper 转换，Service 保持毫秒应用值。
- Access HTTP 统一通过 access-delivery 跟踪密码/部分认证/因素会话及挑战的 issue → send → finish/close。未交付时撤销已提交令牌或挑战，等待清理并保留聚合因果；HTTP finish 仅证明服务器交付完成，不证明浏览器收到。
- 会话事务已经签发、后续身份确认失败时按 operation_unknown 表达并尽力撤销该 token；不降为确定未写入，不自动重试。
- WebAuthn Port 定义独立技术证据，Model 显式投影，Adapter 对 vendor registration/authentication JSON 分别构造；移除 unknown 类型断言，补全 credProps 和 transports，校验 canonical base64url。TOTP issuer/WebAuthn RP 显示名由应用传入，Platform 不硬编码产品名称。
- HTTP 入口统一归 access/interfaces/http；协议容量归 Shared access/values，注册存储使用明确写命令，不虚构创建时间。数据库 bool 严格解码，挑战在最终变更前再次核对到期；Service 回收确定拒绝的 Passkey 挑战，TOTP 输错仍允许期限内重试。
