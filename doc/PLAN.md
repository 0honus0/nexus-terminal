## 模型 GIF 与文件交付：限定浏览器通过，执行远程验收与 dev 发布

范围：允许 Images 返回真实 GIF；新增 `file_deliver`（已选 SSH 普通文件流式入库）和 `artifact_present`（展示当前 App 已有文件），文本 `artifact_create` 也自动展示。参考成熟项目结构化文件引用，复用 Artifact、file-type 与现有 FilePreview；不新增存储格式或数据库迁移，不扩展外部 URL/宿主文件读取。

| 阶段 | 消费者与任务                                      | 判据                              |
| ---- | ------------------------------------------------- | --------------------------------- |
| 设计 | Agent/Remote/Platform owner、Shared 引用、当前 UI | 八节设计、权限和资源闭环          |
| 实现 | GIF MIME、远程流、复合授权、工具目录/指引、文件卡 | 双端与脚本/测试同步，无旧字段兼容 |
| 验证 | 增补正式 E2E；根 check、全格式、双端 build        | 静态通过；行为结果按 D17 单独记录 |
