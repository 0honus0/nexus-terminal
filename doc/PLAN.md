## Agent 工具优化与资源管理

按当前授权继续完善 Run 级 SSH/SFTP 复用：资源跨模型步骤、审批和工具阶段保留，最终任务完成、取消、失败及撤权统一排空；侧栏展示连接、前台/后台执行与清理状态，手动关闭执行中的任务必须确认，后端复核原资源会话身份及当前活动状态。主动关闭 Agent 界面使用同一停止确认，隐藏和切换不视为主动停止。工具活动更新 10 分钟资源空闲期限；执行中的操作和后台任务不得因空闲计时被中断。正常隐藏、切换聊天和短时断网不停止任务；任务最终结束仍立即排空，显式关闭走确认。后端独立追踪到期回收，不依赖浏览器卸载事件。

Shell 工具统一为 commands 数组（单条同一路径），一批命令使用一次 exec，隔离每条命令的 cwd/env 与输出，逐条报告退出码、未执行项；明确遇错停止/继续，不增加冗余命令条数参数。批次结束关闭 exec，SSH/SFTP 留给后续工具；不创建常驻交互 Shell、不落远端临时文件。未知派发和清理失败不重放；Shared 契约、前后端与所有测试消费者同版迁移。Shell Job 结果 JSON 通过独立 v2 迁移转换；文件交付/展示结果通过独立 v3 转换，运行路径不保留旧结构兼容。

### 工具优化范围与消费者

- 文件：同文件多处 patch、同类多路径读写、一次遍历多查询搜索，分项返回与整批路径依赖预检；大文件/目录分页按技术能力同步实现，不扩大现有捕获预算。
- Docker：定向 inspect 替代全量列表与 stats；同目标批量检查/控制逐项结算，保留 fingerprint 与未知围栏。
- Job：多 Job 状态/等待/取消，事件唤醒后权威复查，输出按游标续读；已有 join/cancel 集合不叠加批量包装。
- MCP：复用 SDK 缓存、变更通知与任务租约；Browser 保留会话隔离，组合观测和按资源调度；ACP 保留明确单轮语义，不暗中缓存会话上下文。
- 其余工具：多文件交付/展示、文本 Artifact 页和结果批读；减少重复只读串行屏障，保持上下文变更、付费图像、插件调用的独立授权与结果。
- 声明、严格解码、模型供应商 schema、摘要、权限/账本、测试夹具及官方插件指导同版核对；对象数组不能退化为未经校验的 JSON 字符串。
- 先落工具，再资源管理，最后补后端/浏览器 E2E、本地完整回归、提交推送与远程完整回归；失败保留首次证据后修复，当前 SHA 全绿再发布。
